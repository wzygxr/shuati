# 丁文革第3章例3.21--3.49：原书勘误与独立复算账 DING-C3-v002

本账只记录会改变答案、数量级、图号解释、唯一性或适用范围的高风险项目；普通舍入差异保留在逐题正文中。

| 题位 | 原书口径或结果 | 本卷独立复核 | 证据方式 |
|---|---|---|---|
| 例3.21 | 月面光斑“大小”145 km，扩束后56.4 m | $1.22\lambda L/D$是第一暗环半径。按 $L=3.76\times10^5$ km，半径分别为145.139 km和58.056 m；若题目所称“大小”指直径，应再乘2 | 圆孔第一零点与单位复算 |
| 例3.22 | 最近可分辨距离12.2 μm | 原书混用像方角度与物方距离并漏半口径。由薄透镜公式得物距4.103 mm、物方NA约0.438，Rayleigh物方分辨约0.696 μm（傍轴约0.626 μm） | 有限共轭成像+物方NA |
| 例3.28 | 图(a)为第一、第三缝 | 图(a)周期对应相邻缝中心距2a，应为第一、第二缝；第一、第三缝中心距4a，对应图(c) | 按干涉因子周期反认缝距 |
| 例3.29 | 只列 $d\sin\theta=k\lambda$ | 该式只给最强主极大。完整主极大为 $3d\sin\theta=m\lambda$；$m\equiv0\pmod3$强度归一为1，$m\equiv\pm1\pmod3$为1/4 | 三缝复振幅直接求和 |
| 例3.31 | 楔片使一级方向改变2.24° | 玻璃楔替代空气的相位梯度含 $(n-1)$ 而非 $n$；改变量约0.751° | 光程增量 $(n-1)t$ |
| 例3.33、3.34 | 缺第三级唯一推出 $a=d/3$ | 缺第三级允许 $a/d=1/3$ 或2/3；原书选择的是常见较小开口率设计 | 单缝零点与光栅主极大重合条件 |
| 例3.36 | 光栅B角距0.11角秒 | $5.164\times10^{-6}$ rad等于约1.065角秒，原书小10倍 | rad到角秒换算 |
| 例3.38 | 每侧可见1--5级 | 第5级位于 $\sin\theta=1$ 的90°掠射边界；数学计数可含5，实际有限数值孔径光谱仪通常稳定收集到第4级 | 级次存在条件与仪器孔径边界 |
| 例3.41 | 仅讨论二、三级完整谱重叠 | 对“完整可见谱”口径成立；若计入不完整第4--6级，还存在额外局部重叠 | 逐级区间交集 |
| 例3.42 | 500--510 nm | 这是 $x/f\ll1$ 的近轴值；精确用 $\sin\theta=x/\sqrt{x^2+f^2}$ 得497.52--507.37 nm | 几何角度精算 |
| 例3.43 | 第4级缺级唯一给 $a=d/4$ | 若只知第4级缺失，还允许 $a/d=1/2,3/4$；只有“第4级是第一缺级”才唯一为1/4 | 缺级整数解完整枚举 |
| 例3.49 | 法-珀角散代入10°但题面未给工作角；性能表绝对排序 | 保留原书典型配置比较，同时明确角散、通光量、强度与自由光谱区均依工作点、反射率、闪耀角、狭缝和探测器而变 | 公式参数审计与仪器适用边界 |
