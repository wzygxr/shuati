# 强连通分量笔试面试变种题集锦

## 一、基础变种

### 1. 无向图连通分量 vs 有向图强连通分量

**问题**: 给定一个图，判断是有向图还是无向图，并求对应的连通分量。

**解答思路**:
```cpp
void solve(vector<vector<int>>& adj, bool is_directed) {
    if (is_directed) {
        // 有向图：用Tarjan求SCC
        tarjan_scc(adj);
    } else {
        // 无向图：用DFS或并查集
        dfs_cc(adj);
    }
}
```

---

### 2. 重边和自环处理

**问题**: 图中可能存在重边和自环，如何处理？

**解答**:
- **重边**: 不影响SCC结果，但缩点时可能产生重边，可去重或忽略
- **自环**: 节点与自身形成环，该节点至少自成一个SCC

```cpp
void handle_special_edges(int n, vector<pair<int,int>>& edges) {
    set<pair<int,int>> unique_edges;  // 去重重边
    for (auto& e : edges) {
        if (e.first == e.second) continue;  // 去除自环（或保留）
        unique_edges.insert(e);
    }
}
```

## 二、进阶变种

### 3. 带权SCC - 最小/最大权值

**问题**: 每个节点有权值，求每个SCC的最小/最大权值。

**解答**:
```cpp
void weighted_scc(int n, vector<int>& weights) {
    tarjan(n);  // 求SCC
    
    vector<int> scc_min(scc_cnt + 1, INF);
    vector<int> scc_max(scc_cnt + 1, -INF);
    
    for (int i = 1; i <= n; i++) {
        int id = scc_id[i];
        scc_min[id] = min(scc_min[id], weights[i]);
        scc_max[id] = max(scc_max[id], weights[i]);
    }
}
```

### 4. DAG最长路/最短路

**问题**: 缩点后求DAG的最长路/最短路。

**解答**:
```cpp
int dag_longest_path() {
    topological_sort();  // 拓扑排序
    
    vector<int> dp(scc_cnt + 1, 0);
    for (int u : topo_order) {
        for (int v : dag[u]) {
            dp[v] = max(dp[v], dp[u] + weight[v]);
        }
    }
    
    return *max_element(dp.begin(), dp.end());
}
```

### 5. 路径计数

**问题**: 缩点后求DAG上从源点到汇点的路径数。

**解答**:
```cpp
int count_paths(int source, int sink) {
    topological_sort();
    
    vector<int> dp(scc_cnt + 1, 0);
    dp[source] = 1;
    
    for (int u : topo_order) {
        for (int v : dag[u]) {
            dp[v] = (dp[v] + dp[u]) % MOD;
        }
    }
    
    return dp[sink];
}
```

## 三、高级变种

### 6. 动态SCC

**问题**: 图动态变化（加边/删边），实时查询SCC数量。

**解答思路**:
- **加边**: 可能合并SCC，可用并查集维护
- **删边**: 可能需要重新计算，复杂度较高
- **离线处理**: 用分治或线段树维护

---

### 7. 近似SCC（大规模图）

**问题**: 图太大（10^7节点），无法精确计算SCC。

**解答思路**:
- **采样**: 随机采样子图估计SCC数量
- **分布式**: 用MapReduce并行计算
- **近似算法**: 用Streaming算法

---

### 8. 最小SCC覆盖

**问题**: 选择最少数量的节点，使得每个SCC至少包含一个被选节点。

**解答思路**:
- 缩点后，问题转化为DAG上的最小路径覆盖
- 可以用二分图匹配求解

int min_edges_to_strongly_connected(int n) {
    tarjan(n);
    if (scc_cnt == 1) return 0;
    
    shrink(n);
    
    int in0 = 0, out0 = 0;
    for (int i = 1; i <= scc_cnt; i++) {
        if (in_deg[i] == 0) in0++;
        if (out_deg[i] == 0) out0++;
    }
    
    return max(in0, out0);
}

### 片段4: Kosaraju算法模板
```cpp
void kosaraju(int n) {
    // 第一次DFS
    for (int i = 1; i <= n; i++) {
        if (!vis[i]) dfs1(i);
    }
    
    // 第二次DFS
    reverse(order.begin(), order.end());
    for (int u : order) {
        if (!scc_id[u]) {
            scc_cnt++;
            dfs2(u);
        }
    }
}
```

## 五、面试口述模板

### 模板1: Tarjan算法口述
> "Tarjan算法通过一次DFS找出所有强连通分量。它维护两个数组：dfn记录节点的访问顺序，low记录节点能回溯到的最早祖先。当dfn[u]等于low[u]时，u是一个强连通分量的根，栈中u上方的所有节点构成一个SCC。"

### 模板2: 缩点作用口述
> "缩点将每个强连通分量收缩为一个超级节点，原图中不同SCC之间的边变为超级节点之间的边。缩点后得到的有向图一定是DAG，这样可以利用拓扑排序进行动态规划等操作。"

### 模板3: SCC在ML中的应用口述
> "在图神经网络中，SCC可以用于图结构简化。通过将强连通的节点合并，可以减少节点数量，降低计算复杂度。同时，SCC保留了图的拓扑结构信息，有利于后续的图神经网络训练。"

## 六、常见错误与坑点

### 错误1: 忘记初始化全局变量
```cpp
// 错误：全局变量没有在每个测试用例前清零
void solve() {
    // 缺少初始化导致错误
    tarjan(n);
}

// 正确
void solve() {
    memset(dfn, 0, sizeof(dfn));
    timestamp = 0;
    scc_cnt = 0;
    tarjan(n);
}
```

### 错误2: 缩点时重复统计边
```cpp
// 错误：重边导致入度统计错误
void shrink() {
    for (int u = 1; u <= n; u++) {
        for (int v : adj[u]) {
            if (scc_id[u] != scc_id[v]) {
                in_deg[scc_id[v]]++;  // 重边导致多次增加
            }
        }
    }
}

// 正确：使用set去重
void shrink() {
    set<pair<int,int>> edges;
    for (int u = 1; u <= n; u++) {
        for (int v : adj[u]) {
            if (scc_id[u] != scc_id[v]) {
                edges.insert({scc_id[u], scc_id[v]});
            }
        }
    }
    for (auto& e : edges) {
        in_deg[e.second]++;
        out_deg[e.first]++;
    }
}
```

### 错误3: 递归栈溢出
```cpp
// 错误：递归深度可能超过限制
void tarjan(int u) {
    // 对于10^6节点的图会栈溢出
}

// 正确：使用迭代版本或增加栈空间
#pragma comment(linker, "/STACK:1024000000,1024000000")  // Windows
// 或使用迭代版Tarjan
```

## 七、实战演练

### 练习题1: 强连通分量大小排序
**题目**: 求所有SCC，按大小从大到小输出。

**答案**:
```cpp
vector<int> get_scc_sizes() {
    tarjan(n);
    vector<int> sizes;
    for (int i = 1; i <= scc_cnt; i++) {
        sizes.push_back(scc_size[i]);
    }
    sort(sizes.rbegin(), sizes.rend());
    return sizes;
}
```

### 练习题2: 判断是否存在唯一SCC
**题目**: 判断图中是否存在唯一的最大SCC。

**答案**:
```cpp
bool has_unique_largest_scc() {
    tarjan(n);
    int max_size = *max_element(scc_size + 1, scc_size + scc_cnt + 1);
    int count = 0;
    for (int i = 1; i <= scc_cnt; i++) {
        if (scc_size[i] == max_size) count++;
    }
    return count == 1;
}
```
