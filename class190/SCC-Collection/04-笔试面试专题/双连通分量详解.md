# 双连通分量详解（点双连通 & 边双连通）

## 一、双连通分量简介

### 什么是双连通？

**双连通图**：删除任意一个顶点后，图仍然连通的图。

**边双连通图**：删除任意一条边后，图仍然连通的图。

**对比：**

| 类型 | 定义 | 关键结构 |
|------|------|----------|
| 强连通（有向图） | 任意两点互相可达 | SCC |
| 点双连通（无向图） | 删除任意一点仍连通 | 点双连通分量 |
| 边双连通（无向图） | 删除任意一边仍连通 | 边双连通分量 |

## 二、点双连通分量（Vertex Biconnected Component）

### 定义

**点双连通分量**：极大的点双连通子图。

**关键概念 - 割点（Articulation Point）：**
- 删除该点后，图的连通分量数增加
- 割点是点双连通分量的"边界"

### Tarjan算法求点双连通分量

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 100005;

vector<int> adj[MAXN];

int dfn[MAXN], low[MAXN], timestamp;
stack<pair<int, int>> st;  // 存储边（u,v）

vector<vector<int>> bcc;   // 点双连通分量列表

/**
 * Tarjan求点双连通分量
 * 
 * 与SCC的区别：
 * - SCC用点栈，点双用边栈
 * - 点双在low[v] >= dfn[u]时出栈
 */
void tarjan(int u, int parent) {
    dfn[u] = low[u] = ++timestamp;
    
    int child_count = 0;  // 子树数量，用于判断根节点是否为割点
    
    for (int v : adj[u]) {
        if (!dfn[v]) {
            // 树边
            st.push({u, v});  // 边入栈
            child_count++;
            
            tarjan(v, u);
            low[u] = min(low[u], low[v]);
            
            // 如果low[v] >= dfn[u]，说明v无法绕过u到达祖先
            // u是割点，(u,v)是一个点双连通分量的根
            if (low[v] >= dfn[u]) {
                vector<int> component;
                pair<int, int> e;
                do {
                    e = st.top(); st.pop();
                    component.push_back(e.first);
                    component.push_back(e.second);
                } while (e != make_pair(u, v));
                
                // 去重并保存
                sort(component.begin(), component.end());
                component.erase(unique(component.begin(), component.end()), component.end());
                bcc.push_back(component);
            }
        } else if (v != parent && dfn[v] < dfn[u]) {
            // 回边（避免重复，只考虑指向祖先的回边）
            st.push({u, v});
            low[u] = min(low[u], dfn[v]);
        }
    }
    
    // 特判：根节点是割点的条件是子树数量 >= 2
    if (parent == -1 && child_count >= 2) {
        // 根节点是割点
    }
}

int main() {
    int n, m;
    cin >> n >> m;
    
    for (int i = 0; i < m; i++) {
        int u, v;
        cin >> u >> v;
        adj[u].push_back(v);
        adj[v].push_back(u);
    }
    
    memset(dfn, 0, sizeof(dfn));
    timestamp = 0;
    
    for (int i = 1; i <= n; i++) {
        if (!dfn[i]) {
            tarjan(i, -1);
            
            // 处理栈中剩余的边
            if (!st.empty()) {
                vector<int> component;
                while (!st.empty()) {
                    auto e = st.top(); st.pop();
                    component.push_back(e.first);
                    component.push_back(e.second);
                }
                sort(component.begin(), component.end());
                component.erase(unique(component.begin(), component.end()), component.end());
                bcc.push_back(component);
            }
        }
    }
    
    // 输出点双连通分量
    cout << "点双连通分量数量: " << bcc.size() << endl;
    for (int i = 0; i < bcc.size(); i++) {
        cout << "分量 " << i+1 << ": ";
        for (int v : bcc[i]) {
            cout << v << " ";
        }
        cout << endl;
    }
    
    return 0;
}
```

## 三、边双连通分量（Edge Biconnected Component）

### 定义

**边双连通分量**：极大的边双连通子图。

**关键概念 - 桥（Bridge）：**
- 删除该边后，图的连通分量数增加
- 桥是边双连通分量的"边界"

### Tarjan算法求边双连通分量

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 100005;

vector<int> adj[MAXN];

int dfn[MAXN], low[MAXN], timestamp;
int ebc_id[MAXN], ebc_cnt;  // 边双连通分量编号

// 存储桥
vector<pair<int, int>> bridges;

void tarjan(int u, int parent) {
    dfn[u] = low[u] = ++timestamp;
    
    for (int v : adj[u]) {
        if (!dfn[v]) {
            tarjan(v, u);
            low[u] = min(low[u], low[v]);
            
            // 判断是否为桥
            if (low[v] > dfn[u]) {
                bridges.push_back({u, v});
            }
        } else if (v != parent) {
            low[u] = min(low[u], dfn[v]);
        }
    }
}

/**
 * DFS标记边双连通分量
 * 不经过桥，能到达的所有点属于同一个边双
 */
void dfs(int u, int id) {
    ebc_id[u] = id;
    for (int v : adj[u]) {
        if (ebc_id[v]) continue;
        
        // 检查(u,v)是否为桥
        bool is_bridge = false;
        for (auto& b : bridges) {
            if ((b.first == u && b.second == v) ||
                (b.first == v && b.second == u)) {
                is_bridge = true;
                break;
            }
        }
        
        if (!is_bridge) {
            dfs(v, id);
        }
    }
}

int main() {
    int n, m;
    cin >> n >> m;
    
    for (int i = 0; i < m; i++) {
        int u, v;
        cin >> u >> v;
        adj[u].push_back(v);
        adj[v].push_back(u);
    }
    
    // 第一步：求桥
    memset(dfn, 0, sizeof(dfn));
    timestamp = 0;
    
    for (int i = 1; i <= n; i++) {
        if (!dfn[i]) tarjan(i, -1);
    }
    
    // 第二步：标记边双连通分量
    memset(ebc_id, 0, sizeof(ebc_id));
    ebc_cnt = 0;
    
    for (int i = 1; i <= n; i++) {
        if (!ebc_id[i]) {
            ebc_cnt++;
            dfs(i, ebc_cnt);
        }
    }
    
    cout << "边双连通分量数量: " << ebc_cnt << endl;
    cout << "桥的数量: " << bridges.size() << endl;
    
    return 0;
}
```

## 四、三种连通分量对比

| 特性 | 强连通分量（SCC） | 点双连通分量 | 边双连通分量 |
|------|------------------|-------------|-------------|
| **适用图** | 有向图 | 无向图 | 无向图 |
| **定义** | 互相可达 | 删除任意点仍连通 | 删除任意边仍连通 |
| **关键结构** | 环 | 割点 | 桥 |
| **算法** | Tarjan/Kosaraju | Tarjan（边栈） | Tarjan（求桥+DFS） |
| **缩点后** | DAG | 树 | 树 |
| **时间复杂度** | O(V+E) | O(V+E) | O(V+E) |

## 五、笔试面试高频问题

**Q1: 点双和边双的区别是什么？**
> 点双关注顶点，删除任意顶点后仍连通；边双关注边，删除任意边后仍连通。点双用边栈实现，边双先求桥再DFS。

**Q2: 如何判断一个点是割点？**
> 对于非根节点u，如果存在子节点v满足low[v] >= dfn[u]，则u是割点。对于根节点，需要至少两个子树。

**Q3: 如何判断一条边是桥？**
> 对于边(u,v)，如果low[v] > dfn[u]（v是u的子节点），则(u,v)是桥。

**Q4: 为什么点双用边栈而SCC用点栈？**
> 点双的边界是割点，割点可能属于多个点双，用边栈可以正确处理。SCC的边界是SCC根，每个点只属于一个SCC，用点栈即可。

## 六、应用场景

### 1. 网络可靠性
- **点双**：网络节点故障容错
- **边双**：网络链路故障容错

### 2. 交通规划
- 找出关键路口（割点）
- 找出关键路段（桥）

### 3. 社交网络
- 找出关键人物（割点）
- 社区发现（双连通分量）
