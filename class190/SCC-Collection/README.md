## 📚 核心知识点

### 强连通分量（SCC）
- **定义**：有向图中互相可达的最大子图
- **算法**：Tarjan、Kosaraju、Gabow
- **复杂度**：O(V + E)

### 缩点
- **定义**：将SCC收缩为超级节点
- **性质**：缩点后得到DAG（有向无环图）
- **应用**：DAG上的DP、拓扑排序

### 应用场景
- 社交网络分析
- 依赖关系解析
- 2-SAT问题
- 图神经网络优化

## 💡 学习建议

1. **理解本质**：重点理解dfn和low数组的含义，不要死记硬背
2. **动手实践**：每道题都要自己写代码，至少3遍
