# 【力扣】1192. 查找集群中的关键连接

## 题目链接
https://leetcode.cn/problems/critical-connections-in-a-network/

## 题目描述

n 台服务器，通过一些连接连接成一个网络。给你一个整数 n 和数组 connections，其中 connections[i] = [ai, bi] 表示服务器 ai 和 bi 之间有一条连接。

关键连接是指删除后会导致网络不稳定的连接。请返回所有关键连接，按任意顺序返回。

## 输入输出示例

**示例 1:**
```
输入: n = 4, connections = [[0,1],[1,2],[2,0],[1,3]]
输出: [[1,3]]
解释: 边[1,3]是唯一的桥
```

**示例 2:**
```
输入: n = 2, connections = [[0,1]]
输出: [[0,1]]
```

## 数据范围
- $2 \leq n \leq 10^5$
- $n-1 \leq \text{connections.length} \leq 10^5$
- $0 \leq ai, bi < n$
- $ai \neq bi$

## 笔试/面试考察点分析

### 核心考察点
1. **桥（Bridge）的识别**：low数组的核心应用
2. **无向图处理**：与有向图SCC的区别
3. **Tarjan算法变体**：求割边而非强连通分量
4. **大规模图处理**：$10^5$节点需要高效实现

### 面试高频问题
1. **什么是桥？** 删除后使图不连通的边
2. **如何判断桥？** 对于边(u,v)，如果low[v] > dfn[u]，则(u,v)是桥
3. **与有向图SCC的区别？** 无向图没有"强连通"概念，只有连通性

## 解题思路

### 核心思想
使用Tarjan算法的思想，通过dfn和low数组判断桥：
- 对于树边(u,v)，如果v不能通过回边到达u或u的祖先（即low[v] > dfn[u]）
- 则(u,v)是桥，删除后u和v不连通

### 算法步骤
```
1. 构建无向图邻接表（每条边存两次）
2. Tarjan DFS遍历图
3. 对于每条树边(u,v)，检查low[v] > dfn[u]
4. 如果是，加入结果集
```

## 完整代码实现

```cpp
class Solution {
public:
    vector<vector<int>> criticalConnections(int n, vector<vector<int>>& connections) {
        // 构建无向图邻接表
        vector<vector<int>> adj(n);
        for (auto& conn : connections) {
            int u = conn[0], v = conn[1];
            adj[u].push_back(v);
            adj[v].push_back(u);  // 无向图，双向添加
        }
        
        vector<int> dfn(n, 0), low(n, 0);
        vector<vector<int>> result;
        int timestamp = 0;
        
        // Tarjan算法求桥
        // parent: 当前节点的父节点，用于避免直接返回父节点形成的"假回边"
        function<void(int, int)> tarjan = [&](int u, int parent) {
            dfn[u] = low[u] = ++timestamp;
            
            for (int v : adj[u]) {
                if (v == parent) continue;  // 跳过父节点，避免误判
                
                if (dfn[v] == 0) {  // v未访问，树边
                    tarjan(v, u);
                    low[u] = min(low[u], low[v]);
                    
                    // 关键判断：如果v能到达的最小dfn > u的dfn，说明v无法回到u或u的祖先
                    // 则边(u,v)是桥
                    if (low[v] > dfn[u]) {
                        result.push_back({u, v});
                    }
                } else {  // v已访问，回边
                    low[u] = min(low[u], dfn[v]);
                }
            }
        };
        
        // 图可能不连通，遍历所有节点
        for (int i = 0; i < n; i++) {
            if (dfn[i] == 0) {
                tarjan(i, -1);
            }
        }
        
        return result;
    }
};
```

## Python实现

```python
class Solution:
    def criticalConnections(self, n: int, connections: List[List[int]]) -> List[List[int]]:
        # 构建无向图
        adj = [[] for _ in range(n)]
        for u, v in connections:
            adj[u].append(v)
            adj[v].append(u)
        
        dfn = [0] * n  # DFS序号
        low = [0] * n  # 能回溯到的最小dfn
        timestamp = 0
        result = []
        
        def tarjan(u, parent):
            nonlocal timestamp
            timestamp += 1
            dfn[u] = low[u] = timestamp
            
            for v in adj[u]:
                if v == parent:
                    continue  # 跳过父节点
                
                if dfn[v] == 0:  # 树边
                    tarjan(v, u)
                    low[u] = min(low[u], low[v])
                    
                    # 判断桥
                    if low[v] > dfn[u]:
                        result.append([u, v])
                else:  # 回边
                    low[u] = min(low[u], dfn[v])
        
        for i in range(n):
            if dfn[i] == 0:
                tarjan(i, -1)
        
        return result
```

## 复杂度分析

- **时间复杂度**: O(n + m)
  - 每个节点访问一次，每条边遍历两次（无向图）
  
- **空间复杂度**: O(n + m)
  - 邻接表存储: O(n + m)
  - 递归栈: O(n)

## 与有向图SCC的对比

| 特性 | 无向图桥 | 有向图SCC |
|------|----------|-----------|
| **目标** | 找删除后图不连通的边 | 找互相可达的节点集合 |
| **判断条件** | low[v] > dfn[u] | low[v] >= dfn[u] |
| **边类型** | 树边+回边 | 树边+回边+横叉边+前向边 |
| **父节点处理** | 跳过父节点 | 无需特殊处理 |

```python
import networkx as nx
import torch

def network_robustness_analysis(edge_list, n):
    """
    分析网络的关键连接（桥）
    用于评估网络鲁棒性和识别关键链路
    """
    G = nx.Graph()
    G.add_edges_from(edge_list)
    
    # 找到所有桥
    bridges = list(nx.bridges(G))
    
    # 计算移除桥后的连通分量数
    G.remove_edges_from(bridges)
    num_components = nx.number_connected_components(G)
    
    return {
        'bridges': bridges,
        'num_bridges': len(bridges),
        'num_components_after_removal': num_components,
        'robustness_score': 1 - len(bridges) / len(edge_list)
    }
```

## 面试模拟问答

**Q: 如何判断一条边是否是桥？**
A: 对于DFS树边(u,v)，如果v不能通过回边到达u或u的祖先（即low[v] > dfn[u]），则(u,v)是桥。

**Q: 为什么要跳过父节点？**
A: 无向图中(u,v)和(v,u)是同一条边。如果不跳过父节点，会从v回到u，形成假的回边，导致low[v] <= dfn[u]，误判为非桥。
