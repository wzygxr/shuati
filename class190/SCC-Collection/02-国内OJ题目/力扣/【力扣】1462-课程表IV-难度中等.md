# 【力扣】1462 - 课程表 IV

## 题目信息

- **题目链接**: https://leetcode.cn/problems/course-schedule-iv/
- **难度**: 中等
- **算法标签**: 拓扑排序、Floyd、传递闭包、强连通分量

## 题目描述

你总共需要上 `numCourses` 门课，它们分别编号为 `0` 到 `numCourses-1`。

给你一个数组 `prerequisites` ，其中 `prerequisites[i] = [ai, bi]` ，表示在选修课程 `ai` 前必须先选修 `bi` 。

另给你一个数组 `queries` ，其中 `queries[j] = [uj, vj]`。对于第 `j` 个查询，请判断课程 `uj` 是否是课程 `vj` 的先修课程。

返回一个布尔数组作为答案，第 `j` 个查询的答案为 `true` 当且仅当 `uj` 是 `vj` 的先修课程。

## 输入输出格式

### 示例
输入: numCourses = 2, prerequisites = [[1,0]], queries = [[0,1],[1,0]]
输出: [false,true]
解释: 课程 0 不是课程 1 的先修课程，但课程 1 是课程 0 的先修课程。

### 数据范围
- $2 \leq numCourses \leq 100$
- $0 \leq prerequisites.length \leq (numCourses * (numCourses - 1) / 2)$
- $prerequisites[i].length == 2$
- $0 \leq ai, bi \leq n - 1$
- $ai != bi$

## 笔试/面试考察点分析

### 核心考察点
1. **传递闭包**：判断节点间是否存在路径
2. **Floyd算法**：多源最短路的变体应用
3. **拓扑排序+DFS**：替代方案

### 面试口述要点
- 这是一个**传递闭包**问题：判断u是否能到达v
- 数据范围小(n≤100)，可以用Floyd或DFS预处理所有可达性
- SCC思想：虽然本题不需要显式求SCC，但理解SCC有助于优化（同一SCC内的点互相可达）

## 解题思路

### 方法一：Floyd传递闭包（推荐）
使用Floyd-Warshall算法的思想，预处理所有点对之间的可达性。

### 方法二：拓扑排序+记忆化搜索
对每个查询单独DFS，或使用拓扑排序预处理。

### 方法三：SCC缩点优化（进阶）
- 先求SCC，将图缩成DAG
- 在DAG上进行拓扑排序+DP预处理可达性
- 同一SCC内的点互相可达

## 完整代码实现

### 方法一：Floyd传递闭包

```cpp
class Solution {
public:
    vector<bool> checkIfPrerequisite(int numCourses, vector<vector<int>>& prerequisites, vector<vector<int>>& queries) {
        // reach[i][j] = true 表示i是j的先修课程（i可以到达j）
        vector<vector<bool>> reach(numCourses, vector<bool>(numCourses, false));
        
        // 初始化：直接先修关系
        for (auto& pre : prerequisites) {
            int u = pre[0], v = pre[1];
            reach[u][v] = true;  // u->v有边
        }
        
        // Floyd传递闭包
        // 面试重点：解释三重循环的含义
        // k是中间点，i是起点，j是终点
        // 如果i能到k，k能到j，则i能到j
        for (int k = 0; k < numCourses; k++) {
            for (int i = 0; i < numCourses; i++) {
                for (int j = 0; j < numCourses; j++) {
                    // 传递性：i->k且k->j，则i->j
                    if (reach[i][k] && reach[k][j]) {
                        reach[i][j] = true;
                    }
                }
            }
        }
        
        // 回答查询
        vector<bool> ans;
        for (auto& q : queries) {
            int u = q[0], v = q[1];
            ans.push_back(reach[u][v]);
        }
        
        return ans;
    }
};
```

### 方法二：拓扑排序+SCC优化（进阶）

```cpp
class Solution {
public:
    vector<vector<int>> adj;       // 原图邻接表
    vector<vector<int>> adj_dag;   // 缩点后DAG
    vector<int> dfn, low;
    vector<bool> in_stack;
    stack<int> st;
    int timestamp = 0, scc_cnt = 0;
    vector<int> scc_id;
    vector<vector<bool>> scc_reach; // SCC间的可达性
    
    // Tarjan求SCC
    void tarjan(int u) {
        dfn[u] = low[u] = ++timestamp;
        st.push(u);
        in_stack[u] = true;
        
        for (int v : adj[u]) {
            if (!dfn[v]) {
                tarjan(v);
                low[u] = min(low[u], low[v]);
            } else if (in_stack[v]) {
                low[u] = min(low[u], dfn[v]);
            }
        }
        
        if (dfn[u] == low[u]) {
            scc_cnt++;
            int v;
            do {
                v = st.top(); st.pop();
                in_stack[v] = false;
                scc_id[v] = scc_cnt - 1;  // 0-indexed
            } while (v != u);
        }
    }
    
    // 缩点
    void shrink(int n) {
        adj_dag.resize(scc_cnt);
        for (int u = 0; u < n; u++) {
            for (int v : adj[u]) {
                if (scc_id[u] != scc_id[v]) {
                    adj_dag[scc_id[u]].push_back(scc_id[v]);
                }
            }
        }
    }
    
    // DAG上DFS预处理可达性
    void dfs(int u, vector<bool>& vis) {
        vis[u] = true;
        for (int v : adj_dag[u]) {
            if (!vis[v]) dfs(v, vis);
        }
    }
    
    vector<bool> checkIfPrerequisite(int numCourses, vector<vector<int>>& prerequisites, vector<vector<int>>& queries) {
        adj.resize(numCourses);
        for (auto& pre : prerequisites) {
            adj[pre[0]].push_back(pre[1]);
        }
        
        // 初始化Tarjan数组
        dfn.resize(numCourses);
        low.resize(numCourses);
        in_stack.resize(numCourses);
        scc_id.resize(numCourses);
        
        // 求SCC
        for (int i = 0; i < numCourses; i++) {
            if (!dfn[i]) tarjan(i);
        }
        
        // 缩点
        shrink(numCourses);
        
        // 预处理每个SCC能到达的所有SCC
        scc_reach.resize(scc_cnt, vector<bool>(scc_cnt, false));
        for (int i = 0; i < scc_cnt; i++) {
            vector<bool> vis(scc_cnt, false);
            dfs(i, vis);
            for (int j = 0; j < scc_cnt; j++) {
                scc_reach[i][j] = vis[j];
            }
        }
        
        // 回答查询
        vector<bool> ans;
        for (auto& q : queries) {
            int u = scc_id[q[0]], v = scc_id[q[1]];
            // 同一SCC或u能到达v
            ans.push_back(u == v || scc_reach[u][v]);
        }
        
        return ans;
    }
};
```

## 复杂度分析

### 方法一：Floyd
- **时间复杂度**：$O(n^3 + q)$，n为课程数，q为查询数
- **空间复杂度**：$O(n^2)$

### 方法二：SCC+拓扑
- **时间复杂度**：$O(n + m + scc_cnt^2 + q)$
- **空间复杂度**：$O(n + m + scc_cnt^2)$
- **适用场景**：原图存在大量SCC时更高效

## 笔试面试高频问题

**Q1: Floyd和DFS预处理各有什么优劣？**
> Floyd代码简洁，适合稠密图；DFS预处理每个起点，适合稀疏图。面试时根据数据特征选择。

**Q2: 如果numCourses很大(10^5)，怎么处理？**
> 需要求SCC缩点，然后在DAG上用拓扑排序+位运算优化传递闭包。或者对每个查询单独BFS/DFS，配合记忆化。

**Q3: SCC在这个问题中有什么作用？**
> 同一SCC内的课程互相是先修关系，可以压缩处理，降低问题规模。
