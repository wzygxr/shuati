# 【洛谷】P3387 【模板】缩点

## 题目链接
https://www.luogu.com.cn/problem/P3387

## 题目描述
给定一张 $n$ 个点 $m$ 条边的有向图，每个点有一个非负的点权 $a_i$。
如果重复经过一个点，只计算一次点权。
求一条路径，使得经过的点权之和最大。

## 输入格式
第一行两个正整数 $n, m$
第二行 $n$ 个非负整数，表示每个点的点权
接下来 $m$ 行，每行两个正整数 $u, v$，表示一条从 $u$ 到 $v$ 的有向边

## 输出格式
一行一个整数，表示最大点权之和

## 样例输入
```
2 2
1 1
1 2
2 1
```

## 样例输出
```
2
```

## 数据范围
- $1 \leq n \leq 10^4$
- $1 \leq m \leq 10^5$
- $0 \leq a_i \leq 10^3$

## 笔试/面试考察点分析

### 核心考察点
1. **Tarjan算法模板掌握**：需要熟练写出SCC分解代码
2. **缩点技术理解**：将强连通分量收缩为DAG
3. **DAG上DP**：拓扑序+动态规划求最长路
4. **图论建模能力**：将"重复点只算一次"转化为SCC权值和

### 面试口述要点
1. 先解释为什么需要缩点：环上的点可以互相到达，要么都选要么都不选
2. 说明Tarjan算法的核心：dfn和low数组的作用
3. 解释缩点后DAG的性质：无环，可以拓扑排序
4. 说明DP的转移方程：dp[v] = max(dp[v], dp[u] + val[v])

## 解题思路

```
Step 1: 使用Tarjan算法求出所有强连通分量(SCC)
Step 2: 将每个SCC的权值设为内部所有点权之和
Step 3: 缩点：将每个SCC收缩为一个节点，构造DAG
Step 4: 在DAG上进行拓扑排序
Step 5: 按拓扑序DP，求最长路径（最大点权和）
```

## 完整代码实现

```cpp
#include <iostream>
#include <vector>
#include <stack>
#include <queue>
#include <algorithm>
#include <cstring>
using namespace std;

const int MAXN = 10001;
const int MAXM = 100001;

int n, m;
int a[MAXN];
vector<int> adj[MAXN];

// Tarjan相关
int dfn[MAXN], low[MAXN];
int timestamp = 0;
stack<int> stk;
bool in_stack[MAXN];

// SCC相关
int scc_id[MAXN];
int scc_cnt = 0;
int scc_val[MAXN];

// DAG相关
vector<int> dag[MAXN];
int in_deg[MAXN];
int dp[MAXN];

void tarjan(int u) {
    dfn[u] = low[u] = ++timestamp;
    stk.push(u);
    in_stack[u] = true;
    
    for (int v : adj[u]) {
        if (dfn[v] == 0) {
            tarjan(v);
            low[u] = min(low[u], low[v]);
        } else if (in_stack[v]) {
            low[u] = min(low[u], dfn[v]);
        }
    }
    
    if (dfn[u] == low[u]) {
        ++scc_cnt;
        int v;
        do {
            v = stk.top(); stk.pop();
            in_stack[v] = false;
            scc_id[v] = scc_cnt;
            scc_val[scc_cnt] += a[v];
        } while (v != u);
    }
}

void shrink() {
    for (int u = 1; u <= n; u++) {
        for (int v : adj[u]) {
            int su = scc_id[u];
            int sv = scc_id[v];
            if (su != sv) {
                dag[su].push_back(sv);
                in_deg[sv]++;
            }
        }
    }
}

int solve() {
    queue<int> q;
    for (int i = 1; i <= scc_cnt; i++) {
        dp[i] = scc_val[i];
        if (in_deg[i] == 0) q.push(i);
    }
    
    while (!q.empty()) {
        int u = q.front(); q.pop();
        for (int v : dag[u]) {
            dp[v] = max(dp[v], dp[u] + scc_val[v]);
            if (--in_deg[v] == 0) q.push(v);
        }
    }
    
    int ans = 0;
    for (int i = 1; i <= scc_cnt; i++) ans = max(ans, dp[i]);
    return ans;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    cin >> n >> m;
    for (int i = 1; i <= n; i++) cin >> a[i];
    for (int i = 0; i < m; i++) {
        int u, v; cin >> u >> v;
        adj[u].push_back(v);
    }
    
    for (int i = 1; i <= n; i++) if (!dfn[i]) tarjan(i);
    shrink();
    cout << solve() << endl;
    
    return 0;
}
```

## 复杂度分析

- **时间复杂度**: O(n + m)
  - Tarjan: O(n + m)
  - 缩点: O(m)
  - 拓扑DP: O(scc_cnt + dag_edges) = O(n + m)
  
- **空间复杂度**: O(n + m)
  - 原图: O(n + m)
  - Tarjan栈: O(n)
  - DAG: O(n + m)
