# 【洛谷】P2341 - 牛奶分配

## 题目信息

- **题目链接**: https://www.luogu.com.cn/problem/P2341
- **难度**: 提高+/省选-
- **算法标签**: 强连通分量、缩点、图论

## 题目描述

有一个n个点m条边的有向图，每个点有一个权值（出度）。求从哪些点出发可以到达所有的点。

## 输入输出格式

### 输入格式
第一行两个整数n,m，表示点数和边数
接下来m行，每行两个整数a,b，表示a到b有一条有向边

### 输出格式
输出一行，表示满足条件的点的数量

### 数据范围
- $1 \leq n \leq 10000$
- $1 \leq m \leq 50000$

## 笔试/面试考察点分析

### 核心考察点
1. **缩点核心理解**：缩点后入度为0的SCC是关键
2. **图论建模能力**：将"能到达所有点"转化为"缩点后入度为0的SCC个数"
3. **边界情况处理**：缩点后如果只有一个SCC，则该SCC内所有点都满足条件

### 面试口述要点
- 首先对原图进行缩点，得到DAG
- 在DAG中，只有入度为0的点才能到达所有点（因为没有点能到达它）
- 如果DAG中有多个入度为0的点，则不存在满足条件的点
- 统计入度为0的SCC的节点数即为答案

## 解题思路

### 步骤1：求强连通分量（Tarjan算法）
使用Tarjan算法找出所有强连通分量，给每个节点标记所属SCC。

### 步骤2：缩点构建DAG
将每个SCC缩成一个点，构建缩点后的图（DAG）。

### 步骤3：统计入度为0的SCC
- 如果缩点后只有一个SCC，则该SCC内所有点都可以到达所有点
- 如果有多个入度为0的SCC，则不存在满足条件的点（因为这些SCC互相不可达）
- 如果只有一个入度为0的SCC，则该SCC的大小就是答案

## 完整代码实现

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 10005;      // 最大节点数，根据数据范围设定
const int MAXM = 50005;      // 最大边数

// 原图邻接表
vector<int> adj[MAXN];       // adj[u]存储u的所有出边指向的节点
// 缩点后的图
vector<int> dag[MAXN];       // dag[i]存储缩点后的边

// Tarjan算法相关数组
int dfn[MAXN];               // dfn[u]: 节点u的访问时间戳
int low[MAXN];               // low[u]: 从u出发能到达的最小时间戳
int timestamp = 0;           // 全局时间戳计数器
stack<int> st;               // 存储当前DFS路径上的节点
bool in_stack[MAXN];         // in_stack[u]: 标记u是否在栈中

// SCC相关
int scc_id[MAXN];            // scc_id[u]: 节点u所属的SCC编号
int scc_size[MAXN];          // scc_size[i]: 第i个SCC的节点数量
int scc_cnt = 0;             // SCC的总数量

// DAG相关
int in_deg[MAXN];            // in_deg[i]: 缩点后第i个SCC的入度

/**
 * Tarjan算法求强连通分量
 * 
 * 核心思想：
 * - dfn记录节点被访问的顺序
 * - low记录从当前节点能回溯到的最早节点
 * - 当dfn[u]==low[u]时，说明u是一个SCC的根
 * 
 * 面试重点：解释为什么dfn[u]==low[u]时找到SCC
 * 因为这说明u无法回溯到更早的节点，u及其栈中上方的节点构成SCC
 * 
 * @param u 当前访问的节点
 */
void tarjan(int u) {
    // 初始化当前节点的dfn和low为当前时间戳
    dfn[u] = low[u] = ++timestamp;
    
    // 将当前节点压入栈中
    st.push(u);
    in_stack[u] = true;      // 标记u在栈中
    
    // 遍历u的所有邻接节点
    for (int v : adj[u]) {
        if (!dfn[v]) {        // 如果v未被访问过
            tarjan(v);        // 递归访问v
            // 回溯：用v的low更新u的low
            // 因为u可以到达v，所以u也能到达v能到达的最早节点
            low[u] = min(low[u], low[v]);
        } else if (in_stack[v]) {
            // v已访问且在栈中，说明v在当前DFS路径上
            // 形成环，更新low[u]
            low[u] = min(low[u], dfn[v]);
        }
        // 注意：如果v已访问但不在栈中，说明v属于其他SCC，不处理
    }
    
    // 如果dfn[u]==low[u]，说明u是SCC的根节点
    if (dfn[u] == low[u]) {
        scc_cnt++;            // SCC计数+1
        int v;
        do {
            v = st.top();     // 取栈顶元素
            st.pop();         // 出栈
            in_stack[v] = false;  // 标记不在栈中
            scc_id[v] = scc_cnt;  // 记录v属于第scc_cnt个SCC
            scc_size[scc_cnt]++;  // 该SCC的节点数+1
        } while (v != u);     // 直到u出栈，整个SCC处理完毕
    }
}

/**
 * 缩点函数：将原图缩成DAG
 * 
 * 缩点逻辑：
 * - 遍历原图的每条边(u,v)
 * - 如果scc_id[u]!=scc_id[v]，则在DAG中添加边
 * 
 * ML/DL应用：
 * - 图结构简化，减少GNN计算量
 * - 保留拓扑结构的同时降低节点数
 */
void shrink(int n) {
    // 遍历原图的所有边
    for (int u = 1; u <= n; u++) {
        for (int v : adj[u]) {
            // 如果u和v属于不同的SCC，则在DAG中添加边
            if (scc_id[u] != scc_id[v]) {
                dag[scc_id[u]].push_back(scc_id[v]);
                in_deg[scc_id[v]]++;  // v所在SCC的入度+1
            }
        }
    }
}

int main() {
    ios::sync_with_stdio(false);  // 关闭同步，加速IO
    cin.tie(nullptr);             // 解除cin和cout的绑定
    
    int n, m;                     // n:节点数，m:边数
    cin >> n >> m;
    
    // 读入m条边，构建原图
    for (int i = 0; i < m; i++) {
        int u, v;
        cin >> u >> v;
        adj[u].push_back(v);      // 添加有向边u->v
    }
    
    // 初始化数组
    memset(dfn, 0, sizeof(dfn));
    memset(low, 0, sizeof(low));
    memset(in_stack, false, sizeof(in_stack));
    memset(scc_size, 0, sizeof(scc_size));
    memset(in_deg, 0, sizeof(in_deg));
    
    // 对每个未访问的节点执行Tarjan算法
    for (int i = 1; i <= n; i++) {
        if (!dfn[i]) {
            tarjan(i);
        }
    }
    
    // 缩点构建DAG
    shrink(n);
    
    // 统计入度为0的SCC
    int zero_in_deg = 0;          // 入度为0的SCC数量
    int ans_scc = 0;              // 入度为0的SCC编号
    
    for (int i = 1; i <= scc_cnt; i++) {
        if (in_deg[i] == 0) {
            zero_in_deg++;
            ans_scc = i;          // 记录入度为0的SCC编号
        }
    }
    
    // 判断结果
    if (zero_in_deg == 1) {
        // 只有一个入度为0的SCC，该SCC内所有点都能到达所有点
        cout << scc_size[ans_scc] << endl;
    } else {
        // 有多个入度为0的SCC，不存在满足条件的点
        cout << 0 << endl;
    }
    
    return 0;
}
```

## 复杂度分析

### 时间复杂度
- **Tarjan算法**：$O(V + E)$，每个节点和边只被访问一次
- **缩点**：$O(V + E)$，遍历所有边
- **总复杂度**：$O(V + E) = O(n + m)$

### 空间复杂度
- **邻接表**：$O(V + E)$
- **Tarjan栈**：$O(V)$
- **其他数组**：$O(V)$
- **总复杂度**：$O(V + E) = O(n + m)$

## 笔试面试高频问题

**Q1: 为什么入度为0的SCC中的点能到达所有点？**
> 缩点后得到DAG，在DAG中只有入度为0的点无法被其他点到达。如果存在多个入度为0的点，它们之间互相不可达。只有当DAG只有一个入度为0的点时，从该点出发才能到达所有点。

**Q2: 如果题目改为"能到达所有点的点"，解法有变化吗？**
> 有变化。需要找缩点后出度为0的SCC。类似地，只有唯一的出度为0的SCC才能被所有点到达。

**Q3: Tarjan算法中，为什么low[u]要用dfn[v]更新而不是low[v]？**
> 当v在栈中时，用dfn[v]更新可以直接反映v的发现时间。如果用low[v]，可能会包含v的子树中不属于当前SCC的节点，导致错误。
