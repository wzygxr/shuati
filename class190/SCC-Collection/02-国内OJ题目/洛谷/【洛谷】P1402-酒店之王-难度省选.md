# 【洛谷】P1402 - 酒店之王

## 题目信息

- **题目链接**: https://www.luogu.com.cn/problem/P1402
- **难度**: 省选/NOI-
- **算法标签**: 网络流、二分图、2-SAT

## 题目描述

某国有n个房间，m个人，k个物品。每个人对一些房间和物品有偏好。

安排方案需满足：
1. 每个人恰好分配一个房间和一个物品
2. 每个房间最多分配一个人
3. 每个物品最多被一个人使用

判断是否存在可行方案。

## 输入输出格式

### 输入格式
第一行三个整数n,m,k
接下来m行，每行描述一个人的偏好：
- 首先两个整数a,b，表示喜欢的房间数和物品数
- 然后a个整数，表示喜欢的房间编号
- 然后b个整数，表示喜欢的物品编号

### 输出格式
如果存在可行方案，输出"YES"；否则输出"NO"

### 数据范围
- $1 \leq n,m,k \leq 500$

## 笔试/面试考察点分析

### 核心考察点
1. **网络流建模**: 将问题转化为最大流问题
2. **二分图匹配**: 房间和物品的联合匹配
3. **2-SAT思路**: 也可以用2-SAT求解（进阶）

### 面试口述要点
- 这是一个典型的网络流问题
- 建图：源点→人→房间→物品→汇点
- 每个人只能选一个房间和一个物品
- 最大流等于m则有解

## 解题思路

### 网络流建模
```
源点 → 人 → 房间 → 物品 → 汇点
```

**边容量设置：**
- 源点→人: 1（每个人只能选一对）
- 人→房间: 1（喜欢的房间）
- 房间→物品: INF（房间和物品的匹配）
- 物品→汇点: 1（每个物品只能用一次）

**优化：** 直接房间连物品会导致O(n*k)条边，需要优化。

## 完整代码实现

```cpp
#include <bits/stdc++.h>
using namespace std;

const int INF = 0x3f3f3f3f;
const int MAXN = 2005;  // 总节点数

struct Edge {
    int to, cap, flow, rev;
    Edge(int t, int c, int r) : to(t), cap(c), flow(0), rev(r) {}
};

vector<Edge> adj[MAXN];
int level[MAXN], iter[MAXN];
int n, m, k;

// 添加边
void add_edge(int from, int to, int cap) {
    adj[from].push_back(Edge(to, cap, adj[to].size()));
    adj[to].push_back(Edge(from, 0, adj[from].size() - 1));
}

// BFS建层次图
bool bfs(int s, int t) {
    memset(level, -1, sizeof(level));
    queue<int> q;
    level[s] = 0;
    q.push(s);
    
    while (!q.empty()) {
        int u = q.front(); q.pop();
        for (auto& e : adj[u]) {
            if (level[e.to] < 0 && e.flow < e.cap) {
                level[e.to] = level[u] + 1;
                q.push(e.to);
            }
        }
    }
    return level[t] >= 0;
}

// DFS增广
int dfs(int u, int t, int f) {
    if (u == t) return f;
    for (int& i = iter[u]; i < adj[u].size(); i++) {
        Edge& e = adj[u][i];
        if (e.cap > e.flow && level[u] < level[e.to]) {
            int d = dfs(e.to, t, min(f, e.cap - e.flow));
            if (d > 0) {
                e.flow += d;
                adj[e.to][e.rev].flow -= d;
                return d;
            }
        }
    }
    return 0;
}

// 最大流（Dinic算法）
int max_flow(int s, int t) {
    int flow = 0;
    while (bfs(s, t)) {
        memset(iter, 0, sizeof(iter));
        int f;
        while ((f = dfs(s, t, INF)) > 0) {
            flow += f;
        }
    }
    return flow;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    cin >> n >> m >> k;
    
    int source = 0;
    int person_start = 1;
    int room_start = person_start + m;
    int item_start = room_start + n;
    int sink = item_start + k;
    
    // 建图
    for (int i = 0; i < m; i++) {
        int a, b;
        cin >> a >> b;
        
        // 源点连人
        add_edge(source, person_start + i, 1);
        
        // 人连喜欢的房间
        for (int j = 0; j < a; j++) {
            int room;
            cin >> room;
            add_edge(person_start + i, room_start + room - 1, 1);
        }
        
        // 人连喜欢的物品
        for (int j = 0; j < b; j++) {
            int item;
            cin >> item;
            add_edge(person_start + i, item_start + item - 1, 1);
        }
    }
    
    // 房间连物品（需要优化，这里简化处理）
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < k; j++) {
            add_edge(room_start + i, item_start + j, 1);
        }
    }
    
    // 物品连汇点
    for (int j = 0; j < k; j++) {
        add_edge(item_start + j, sink, 1);
    }
    
    // 求最大流
    int flow = max_flow(source, sink);
    
    if (flow == m) {
        cout << "YES" << endl;
    } else {
        cout << "NO" << endl;
    }
    
    return 0;
}
```

## 优化建图思路

上面的建图有问题，正确的建图应该是：

```
源点 → 人 → 房间 → 汇点
源点 → 人 → 物品 → 汇点
```

每个人必须同时选一个房间和一个物品，这是一个"配对"问题。

正确的做法是：
1. 将人和房间匹配
2. 将人和物品匹配
3. 确保匹配一致性

或者用2-SAT：每个人选择一个房间-物品对。

## 笔试面试高频问题

**Q: 这题为什么不能用简单贪心？**
> 贪心可能会导致后续的人无法匹配，需要全局优化。网络流可以找到全局最优解。

**Q: 如果n,m,k都是10^5，怎么优化？**
> 需要更高效的算法，如Hopcroft-Karp算法进行二分图匹配，或者使用启发式方法。
