# 【PTA】7-10 - 关键活动（AOE网关键路径）

## 题目信息

- **题目链接**: https://pintia.cn/problem-sets/16/problems/681
- **难度**: 困难
- **算法标签**: 拓扑排序、关键路径、强连通分量

## 题目描述

假定一个AOE网（Activity On Edge network），求其中的关键活动。

AOE网是一个带权有向无环图，其中：
- 顶点表示事件
- 有向边表示活动
- 边上的权值表示活动持续时间

关键活动是指：如果该活动延期，会导致整个工程延期。

## 输入输出格式

### 输入格式
第一行两个整数n,m，表示顶点数和边数
接下来m行，每行u,v,w，表示活动从u到v，持续时间为w

### 输出格式
输出所有关键活动，按起点从小到大，起点相同按终点从小到大

### 数据范围
- $1 \leq n \leq 100$
- $1 \leq m \leq 500$

## 笔试/面试考察点分析

### 核心考察点
1. **关键路径算法**：ve（最早发生时间）和vl（最晚发生时间）
2. **拓扑排序**：计算ve需要拓扑序
3. **逆拓扑排序**：计算vl需要逆拓扑序
4. **SCC检测**：确保图是DAG（无环）

### 面试口述要点
- 首先检查图是否为DAG（可用SCC或拓扑排序检测）
- 关键路径 = 最长路径
- ve[j] = max(ve[i] + w(i,j))，需要拓扑序
- vl[i] = min(vl[j] - w(i,j))，需要逆拓扑序
- 关键活动：e(i)=l(i)的活动

## 解题思路

### 关键路径算法步骤
1. **拓扑排序**：检查是否有环，同时得到拓扑序
2. **计算ve**：从源点出发，按拓扑序计算每个事件的最早发生时间
3. **计算vl**：从汇点出发，按逆拓扑序计算每个事件的最晚发生时间
4. **找关键活动**：e(i) == l(i)的活动

### SCC的作用
- 如果图中有环，则不存在关键路径（或需要特殊处理）
- 可用SCC检测环，或拓扑排序时检测环

## 完整代码实现

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 105;
const int INF = 0x3f3f3f3f;

struct Edge {
    int to, w;
    Edge(int t, int weight) : to(t), w(weight) {}
};

vector<Edge> adj[MAXN];      // 邻接表
vector<Edge> radj[MAXN];     // 逆邻接表

int in_deg[MAXN];            // 入度
int ve[MAXN], vl[MAXN];      // 最早/最晚发生时间
vector<int> topo_order;      // 拓扑序

int n, m;

/**
 * 拓扑排序（Kahn算法）
 * 
 * 同时检测环：如果排序后节点数<n，说明有环
 * 
 * @return 是否有环
 */
bool topological_sort() {
    queue<int> q;
    
    // 入度为0的节点入队
    for (int i = 0; i < n; i++) {
        if (in_deg[i] == 0) {
            q.push(i);
        }
    }
    
    while (!q.empty()) {
        int u = q.front(); q.pop();
        topo_order.push_back(u);
        
        for (auto& e : adj[u]) {
            int v = e.to;
            in_deg[v]--;
            if (in_deg[v] == 0) {
                q.push(v);
            }
        }
    }
    
    // 如果拓扑序节点数<n，说明有环
    return topo_order.size() == n;
}

/**
 * 计算关键路径
 * 
 * 步骤：
 * 1. 拓扑排序
 * 2. 计算ve（最早发生时间）
 * 3. 计算vl（最晚发生时间）
 * 4. 找出关键活动
 */
void critical_path() {
    // 步骤1：拓扑排序
    if (!topological_sort()) {
        cout << "图中有环，不存在关键路径" << endl;
        return;
    }
    
    // 步骤2：计算ve（最早发生时间）
    // ve[j] = max(ve[i] + w(i,j))
    memset(ve, 0, sizeof(ve));
    for (int u : topo_order) {
        for (auto& e : adj[u]) {
            int v = e.to, w = e.w;
            if (ve[u] + w > ve[v]) {
                ve[v] = ve[u] + w;
            }
        }
    }
    
    // 找到汇点（ve最大的点）
    int max_ve = 0;
    for (int i = 0; i < n; i++) {
        max_ve = max(max_ve, ve[i]);
    }
    
    // 步骤3：计算vl（最晚发生时间）
    // vl[i] = min(vl[j] - w(i,j))
    // 初始化：汇点的vl = ve，其他为INF
    for (int i = 0; i < n; i++) {
        vl[i] = max_ve;
    }
    
    // 逆拓扑序计算vl
    for (int i = topo_order.size() - 1; i >= 0; i--) {
        int u = topo_order[i];
        for (auto& e : adj[u]) {
            int v = e.to, w = e.w;
            if (vl[v] - w < vl[u]) {
                vl[u] = vl[v] - w;
            }
        }
    }
    
    // 步骤4：找出关键活动
    // 活动<k>：从u到v，持续时间w
    // e(k) = ve[u]（最早开始时间）
    // l(k) = vl[v] - w（最晚开始时间）
    // 关键活动：e(k) == l(k)
    
    vector<pair<int, int>> critical_activities;
    
    for (int u = 0; u < n; u++) {
        for (auto& e : adj[u]) {
            int v = e.to, w = e.w;
            int ek = ve[u];          // 最早开始时间
            int lk = vl[v] - w;      // 最晚开始时间
            
            if (ek == lk) {
                // 是关键活动
                critical_activities.push_back({u, v});
            }
        }
    }
    
    // 输出关键活动
    sort(critical_activities.begin(), critical_activities.end());
    for (auto& act : critical_activities) {
        cout << act.first << "->" << act.second << endl;
    }
}

int main() {
    cin >> n >> m;
    
    for (int i = 0; i < m; i++) {
        int u, v, w;
        cin >> u >> v >> w;
        adj[u].push_back(Edge(v, w));
        radj[v].push_back(Edge(u, w));  // 建逆图
        in_deg[v]++;
    }
    
    critical_path();
    
    return 0;
}
```

## 复杂度分析

| 步骤 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 拓扑排序 | $O(V + E)$ | $O(V)$ |
| 计算ve | $O(V + E)$ | $O(V)$ |
| 计算vl | $O(V + E)$ | $O(V)$ |
| 找关键活动 | $O(E)$ | $O(E)$ |
| 总体 | $O(V + E)$ | $O(V + E)$ |

## 笔试面试高频问题

**Q1: 为什么AOE网必须是无环的？**
> 如果存在环，活动会循环依赖，无法确定完成时间。关键路径算法要求图是DAG。

**Q2: 如何检测环？**
> 可以用拓扑排序（Kahn算法），如果最终入队节点数<n则有环；也可以用Tarjan求SCC，SCC大小>1说明有环。

**Q3: ve和vl的递推公式为什么是这样？**
> ve是"最早"，所以取max；vl是"最晚"，所以取min。这是为了保证关键路径上的活动不能延期。
