# 【牛客网】有向图强连通分量 - 模板题

## 题目信息

- **题目链接**: https://www.nowcoder.com/practice/e9470f2897af440cb91bc09fdea1a3c2
- **难度**: 中等
- **算法标签**: 图论、强连通分量、Tarjan算法

## 题目描述

给定一个有向图，图中可能存在重边和自环，请输出图中强连通分量的数量以及每个强连通分量包含的节点。

## 输入输出格式

### 输入格式
第一行两个整数n,m，表示图的点数和边数
接下来m行，每行两个整数u,v，表示u到v有一条有向边

### 输出格式
第一行输出强连通分量的数量
接下来每行输出一个强连通分量包含的所有节点，节点编号从小到大输出

### 数据范围
- $1 \leq n \leq 20000$
- $1 \leq m \leq 100000$

### 核心考察点

2. **重边和自环处理**：需要正确处理特殊情况
3. **结果格式化输出**：按要求输出每个SCC的节点

### 面试口述要点
- 这是SCC的基础模板题，重点在于算法的正确实现
- 强调dfn和low数组的作用
- 解释出栈时如何标记整个SCC

## 解题思路

### 标准Tarjan算法流程
1. 初始化时间戳和栈
2. DFS遍历每个未访问节点
3. 更新dfn和low值
4. 当dfn[u]==low[u]时，出栈标记SCC

### 重边和自环处理
- **重边**：不影响SCC的正确性，无需特殊处理
- **自环**：节点与自身构成环，属于SCC的一部分，无需特殊处理

## 完整代码实现

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 20005;      // 最大节点数
const int MAXM = 100005;     // 最大边数

// 图结构
vector<int> adj[MAXN];       // 邻接表

// Tarjan算法
int dfn[MAXN];               // 访问时间戳
int low[MAXN];               // 能回溯到的最早时间戳
int timestamp = 0;           // 时间戳计数器
stack<int> st;               // DFS栈
bool in_stack[MAXN];         // 是否在栈中

// SCC结果
int scc_id[MAXN];            // 节点所属SCC编号
int scc_cnt = 0;             // SCC总数
vector<vector<int>> scc_nodes; // 存储每个SCC包含的节点

/**
 * Tarjan算法求强连通分量
 * 
 * 核心逻辑：
 * 1. 初始化dfn[u]和low[u]为当前时间戳
 * 2. 将u压入栈中
 * 3. 遍历u的所有邻接节点v
 *    - 如果v未访问，递归访问，回溯更新low[u]
 *    - 如果v在栈中，用dfn[v]更新low[u]
 * 4. 如果dfn[u]==low[u]，说明u是SCC的根，出栈标记整个SCC
 * 
 * @param u 当前节点
 */
void tarjan(int u) {
    // 步骤1：初始化时间戳
    dfn[u] = low[u] = ++timestamp;
    
    // 步骤2：入栈
    st.push(u);
    in_stack[u] = true;
    
    // 步骤3：遍历邻接节点
    for (int v : adj[u]) {
        if (!dfn[v]) {
            // v未访问，递归DFS
            tarjan(v);
            // 回溯：更新low[u]
            // 原理：u可以到达v，所以u能到达的最早节点至少是v能到达的最早节点
            low[u] = min(low[u], low[v]);
        } else if (in_stack[v]) {
            // v已访问且在栈中，说明v在当前DFS路径上
            // 形成环，用v的发现时间更新low[u]
            low[u] = min(low[u], dfn[v]);
        }
        // 注意：如果v已访问但不在栈中，说明v已属于其他SCC，不处理
    }
    
    // 步骤4：判断是否为SCC根节点
    if (dfn[u] == low[u]) {
        // u是SCC的根，开始出栈
        scc_cnt++;
        vector<int> nodes;    // 存储当前SCC的所有节点
        int v;
        
        do {
            v = st.top();     // 取栈顶
            st.pop();         // 出栈
            in_stack[v] = false;  // 标记不在栈中
            scc_id[v] = scc_cnt;  // 记录所属SCC
            nodes.push_back(v);   // 记录节点
        } while (v != u);     // 直到u出栈
        
        // 对节点排序，按要求输出
        sort(nodes.begin(), nodes.end());
        scc_nodes.push_back(nodes);
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int n, m;
    cin >> n >> m;
    
    // 读入边（可能存在重边和自环）
    for (int i = 0; i < m; i++) {
        int u, v;
        cin >> u >> v;
        adj[u].push_back(v);  // 添加有向边
    }
    
    // 初始化数组
    memset(dfn, 0, sizeof(dfn));
    memset(low, 0, sizeof(low));
    memset(in_stack, false, sizeof(in_stack));
    
    // 对每个未访问节点执行Tarjan
    for (int i = 1; i <= n; i++) {
        if (!dfn[i]) {
            tarjan(i);
        }
    }
    
    // 输出结果
    cout << scc_cnt << endl;
    
    // 按SCC编号排序输出（可选，根据题目要求）
    for (int i = 0; i < scc_nodes.size(); i++) {
        for (int j = 0; j < scc_nodes[i].size(); j++) {
            if (j > 0) cout << " ";
            cout << scc_nodes[i][j];
        }
        cout << endl;
    }
    
    return 0;
}
```

| 操作 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| Tarjan算法 | $O(V + E)$ | $O(V)$ |
| 结果排序 | $O(V \log V)$ | $O(V)$ |
| 总体 | $O(V + E + V \log V)$ | $O(V + E)$ |

## 笔试面试高频问题

**Q1: 如何处理重边和自环？**
> Tarjan算法天然支持重边和自环。重边不影响SCC的识别；自环会使节点dfn=low，单独成为一个SCC（如果无其他边）。

**Q2: 时间复杂度为什么是O(V+E)？**
> 每个节点被访问一次，每条边被遍历一次，栈操作是O(1)，所以总体是线性。

**Q3: 如果图有10^6个节点，Tarjan算法还能用吗？**
> 可以，但需要优化：1) 使用迭代版避免栈溢出；2) 使用链式前向星代替vector邻接表；3) 注意递归深度限制。
