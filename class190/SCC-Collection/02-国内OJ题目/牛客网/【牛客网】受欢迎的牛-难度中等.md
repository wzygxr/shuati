# 牛客网 - 受欢迎的牛

## 题目链接
https://ac.nowcoder.com/acm/problem/21312

## 题目描述

在一个有向图中，如果存在一个顶点，从该顶点出发可以到达图中所有其他顶点，则称该顶点为"受欢迎的点"。

给定一个有向图，请找出所有的受欢迎的点，并输出它们的数量。

注意：本题中，一个点可以到达自身。

## 输入格式

第一行包含两个整数 N 和 M，表示图的顶点数和边数。

接下来 M 行，每行两个整数 u 和 v，表示从顶点 u 到顶点 v 有一条有向边。

## 输出格式

输出一个整数，表示受欢迎点的数量。如果不存在，输出 0。

## 数据范围

- 1 ≤ N ≤ 10,000
- 1 ≤ M ≤ 50,000

## 样例输入
```
3 3
1 2
2 1
2 3
```

## 样例输出
```
1
```

## 笔试/面试考察点分析

### 核心考察点

1. **强连通分量 + 缩点的综合应用**
   - 这是 SCC 最经典的应用场景之一
   - 笔试中常考的基础题型

2. **汇点性质的理解**
   - 在 DAG 中，只有汇点（出度为 0）才能被所有点到达
   - 这是图论中的基础结论

3. **边界情况处理**
   - 多个汇点的情况
   - 单个节点的情况

### 面试高频问题

```
Q: 为什么只有出度为 0 的 SCC 才能被所有点到达？

A: 在缩点后的 DAG 中，从任意节点出发沿着边走，由于图是有限的且没有环，
    最终一定会到达一个出度为 0 的节点（汇点）。如果有多个汇点，它们之间
    无法互相到达；如果只有一个汇点，则所有路径都终止于它，所以它能被所有
    节点到达。
```

## 解题思路

本题与洛谷 P2341 是同一道题，是 SCC 缩点求汇点的经典应用。

### 算法流程

```
1. 使用 Tarjan 算法求所有强连通分量
2. 缩点，统计每个 SCC 的出度
3. 如果出度为 0 的 SCC 数量为 1，输出其节点数
   否则输出 0
```

## 完整代码实现

### C++ 实现（含详细注释）

```cpp
#include <bits/stdc++.h>
using namespace std;

// maxn: 最大节点数，根据数据范围 N ≤ 10000 设定
const int MAXN = 10005;

// 邻接表存图，vector 数组存储每个节点的出边列表
vector<int> adj[MAXN];

// Tarjan 算法核心数组
int dfn[MAXN];      // 访问时间戳，记录节点首次访问的顺序
int low[MAXN];      // 能回溯到的最小时间戳，用于识别 SCC
int timestamp = 0;  // 全局时间戳计数器

// 节点栈，存储当前 DFS 路径上的节点
stack<int> st;

// 标记数组，in_stack[i] 表示节点 i 是否在栈中
bool in_stack[MAXN];

// SCC 相关数组
int scc_id[MAXN];       // 节点所属 SCC 的编号
int scc_cnt = 0;        // SCC 总数
int scc_size[MAXN];     // 每个 SCC 包含的节点数

/**
 * Tarjan 算法：求强连通分量
 * 
 * 核心思想：
 * - 通过 DFS 遍历图，为每个节点记录 dfn（发现时间）和 low（能到达的最小 dfn）
 * - 当 dfn[u] == low[u] 时，u 是 SCC 的根，栈中从 u 到栈顶的所有节点构成一个 SCC
 * 
 * 时间复杂度：O(V + E)，每个节点和边只访问一次
 * 
 * @param u: 当前访问的节点
 */
void tarjan(int u) {
    // 步骤1：初始化 dfn 和 low
    // 发现新节点时，dfn 和 low 都设为当前时间戳
    dfn[u] = low[u] = ++timestamp;
    
    // 步骤2：当前节点入栈
    // 栈用于保存当前 DFS 路径，便于后续提取 SCC
    st.push(u);
    in_stack[u] = true;
    
    // 步骤3：遍历 u 的所有邻接节点
    for (int v : adj[u]) {
        if (dfn[v] == 0) {
            // 情况A：v 未访问过，递归访问
            tarjan(v);
            // 递归返回后，用 v 的 low 更新 u 的 low
            // 表示 u 可以通过 v 到达的节点，u 也能到达
            low[u] = min(low[u], low[v]);
        } else if (in_stack[v]) {
            // 情况B：v 已访问且在栈中（回边）
            // 说明 v 在当前 DFS 路径上，构成环
            // 用 v 的 dfn 更新 u 的 low
            low[u] = min(low[u], dfn[v]);
        }
        // 情况C：v 已访问但不在栈中（横叉边），忽略
        // v 属于其他 SCC，已经处理完毕
    }
    
    // 步骤4：判断 u 是否为 SCC 的根
    // 当 dfn[u] == low[u] 时，u 无法回溯到更早的节点，是 SCC 的根
    if (dfn[u] == low[u]) {
        scc_cnt++;  // 发现新的 SCC
        int v;
        // 从栈中弹出节点，直到 u 被弹出
        // 这些节点属于同一个 SCC
        do {
            v = st.top();      // 取栈顶
            st.pop();          // 出栈
            in_stack[v] = false;  // 标记不在栈中
            scc_id[v] = scc_cnt;  // 记录所属 SCC
            scc_size[scc_cnt]++;  // SCC 节点数加1
        } while (v != u);  // 直到 u 被弹出
    }
}

int main() {
    ios::sync_with_stdio(false);  // 关闭同步，加速 IO
    cin.tie(nullptr);
    
    int n, m;
    cin >> n >> m;
    
    // 建图：读入 m 条有向边
    for (int i = 0; i < m; i++) {
        int u, v;
        cin >> u >> v;
        adj[u].push_back(v);  // 添加边 u → v
    }
    
    // 初始化数组
    memset(dfn, 0, sizeof(dfn));
    memset(low, 0, sizeof(low));
    memset(in_stack, false, sizeof(in_stack));
    memset(scc_id, 0, sizeof(scc_id));
    memset(scc_size, 0, sizeof(scc_size));
    
    // 对所有未访问节点运行 Tarjan
    for (int i = 1; i <= n; i++) {
        if (dfn[i] == 0) {
            tarjan(i);
        }
    }
    
    // 统计每个 SCC 的出度
    vector<int> outdeg(scc_cnt + 1, 0);
    for (int u = 1; u <= n; u++) {
        for (int v : adj[u]) {
            if (scc_id[u] != scc_id[v]) {
                // 跨 SCC 的边，增加起点的出度
                outdeg[scc_id[u]]++;
            }
        }
    }
    
    // 统计出度为 0 的 SCC 数量和答案
    int zero_out = 0;  // 出度为 0 的 SCC 数量
    int ans = 0;       // 答案（受欢迎点的数量）
    
    for (int i = 1; i <= scc_cnt; i++) {
        if (outdeg[i] == 0) {
            zero_out++;
            ans = scc_size[i];
        }
    }
    
    // 如果有多个出度为 0 的 SCC，不存在受欢迎的点
    if (zero_out != 1) {
        ans = 0;
    }
    
    cout << ans << endl;
    
    return 0;
}
```

### Java 实现

```java
import java.io.*;
import java.util.*;

public class Main {
    // 最大节点数
    static final int MAXN = 10005;
    
    // 邻接表存图
    static List<Integer>[] adj = new ArrayList[MAXN];
    
    // Tarjan 算法数组
    static int[] dfn = new int[MAXN];  // 访问时间戳
    static int[] low = new int[MAXN];  // 能回溯到的最小时间戳
    static int timestamp = 0;          // 时间戳计数器
    
    // 节点栈
    static Stack<Integer> stack = new Stack<>();
    static boolean[] inStack = new boolean[MAXN];  // 标记是否在栈中
    
    // SCC 相关
    static int[] sccId = new int[MAXN];   // 节点所属 SCC
    static int sccCnt = 0;                // SCC 总数
    static int[] sccSize = new int[MAXN]; // 每个 SCC 的节点数
    
    // 静态代码块初始化邻接表
    static {
        for (int i = 0; i < MAXN; i++) {
            adj[i] = new ArrayList<>();
        }
    }
    
    /**
     * Tarjan 算法求强连通分量
     * @param u 当前节点
     */
    static void tarjan(int u) {
        // 初始化时间戳
        dfn[u] = low[u] = ++timestamp;
        
        // 入栈
        stack.push(u);
        inStack[u] = true;
        
        // 遍历邻接节点
        for (int v : adj[u]) {
            if (dfn[v] == 0) {
                // 未访问，递归
                tarjan(v);
                low[u] = Math.min(low[u], low[v]);
            } else if (inStack[v]) {
                // 在栈中，更新 low
                low[u] = Math.min(low[u], dfn[v]);
            }
        }
        
        // 判断是否为 SCC 根
        if (dfn[u] == low[u]) {
            sccCnt++;
            int v;
            do {
                v = stack.pop();
                inStack[v] = false;
                sccId[v] = sccCnt;
                sccSize[sccCnt]++;
            } while (v != u);
        }
    }
    
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        PrintWriter out = new PrintWriter(System.out);
        
        StringTokenizer st = new StringTokenizer(br.readLine());
        int n = Integer.parseInt(st.nextToken());
        int m = Integer.parseInt(st.nextToken());
        
        // 建图
        for (int i = 0; i < m; i++) {
            st = new StringTokenizer(br.readLine());
            int u = Integer.parseInt(st.nextToken());
            int v = Integer.parseInt(st.nextToken());
            adj[u].add(v);
        }
        
        // 运行 Tarjan
        for (int i = 1; i <= n; i++) {
            if (dfn[i] == 0) {
                tarjan(i);
            }
        }
        
        // 统计每个 SCC 的出度
        int[] outdeg = new int[sccCnt + 1];
        for (int u = 1; u <= n; u++) {
            for (int v : adj[u]) {
                if (sccId[u] != sccId[v]) {
                    outdeg[sccId[u]]++;
                }
            }
        }
        
        // 统计答案
        int zeroOut = 0;
        int ans = 0;
        for (int i = 1; i <= sccCnt; i++) {
            if (outdeg[i] == 0) {
                zeroOut++;
                ans = sccSize[i];
            }
        }
        
        if (zeroOut != 1) {
            ans = 0;
        }
        
        out.println(ans);
        out.flush();
    }
}
```

## 时间/空间复杂度分析

- **时间复杂度**：O(N + M)
  - Tarjan 算法线性时间遍历所有节点和边

- **空间复杂度**：O(N + M)
  - 邻接表存储图
  - 辅助数组和栈空间

## 笔试面试要点

### 口述算法流程

```
1. 首先使用 Tarjan 算法求出所有强连通分量
2. 将每个强连通分量缩成一个点，形成 DAG
3. 在 DAG 中，只有出度为 0 的点（汇点）才可能被所有点到达
4. 如果只有一个汇点，答案就是它的节点数；否则为 0
```

### 常见错误

1. **忘记处理重边**：重边不影响 SCC，但统计出度时会重复计数
   - 解决：使用 set 去重，或在统计时判断是否已计数

2. **忽略自环**：自环不影响算法正确性

3. **图不连通**：需要对每个未访问节点都运行 Tarjan
