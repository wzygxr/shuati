# 【蓝桥杯】国赛 - 连通图

## 题目信息

- **题目类型**: 蓝桥杯国赛真题
- **难度**: 中等
- **算法标签**: 强连通分量、Tarjan算法、图论

## 题目描述

给定一个有向图，请判断该图是否是强连通图。如果是，输出"Yes"；否则输出"No"并输出需要添加的最少边数使得图变成强连通图。

## 输入输出格式

### 输入格式
第一行一个整数T，表示测试数据组数
每组数据第一行两个整数n,m，表示点数和边数
接下来m行，每行u,v表示u到v有一条有向边

### 输出格式
对于每组数据：
- 如果图强连通，输出"Yes"
- 否则输出"No"和最少需要添加的边数

### 数据范围
- $1 \leq T \leq 10$
- $1 \leq n \leq 1000$
- $1 \leq m \leq 5000$

## 笔试/面试考察点分析

### 核心考察点
1. **强连通图判断**：SCC数量是否为1
2. **缩点后分析**：入度为0和出度为0的SCC数量
3. **最少边数计算**：max(入度为0的SCC数, 出度为0的SCC数)

### 面试口述要点
- 首先求SCC，缩点得到DAG
- 在DAG中，入度为0的SCC需要添加进入边
- 出度为0的SCC需要添加出去边
- 最少边数 = max(入度为0的个数, 出度为0的个数)
- 特殊情况：如果只有一个SCC，已经强连通

## 解题思路

### 步骤1：求SCC
使用Tarjan算法求所有强连通分量。

### 步骤2：缩点并统计入度出度
构建缩点后的DAG，统计每个SCC的入度和出度。

### 步骤3：计算最少边数
- 统计入度为0的SCC数量（in0）
- 统计出度为0的SCC数量（out0）
- 答案 = max(in0, out0)

**为什么？**
- 每个入度为0的SCC需要至少一条入边
- 每个出度为0的SCC需要至少一条出边
- 可以将出度为0的SCC连到入度为0的SCC，一次解决两个

## 完整代码实现

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 1005;

vector<int> adj[MAXN];

int dfn[MAXN], low[MAXN], timestamp;
stack<int> st;
bool in_stack[MAXN];

int scc_id[MAXN], scc_cnt;
int in_deg[MAXN], out_deg[MAXN];

/**
 * Tarjan算法求强连通分量
 * 
 * 面试要点：
 * - dfn记录访问时间戳
 * - low记录能回溯到的最早时间戳
 * - 栈维护当前DFS路径
 */
void tarjan(int u) {
    dfn[u] = low[u] = ++timestamp;
    st.push(u);
    in_stack[u] = true;
    
    for (int v : adj[u]) {
        if (!dfn[v]) {
            tarjan(v);
            low[u] = min(low[u], low[v]);
        } else if (in_stack[v]) {
            low[u] = min(low[u], dfn[v]);
        }
    }
    
    if (dfn[u] == low[u]) {
        scc_cnt++;
        int v;
        do {
            v = st.top(); st.pop();
            in_stack[v] = false;
            scc_id[v] = scc_cnt;
        } while (v != u);
    }
}

/**
 * 缩点并统计入度出度
 */
void shrink(int n) {
    for (int u = 1; u <= n; u++) {
        for (int v : adj[u]) {
            if (scc_id[u] != scc_id[v]) {
                out_deg[scc_id[u]]++;
                in_deg[scc_id[v]]++;
            }
        }
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int T;
    cin >> T;
    
    while (T--) {
        int n, m;
        cin >> n >> m;
        
        // 清空图
        for (int i = 1; i <= n; i++) {
            adj[i].clear();
        }
        
        // 读入边
        for (int i = 0; i < m; i++) {
            int u, v;
            cin >> u >> v;
            adj[u].push_back(v);
        }
        
        // 初始化
        memset(dfn, 0, sizeof(dfn));
        memset(low, 0, sizeof(low));
        memset(in_stack, false, sizeof(in_stack));
        memset(scc_id, 0, sizeof(scc_id));
        memset(in_deg, 0, sizeof(in_deg));
        memset(out_deg, 0, sizeof(out_deg));
        timestamp = 0;
        scc_cnt = 0;
        
        // Tarjan求SCC
        for (int i = 1; i <= n; i++) {
            if (!dfn[i]) tarjan(i);
        }
        
        // 如果只有一个SCC，已经强连通
        if (scc_cnt == 1) {
            cout << "Yes" << endl;
            continue;
        }
        
        // 缩点
        shrink(n);
        
        // 统计入度为0和出度为0的SCC
        int in0 = 0, out0 = 0;
        for (int i = 1; i <= scc_cnt; i++) {
            if (in_deg[i] == 0) in0++;
            if (out_deg[i] == 0) out0++;
        }
        
        cout << "No " << max(in0, out0) << endl;
    }
    
    return 0;
}
```

## 笔试面试高频问题

**Q: 为什么答案是max(in0, out0)？**
> 每个入度为0的SCC需要至少一条入边，每个出度为0的SCC需要至少一条出边。我们可以将出度为0的SCC连接到入度为0的SCC，一次解决两个。所以最少需要max(in0, out0)条边。

**Q: 如果只有一个SCC，答案是什么？**
> 已经强连通，不需要添加边。但要注意特判，避免除以0等错误。

**Q: 如何构造具体的加边方案？**
> 将出度为0的SCC按顺序连接到入度为0的SCC。如果有k个出度为0的SCC和k个入度为0的SCC，可以形成一个环。
