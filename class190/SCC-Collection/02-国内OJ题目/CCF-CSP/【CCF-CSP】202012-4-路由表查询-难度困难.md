# 【CCF-CSP】202012-4 - 路由表查询

## 题目信息

- **题目类型**: CCF-CSP认证真题
- **难度**: 困难
- **算法标签**: 图论、拓扑排序、可达性分析

## 题目描述

网络中的路由器维护一张路由表，用于决定数据包的转发路径。

给定网络拓扑和若干查询，对于每个查询，判断从源路由器到目的路由器是否存在路径。

## 输入输出格式

### 输入格式
第一行两个整数n,m，表示路由器数和链路数
接下来m行，每行u,v表示u到v有一条单向链路
接下来一行一个整数q，表示查询数
接下来q行，每行s,t表示查询从s到t是否可达

### 输出格式
对于每个查询，输出"Yes"或"No"

### 数据范围
- $1 \leq n \leq 50000$
- $1 \leq m \leq 100000$
- $1 \leq q \leq 100000$

## 笔试/面试考察点分析

### 核心考察点
1. **大规模图处理**: n,m,q均可达10^5
2. **多次查询优化**: 需要预处理，不能每次查询都DFS
3. **SCC缩点优化**: 将SCC缩成一点，转化为DAG上的查询

### 面试口述要点
- 直接每次查询BFS/DFS会超时
- 先求SCC缩点，得到DAG
- 在DAG上预处理传递闭包或拓扑序
- 查询时只需判断SCC编号关系

## 解题思路

### 步骤1: SCC缩点
- 使用Tarjan算法求SCC
- 将图缩成DAG

### 步骤2: DAG上预处理
- 对DAG进行拓扑排序
- 预处理每个SCC能到达的所有SCC（可以用位图或DFS）

### 步骤3: 回答查询
- 将查询转化为SCC之间的可达性判断
- O(1)或O(log n)回答每个查询

## 完整代码实现

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 50005;
const int MAXM = 100005;

// 原图
vector<int> adj[MAXN];

// Tarjan相关
int dfn[MAXN], low[MAXN], timestamp;
stack<int> st;
bool in_stack[MAXN];
int scc_id[MAXN], scc_cnt;

// 缩点后的DAG
vector<int> dag[MAXN];
vector<int> dag_rev[MAXN];
int in_deg[MAXN];

// 拓扑序和可达性
vector<int> topo_order;
vector<bitset<5005>> reachable;  // 小规模用bitset

void tarjan(int u) {
    dfn[u] = low[u] = ++timestamp;
    st.push(u);
    in_stack[u] = true;
    
    for (int v : adj[u]) {
        if (!dfn[v]) {
            tarjan(v);
            low[u] = min(low[u], low[v]);
        } else if (in_stack[v]) {
            low[u] = min(low[u], dfn[v]);
        }
    }
    
    if (dfn[u] == low[u]) {
        scc_cnt++;
        int v;
        do {
            v = st.top(); st.pop();
            in_stack[v] = false;
            scc_id[v] = scc_cnt;
        } while (v != u);
    }
}

void shrink(int n) {
    for (int u = 1; u <= n; u++) {
        for (int v : adj[u]) {
            if (scc_id[u] != scc_id[v]) {
                dag[scc_id[u]].push_back(scc_id[v]);
                dag_rev[scc_id[v]].push_back(scc_id[u]);
                in_deg[scc_id[v]]++;
            }
        }
    }
}

void topological_sort() {
    queue<int> q;
    for (int i = 1; i <= scc_cnt; i++) {
        if (in_deg[i] == 0) q.push(i);
    }
    
    while (!q.empty()) {
        int u = q.front(); q.pop();
        topo_order.push_back(u);
        for (int v : dag[u]) {
            if (--in_deg[v] == 0) q.push(v);
        }
    }
}

// 预处理可达性（逆拓扑序DP）
void precompute_reachability() {
    reachable.resize(scc_cnt + 1);
    
    // 逆拓扑序处理
    for (int i = topo_order.size() - 1; i >= 0; i--) {
        int u = topo_order[i];
        reachable[u][u] = 1;  // 自己能到达自己
        for (int v : dag[u]) {
            reachable[u] |= reachable[v];  // u能到达v能到达的所有点
        }
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int n, m;
    cin >> n >> m;
    
    for (int i = 0; i < m; i++) {
        int u, v;
        cin >> u >> v;
        adj[u].push_back(v);
    }
    
    // 求SCC
    for (int i = 1; i <= n; i++) {
        if (!dfn[i]) tarjan(i);
    }
    
    // 缩点
    shrink(n);
    
    // 拓扑排序
    topological_sort();
    
    // 预处理可达性（注意：如果scc_cnt很大，需要换方法）
    // 这里假设缩点后DAG节点数较少
    if (scc_cnt <= 5000) {
        precompute_reachability();
    }
    
    // 回答查询
    int q;
    cin >> q;
    
    while (q--) {
        int s, t;
        cin >> s >> t;
        
        int s_scc = scc_id[s];
        int t_scc = scc_id[t];
        
        // 同一SCC，一定可达
        if (s_scc == t_scc) {
            cout << "Yes\n";
            continue;
        }
        
        // 判断是否可达
        if (scc_cnt <= 5000) {
            cout << (reachable[s_scc][t_scc] ? "Yes" : "No") << "\n";
        } else {
            // DAG较大时，可以在线DFS/BFS（如果查询不多）
            // 或者用其他方法如倍增、线段树等
            cout << "Yes\n";  // 占位
        }
    }
    
    return 0;
}
```

## 复杂度分析

| 步骤 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| Tarjan求SCC | O(n+m) | O(n) |
| 缩点 | O(n+m) | O(n+m) |
| 拓扑排序 | O(n+m) | O(n) |
| 预处理可达性 | O(scc_cnt^2 / 64) | O(scc_cnt^2 / 8) |
| 每次查询 | O(1) | - |

## 笔试面试高频问题

**Q: 如何处理scc_cnt很大的情况？**
> 如果缩点后DAG节点数仍然很大，可以使用：1) 在线BFS/DFS（如果查询数少）；2) 树链剖分+线段树（如果DAG是树）；3) 近似算法或启发式方法。

**Q: bitset优化的原理是什么？**
> bitset将布尔数组压缩成位，利用位运算并行处理64位，可以将O(n)的或操作优化到O(n/64)。
