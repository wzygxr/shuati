# 【HDU】1269 - 迷宫城堡

## 题目信息

- **题目链接**: http://acm.hdu.edu.cn/showproblem.php?pid=1269
- **难度**: 基础模板题
- **算法标签**: 强连通分量、Tarjan算法

## 题目描述

为了训练小希的方向感，Gardon建立了一座大城堡，里面有N个房间和M条路。

有一天，Gardon想问小希："你能找到一条通路，使得从任意一个房间出发都能到达任意另一个房间吗？"

## 输入输出格式

### 输入格式
多组测试数据
每组第一行两个整数N,M
接下来M行，每行u,v表示u到v有一条路
N=0,M=0表示输入结束

### 输出格式
如果整个图强连通，输出"Yes"，否则输出"No"

### 数据范围
- $1 \leq N \leq 10000$
- $1 \leq M \leq 100000$

## 笔试/面试考察点分析

### 核心考察点
1. **强连通的定义**：整个图是一个强连通分量
2. **Tarjan算法模板**：判断SCC数量是否为1
3. **多组数据输入处理**

## 解题思路

### 判断图强连通
- 求SCC数量
- 如果scc_cnt == 1，则图强连通

## 完整代码实现

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 10005;

vector<int> adj[MAXN];

int dfn[MAXN], low[MAXN], timestamp;
stack<int> st;
bool in_stack[MAXN];
int scc_cnt;

void tarjan(int u) {
    dfn[u] = low[u] = ++timestamp;
    st.push(u);
    in_stack[u] = true;
    
    for (int v : adj[u]) {
        if (!dfn[v]) {
            tarjan(v);
            low[u] = min(low[u], low[v]);
        } else if (in_stack[v]) {
            low[u] = min(low[u], dfn[v]);
        }
    }
    
    if (dfn[u] == low[u]) {
        scc_cnt++;
        int v;
        do {
            v = st.top(); st.pop();
            in_stack[v] = false;
        } while (v != u);
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int n, m;
    while (cin >> n >> m && (n || m)) {
        // 清空图
        for (int i = 1; i <= n; i++) {
            adj[i].clear();
        }
        
        // 读入边
        for (int i = 0; i < m; i++) {
            int u, v;
            cin >> u >> v;
            adj[u].push_back(v);
        }
        
        // 初始化
        memset(dfn, 0, sizeof(dfn));
        memset(low, 0, sizeof(low));
        memset(in_stack, false, sizeof(in_stack));
        timestamp = 0;
        scc_cnt = 0;
        
        // 求SCC
        for (int i = 1; i <= n; i++) {
            if (!dfn[i]) tarjan(i);
        }
        
        // 判断
        if (scc_cnt == 1) {
            cout << "Yes" << endl;
        } else {
            cout << "No" << endl;
        }
    }
    
    return 0;
}
```

## 复杂度分析

- **时间**：$O(T \cdot (N + M))$，T为测试数据组数
- **空间**：$O(N + M)$

## 笔试面试问题

**Q: 如何判断无向图是否连通？**
> 无向图用并查集或DFS/BFS判断连通分量数量。有向图需要用SCC判断强连通。
