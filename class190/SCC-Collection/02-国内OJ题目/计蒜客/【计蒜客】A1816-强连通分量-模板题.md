# 【计蒜客】A1816 - 强连通分量

## 题目信息

- **题目链接**: https://www.jisuanke.com/problem/A1816
- **难度**: 中等
- **算法标签**: 图论、强连通分量、Tarjan算法

## 题目描述

给定一个有向图，请找出图中的所有强连通分量。

## 输入输出格式

### 输入格式
第一行两个整数n,m，表示点数和边数
接下来m行，每行两个整数u,v，表示u到v有一条有向边

### 输出格式
输出每个强连通分量包含的节点，每行一个SCC，节点编号从小到大

### 数据范围
- $1 \leq n \leq 10000$
- $1 \leq m \leq 50000$

## 笔试/面试考察点分析

### 核心考察点
1. **Tarjan算法标准模板**
2. **结果排序输出**
3. **算法稳定性**

## 解题思路

### 标准Tarjan算法
1. DFS遍历图
2. 维护dfn和low数组
3. 栈标记当前路径
4. 出栈时标记SCC

## 完整代码实现

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 10005;

vector<int> adj[MAXN];

int dfn[MAXN], low[MAXN], timestamp;
stack<int> st;
bool in_stack[MAXN];

int scc_id[MAXN], scc_cnt;
vector<vector<int>> scc_nodes;

void tarjan(int u) {
    dfn[u] = low[u] = ++timestamp;
    st.push(u);
    in_stack[u] = true;
    
    for (int v : adj[u]) {
        if (!dfn[v]) {
            tarjan(v);
            low[u] = min(low[u], low[v]);
        } else if (in_stack[v]) {
            low[u] = min(low[u], dfn[v]);
        }
    }
    
    if (dfn[u] == low[u]) {
        scc_cnt++;
        vector<int> nodes;
        int v;
        do {
            v = st.top(); st.pop();
            in_stack[v] = false;
            scc_id[v] = scc_cnt;
            nodes.push_back(v);
        } while (v != u);
        
        sort(nodes.begin(), nodes.end());
        scc_nodes.push_back(nodes);
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int n, m;
    cin >> n >> m;
    
    for (int i = 0; i < m; i++) {
        int u, v;
        cin >> u >> v;
        adj[u].push_back(v);
    }
    
    memset(dfn, 0, sizeof(dfn));
    timestamp = 0;
    scc_cnt = 0;
    
    for (int i = 1; i <= n; i++) {
        if (!dfn[i]) tarjan(i);
    }
    
    // 按SCC内最小节点排序输出
    sort(scc_nodes.begin(), scc_nodes.end());
    
    for (auto& nodes : scc_nodes) {
        for (int i = 0; i < nodes.size(); i++) {
            if (i > 0) cout << " ";
            cout << nodes[i];
        }
        cout << endl;
    }
    
    return 0;
}
```

## 复杂度分析

- **时间**：$O(n + m + n \log n)$（含排序）
- **空间**：$O(n + m)$
