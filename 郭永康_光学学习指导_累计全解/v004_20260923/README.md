## 关键勘误

1. 习题 3.1 两列波都含 `omega t-kz`，均沿 `+z` 传播；长度单位按题面明确的 m 处理。
2. 普通无吸收部分反射时，实数 `r_s,r_p` 不会使线偏振自动变为椭圆偏振；全反射或吸收反射才一般产生非平凡相位差。
3. 习题 3.4 的 45 度方向投影空间频率复算为 `1.813094e6 m^-1`。
4. 习题 3.15 四界面透射率连乘：裸表面总损耗 19.8128%，每面反射率 1% 时总损耗 3.9404%。
