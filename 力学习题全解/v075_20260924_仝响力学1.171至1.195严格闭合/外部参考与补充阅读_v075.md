# 外部参考与补充阅读 v075

公开课程只用于核对一般物理原理、补充新手解释和提供额外训练。仝响原题的题号、数据、图形和答案边界仍以376页完整扫描母版为唯一题源。

1. OpenStax University Physics Volume 1, §9.2 Impulse and Collisions：冲量-动量定理、短时碰撞和平均冲击力。适合补充题1.192的碰地瞬间模型。
   https://openstax.org/books/university-physics-volume-1/pages/9-2-impulse-and-collisions

2. OpenStax, §10.8 Work and Power for Rotational Motion：转动功-能、力矩功和角位移。适合题1.190、1.191。
   https://openstax.org/books/university-physics-volume-1/pages/10-8-work-and-power-for-rotational-motion

3. OpenStax, §11.1 Rolling Motion：区分无滑动与有滑动；有滑动时不能使用 v=Rω。
   https://openstax.org/books/university-physics-volume-1/pages/11-1-rolling-motion

4. MIT OpenCourseWare 8.01SC Online Textbook：碰撞、刚体转动、简谐振动与天体力学的系统教材入口。
   https://ocw.mit.edu/courses/8-01sc-classical-mechanics-fall-2016/pages/online-textbook/

5. MIT 8.01SC Problem Set 10：转动惯量、复合滑轮、V形槽圆柱和有质量滑轮。
   https://ocw.mit.edu/courses/8-01sc-classical-mechanics-fall-2016/pages/week-10-rotational-motion/problem-set-10/

6. MIT 8.01SC Problem Set 12：滚动、低台阶碰撞、悠悠球和台球。
   https://ocw.mit.edu/courses/8-01sc-classical-mechanics-fall-2016/pages/week-12-rotations-and-translation-rolling/problem-set-12/

建议训练顺序：先用1.188练习“负支持力意味着约束失效”；再用1.190--1.191区分摩擦耗散、角冲量和无滑动终态；随后用1.192训练碰撞后的相对运动和等比递推；最后用1.194--1.195训练虚功约束与双向/单向接触模型的区别。
