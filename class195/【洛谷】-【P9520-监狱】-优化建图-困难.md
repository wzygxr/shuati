# 【洛谷】-【P9520 监狱】-优化建图-困难

- 洛谷: https://www.luogu.com.cn/problem/P9520

## 2. 题目完整描述（精炼版）
树上 `m` 个囚犯从各自卧室到工作室，必须沿最短路移动；任意时刻任一房间最多一个囚犯。判断是否存在合法调度。

## 3. 考察点
- 树上路径冲突建模
- 路径约束转偏序图
- 倍增优化建图
- 拓扑可行性判定

## 4. 解题思路
1. 每个囚犯的最短路是树上唯一简单路径。
2. 把“先后进入同一房间”的冲突转成有向依赖。
3. 用倍增/虚拟节点压缩路径级约束。
4. 拓扑排序判断是否有环。
