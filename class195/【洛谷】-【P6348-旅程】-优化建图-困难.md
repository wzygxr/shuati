# 【洛谷】-【P6348 旅程】-优化建图-困难

## 1. 题目原始链接
- 洛谷: https://www.luogu.com.cn/problem/P6348

## 2. 题目完整描述（精炼版）
有 `n` 个点、起点 `p`，执行 `m` 次操作：
- `a b c d`：让 `[a,b]` 与 `[c,d]` 的所有点两两连无向边

操作结束后，求 `p` 到每个点的最少经过边数。

- 输入：`n m p`，随后 `m` 行区间对
- 输出：`n` 行最少边数（题目保证连通）
- 数据范围：`1 <= n <= 5e5`，`1 <= m <= 1e5`

示例（格式演示）
```text
4 2 1
1 2 3 4
2 3 1 1
```

## 3. 笔试/面试考察点
- 区间-区间连边优化
- 虚拟点拆桥（`x -> y` 权重 1）
- 0-1 BFS

## 4. 解题思路
1. 每个区间对操作创建两个中间虚拟点。
2. `[a,b] -> x`、`y -> [c,d]` 走 0 权，`x -> y` 走 1 权。
3. 对称再建一次实现无向效果。
4. 在扩展图上跑 0-1 BFS。

## 6. 复杂度
- 建图：`O(m log n)`
- 最短路：`O(V+E)`（0-1 BFS）
- 空间：`O(V+E)`
