# 【洛谷】-【P5025 炸弹】-优化建图-困难

## 1. 题目原始链接
- 洛谷: https://www.luogu.com.cn/problem/P5025

## 2. 题目完整描述（精炼版）
线性排列 `n` 个炸弹，第 `i` 个炸弹坐标 `xi`、半径 `ri`。引爆 `i` 后会连锁引爆其作用范围内炸弹。定义 `query(i)` 为最终引爆数量，求 `sum(i * query(i)) mod 1e9+7`。

## 3. 考察点
- 区间影响建图优化
- 强连通分量缩点
- DAG 上可达区间 DP

## 4. 解题思路
1. 通过二分确定每个炸弹能直接影响的下标区间。
2. 用线段树把“点影响区间”压缩成 `O(logn)` 连边。
3. Tarjan 缩点后在 DAG 上传播左右边界。
4. 得到每个点可波及区间长度。
