## 2. 题目完整描述（精炼版）
给定 `n` 个点和起点 `s`，有 `q` 次操作：
1. `1 x y w`：增加 `x -> y` 的有向边，边权 `w`
2. `2 x l r w`：增加 `x -> [l, r]` 的所有有向边，边权 `w`
3. `3 x l r w`：增加 `[l, r] -> x` 的所有有向边，边权 `w`

最终输出从 `s` 到每个点的最短路，不可达输出 `-1`。

- 输入：`n q s`，随后 `q` 行操作
- 输出：`n` 个答案
- 数据范围：`1 <= n,q <= 1e5`，`1 <= w <= 1e9`

示例（格式演示）
```text
5 4 1
1 1 2 3
2 1 3 5 2
3 4 1 2 4
1 2 5 1
```

## 3. 笔试/面试考察点
- 线段树优化建图（入树 + 出树）
- 区间到点、点到区间连边的 `O(log n)` 化
- 稀疏图最短路（Dijkstra）
- 大规模图的节点/边数量估算与内存控制

## 4. 解题思路（口述版）
1. 直接展开区间边会超内存，必须用“线段树虚拟点”压缩边数。
2. 建两棵树：
   - 出树：支持 `点 -> 区间`
   - 入树：支持 `区间 -> 点`
3. 每次区间操作只连 `O(log n)` 条边。
4. 在扩展图上跑 Dijkstra，取原始 `1..n` 节点答案。

面试高频口述：
- “什么时候一眼判断要用优化建图？”
  当关系是“单点与区间”或“区间与区间”批量连边，且 `n,q` 在 `1e5` 级别时。

## 6. 时间/空间复杂度
- 建图：`O((n+q)logn)`
- 最短路：`O(E log V)`
- 空间：`O(V+E)`，其中 `V,E` 为优化建图后的规模

## 7. 同类题目拓展
