# 【HDU】-【5669 Road】-优化建图-困难

## 1. 题目原始链接
- HDU: https://acm.hdu.edu.cn/showproblem.php?pid=5669

## 2. 题目完整描述（精炼版）
有 `n` 点，执行 `m` 次区间对连边操作：
- `a b c d w`：`[a,b]` 与 `[c,d]` 全连无向边，边权 `w`

从 1 到 n 最短路，但有 `k` 次“免费过边”机会。

- 输入含多组数据
- 输出最小代价，不可达输出固定字符串
- 范围：`n<=5e4,m<=1e5,k<=10,w<=1e3`

## 3. 考察点
- 区间-区间加权连边优化
- 分层图（免费次数维度）
- Dijkstra

## 4. 解题思路
1. 线段树优化处理区间端点。
2. 扩展 `k+1` 层状态：`(node, usedFree)`。
3. 普通走边：代价 `w`；免费走边：`usedFree+1` 层，代价 `0`。
4. Dijkstra 求解。
