# 【洛谷】-【P5344 逛森林】-优化建图-困难

## 1. 题目原始链接
- 洛谷: https://www.luogu.com.cn/problem/P5344

## 2. 题目完整描述（精炼版）
动态加边维护森林连通；另有“路径到路径单向传送”操作。最终求起点 `s` 到所有点最小代价。

## 3. 考察点
- 并查集动态森林
- 树上路径分解（倍增）
- 路径到路径优化建图
- Dijkstra

## 4. 解题思路
1. 2 类操作只在连通条件成立时生效。
2. 对动态形成的树做倍增结构，支持路径打包成虚拟节点边。
3. 每次传送操作转为“源路径 -> 虚拟点 -> 目标路径”的少量边。
4. 在扩展图上做 Dijkstra。

## 6. 复杂度
- 建图：约 `O((n+m)log n)`
- 最短路：`O(E log V)`

## 7. 同类题
- 动态树 + 传送边
- 路径批量连边最短路
