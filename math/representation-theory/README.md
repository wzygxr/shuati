## 内容（六题，全部闭合）

1. 二面体群 $D_{2n}$ 的**全部正规子群**分类（完备性证明：任意子群的标准形 + 正规性判据 $d\mid 2$）
2. 平均化投影 $P=\frac1{|G|}\sum_g \rho(g)\pi\rho(g)^{-1}$：幂等、像 $=W$、$G$-等变、$V=W\oplus\ker P$（Maschke 的证明）
3. 正则表示：$\chi_{V_R}$、重数 $a_i=\dim V_i$、$|G|=\sum_i(\dim V_i)^2$
4. $S_n$ 共轭类大小公式 $\dfrac{n!}{\prod_j j^{m_j}m_j!}$（模板填数法 + 轨道–稳定子两证）
5. 置换特征标 = 不动点数；$\chi_{W_n}=\#\mathrm{fix}-1$；$S_3$ 数值表 $(2,0,-1)$
6. 标准表示 $W_n$ 不可约（不变子空间法为正证，特征标法为备证）；$W_n\simeq V_{(n-1,1)}$（特征标对照 + 钩长核验 + $n=3$ 全表验证）
