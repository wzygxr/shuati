## 算法核心内容

### 欧拉序+ST表方法
- **预处理时间复杂度**：O(n log n)
- **查询时间复杂度**：O(1)
- **空间复杂度**：O(n log n)
- **适用场景**：大量查询的在线算法

### DFN序+倍增法方法
- **预处理时间复杂度**：O(n log n)
- **查询时间复杂度**：O(log n)
- **空间复杂度**：O(n log n)
- **适用场景**：一般查询场景，实现简单

## 机器学习关联

### 欧拉序在ML中的应用
1. **树结构序列化**：将树转化为序列，适配RNN、Transformer等模型
2. **特征提取**：欧拉序中的位置信息和深度信息作为节点嵌入特征
3. **拓扑关系建模**：保持节点间的拓扑关系

### DFN序在GNN中的应用
1. **节点嵌入**：DFN序和深度信息作为节点的嵌入特征
2. **注意力机制**：LCA结果用于构建节点间的注意力权重
3. **路径特征**：通过LCA计算节点间的最短路径信息
