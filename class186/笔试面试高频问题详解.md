# LCA算法笔试面试高频问题详解

## 1. 欧拉序与DFN序基础概念

### 1.1 欧拉序和DFN序的定义及区别

**Q: 请解释欧拉序（Euler Tour）和DFN序（DFS序）的定义，它们的核心区别是什么？**

**A:**
- **欧拉序（Euler Tour）定义**：
  - 在深度优先搜索（DFS）过程中，每次访问节点时（包括进入和回溯）都记录该节点的序列
  - 每个节点在序列中出现的次数等于其子树中的节点数（包括自己）
  - 性质：任意两个节点在欧拉序中首次出现位置之间的最浅节点即为它们的最近公共祖先

- **DFN序（DFS序）定义**：
  - 在深度优先搜索（DFS）过程中，按访问顺序给节点编号的序列
  - 每个节点在序列中只出现一次，编号反映访问顺序
  - 性质：子树中的节点编号在父节点编号之后，且构成连续区间

- **核心区别**：
  - **出现次数**：欧拉序中节点可能多次出现，DFN序中每个节点只出现一次
  - **序列长度**：欧拉序长度为2n-1，DFN序长度为n
  - **应用场景**：欧拉序适合RMQ问题，DFN序适合倍增法

### 1.2 两种方法的适用场景

**Q: 欧拉序求LCA和DFN序求LCA分别适用于什么场景？**

**A:**
- **欧拉序+ST表方法**：
  - **预处理时间复杂度**：O(n log n)
  - **查询时间复杂度**：O(1)
  - **适用场景**：需要大量LCA查询的场景，如在线算法、实时查询系统
  - **优势**：查询时间最短
  - **劣势**：预处理复杂度较高，空间占用较大

- **DFN序+倍增法方法**：
  - **预处理时间复杂度**：O(n log n)
  - **查询时间复杂度**：O(log n)
  - **适用场景**：一般查询场景，实现相对简单
  - **优势**：实现简单，代码量少，易调试
  - **劣势**：查询时间相对较长

## 2. 欧拉序求LCA核心原理

### 2.1 RMQ与LCA的转化

**Q: 欧拉序求LCA的核心原理是什么？为什么RMQ查询能得到最近公共祖先？**

**A:**
欧拉序求LCA的核心原理是将LCA问题转化为RMQ（Range Minimum Query）问题：

1. **欧拉序列构建**：通过DFS遍历树，记录每个节点的进入和退出时间，形成欧拉序列
2. **深度数组构建**：记录欧拉序列中每个位置对应节点的深度
3. **LCA转化为RMQ**：对于节点u和v，它们的LCA对应于欧拉序列中u和v首次出现位置之间深度最小的节点

**为什么RMQ查询能得到LCA？**
- 在欧拉序列中，从节点u到节点v的路径必须经过它们的LCA
- 从u的首次出现到v的首次出现之间的所有节点中，LCA的深度是最小的
- 因为LCA是u和v路径上深度最小的节点（离根最近的公共祖先）

### 2.2 ST表原理

**Q: ST表（Sparse Table）是如何工作的？时间复杂度如何保证？**

**A:**
ST表是一种用于解决RMQ问题的数据结构：

```cpp
// ST表构建
for (int k = 1; k <= log2(n); k++) {
    for (int i = 0; i + (1 << k) <= n; i++) {
        st[i][k] = min(st[i][k-1], st[i + (1 << (k-1))][k-1]);
    }
}
```

- **工作原理**：预计算所有长度为2^k的区间的最小值
- **查询原理**：任意区间[a,b]可以分解为两个长度为2^k的重叠区间
- **时间复杂度**：
  - 预处理：O(n log n)
  - 查询：O(1)

## 3. DFN序求LCA核心原理

### 3.1 倍增法原理

**Q: DFN序+倍增法求LCA的倍增数组递推公式如何推导？时间复杂度是多少？**

**A:**
倍增数组递推公式：`up[u][k] = up[up[u][k-1]][k-1]`

**推导过程：**
- `up[u][k]`表示节点u的2^k级祖先
- `up[u][k-1]`表示节点u的2^(k-1)级祖先，设为节点v
- `up[v][k-1]`表示节点v的2^(k-1)级祖先，也就是u的2^(k-1) + 2^(k-1) = 2^k级祖先
- 因此：`up[u][k] = up[up[u][k-1]][k-1]`

**时间复杂度：**
- 预处理：O(n log n) - 每个节点需要计算log n个祖先
- 查询：O(log n) - 最多进行log n次跳跃

### 3.2 查询过程详解

**Q: 倍增法查询LCA的具体过程是怎样的？**

**A:**
倍增法查询LCA分为三个步骤：

```cpp
int getLCA(int u, int v) {
    // 步骤1：调整到同一深度
    if (depth[u] < depth[v]) swap(u, v);
    int diff = depth[u] - depth[v];
    for (int k = 0; k < LOG; k++) {
        if (diff & (1 << k)) u = up[u][k];
    }
    
    // 步骤2：特殊情况处理
    if (u == v) return u;
    
    // 步骤3：同时向上跳跃
    for (int k = LOG - 1; k >= 0; k--) {
        if (up[u][k] != up[v][k]) {
            u = up[u][k];
            v = up[v][k];
        }
    }
    
    return up[u][0]; // 返回父节点
}
```

## 4. 复杂度分析对比

### 4.1 时间复杂度对比

**Q: 两种LCA求解方法的时间/空间复杂度对比？面试中如何根据题目场景选型？**

**A:**

| 方法 | 预处理时间 | 查询时间 | 空间复杂度 | 适用场景 |
|------|------------|----------|------------|----------|
| 欧拉序+ST表 | O(n log n) | O(1) | O(n log n) | 大量查询场景 |
| DFN序+倍增法 | O(n log n) | O(log n) | O(n log n) | 一般查询场景 |

**选型建议：**
- **大量查询（> n次）**：选择欧拉序+ST表
- **少量查询（< n次）**：选择DFN序+倍增法（实现简单）
- **代码简洁性要求高**：选择DFN序+倍增法
- **查询时间要求严格**：选择欧拉序+ST表

### 4.2 空间复杂度分析

**Q: 两种方法的空间复杂度如何分析？**

**A:**
- **欧拉序+ST表**：
  - 欧拉序列：O(n) - 长度为2n-1
  - ST表：O(n log n) - n个位置，每个位置log n层
  - 总计：O(n log n)

- **DFN序+倍增法**：
  - 倍增数组：O(n log n) - n个节点，每个节点log n个祖先
  - 其他数组：O(n)
  - 总计：O(n log n)

## 5. 边界条件处理

### 5.1 特殊情况处理

**Q: LCA算法需要处理哪些边界条件？**

**A:**
1. **单节点查询**：当u == v时，LCA就是u（或v）本身
2. **根节点查询**：根节点的处理，注意父节点为0的边界情况
3. **深度相等**：两个节点深度相等时的处理
4. **祖先关系**：一个节点是另一个节点祖先的情况

### 5.2 实现细节

**Q: 实现LCA算法时需要注意哪些细节？**

**A:**
1. **数组大小**：欧拉序数组大小应为2n-1
2. **深度初始化**：根节点深度通常设为1，虚拟根节点深度为0
3. **倍增数组边界**：检查祖先是否存在
4. **位运算优化**：使用位运算代替乘除法提高效率

**Q: 如何利用LCA算法进行路径统计？**

**A:**
```cpp
// 计算路径上的节点数
int pathLength(int u, int v) {
    int lca = getLCA(u, v);
    return depth[u] + depth[v] - 2 * depth[lca] + 1;
}

// 计算路径上的权重和
int pathWeight(int u, int v) {
    int lca = getLCA(u, v);
    return dist[u] + dist[v] - 2 * dist[lca];
}
```

## 8. 代码实现模板

### 8.1 欧拉序+ST表模板

```cpp
#include <iostream>
#include <vector>
#include <cmath>
#include <algorithm>
using namespace std;

const int MAXN = 1e5 + 5;
const int LOG = 20;

vector<int> adj[MAXN];
int depth[MAXN], first[MAXN];
vector<int> euler;
int st[2 * MAXN][LOG], lg[2 * MAXN];

void eulerTour(int u, int parent) {
    first[u] = euler.size();
    euler.push_back(u);
    depth[u] = depth[parent] + 1;
    
    for (int v : adj[u]) {
        if (v != parent) {
            eulerTour(v, u);
            euler.push_back(u);
        }
    }
}

void buildSparseTable() {
    int n = euler.size();
    lg[1] = 0;
    for (int i = 2; i <= n; i++) lg[i] = lg[i >> 1] + 1;
    
    for (int i = 0; i < n; i++) st[i][0] = i;
    
    for (int k = 1; k <= lg[n]; k++) {
        for (int i = 0; i + (1 << k) <= n; i++) {
            int left = st[i][k-1], right = st[i + (1 << (k-1))][k-1];
            st[i][k] = (depth[euler[left]] < depth[euler[right]]) ? left : right;
        }
    }
}

int rmq(int ql, int qr) {
    int k = lg[qr - ql + 1];
    int left = st[ql][k], right = st[qr - (1 << k) + 1][k];
    return (depth[euler[left]] < depth[euler[right]]) ? left : right;
}

int getLCA(int u, int v) {
    int left = first[u], right = first[v];
    if (left > right) swap(left, right);
    return euler[rmq(left, right)];
}
```

### 8.2 DFN序+倍增法模板

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

const int MAXN = 1e5 + 5;
const int LOG = 20;

vector<int> adj[MAXN];
int depth[MAXN], dfn[MAXN], up[MAXN][LOG];
int time_stamp = 0;

void dfnPreprocess(int u, int p) {
    dfn[u] = ++time_stamp;
    depth[u] = depth[p] + 1;
    up[u][0] = p;
    
    for (int k = 1; k < LOG; k++) {
        if (up[u][k-1] != 0) up[u][k] = up[up[u][k-1]][k-1];
        else up[u][k] = 0;
    }
    
    for (int v : adj[u]) {
        if (v != p) dfnPreprocess(v, u);
    }
}

int getLCA(int u, int v) {
    if (u == v) return u;
    
    if (depth[u] < depth[v]) swap(u, v);
    
    int diff = depth[u] - depth[v];
    for (int k = 0; k < LOG; k++) {
        if (diff & (1 << k)) u = up[u][k];
    }
    
    if (u == v) return u;
    
    for (int k = LOG - 1; k >= 0; k--) {
        if (up[u][k] != up[v][k]) {
            u = up[u][k];
            v = up[v][k];
        }
    }
    
    return up[u][0];
}
```
