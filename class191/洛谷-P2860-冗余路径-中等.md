# 洛谷-P2860-Redundant Paths-中等

## 题目信息

- **题目链接**: https://www.luogu.com.cn/problem/P2860
- **原题链接（USACO）**: http://usaco.org/index.php?page=jan06&lang=zh
- **难度**: 中等
- **考察点**: 边双连通分量（e-DCC）、缩点、叶子节点度数统计

## 题目描述

### 题目背景

USACO 2006 January Gold - Redundant Paths

### 题目描述

为了从草地的一个区域到达另一个区域，Bessie必须经过一棵腐烂苹果树附近的道路。现在有F个草地（编号为1到F），它们之间有至少一条路径。Bessie想要建造一些新的道路，使得在任意两个区域之间都有至少两条独立的路径。

求最少需要添加多少条道路，才能使得整个图变成边双连通的（即不存在割边）。

### 输入格式

第一行包含两个整数 F 和 R，分别表示草地数量（节点数）和道路数量（边数）。
接下来 R 行，每行包含两个整数 a 和 b，表示一条无向道路。

### 输出格式

输出一个整数，表示最少需要添加的道路数量。

### 数据范围

- 1 ≤ F ≤ 5000
- R 的范围未明确给出，但满足 F-1 ≤ R ≤ F*(F-1)/2

### 样例输入

```
5 4
1 2
2 3
3 1
2 4
```

### 样例输出

```
2
```

### 样例解释

```
    1
   / \
  2---3
   \
    4
```

要在任意两点间都有两条独立路径，需要添加2条道路。例如在1-4和3-4之间添加道路。

## 笔试面试考察点分析

1. **边双连通分量（e-DCC）概念**：极大无边双通子图的定义与性质
2. **缩点原理**：将e-DCC缩为节点，割边作为树的边
3. **树的度数分析**：缩点后树的叶子节点数量与添加边数的关系
4. **公式推导**：`answer = (leaf + 1) / 2`（上取整）
5. **Tarjan算法应用**：求割边和e-DCC

## 解题思路

### 核心原理

1. **边双连通分量**：内部没有割边的极大子图
2. **缩点**：将每个e-DCC缩为一个节点，割边作为连接新节点的边
3. **缩点后的图**：一定是一棵树（对于连通图）
4. **添加边的策略**：将叶子节点两两配对连边，使树变成环

### 公式推导

设缩点后树的叶子节点数量为 `leaf`：
- 每个叶子节点需要至少一条新边与其他部分连接
- 两两配对可以形成环，消除割边
- 最少需要添加的边数 = ⌈leaf / 2⌉ = (leaf + 1) / 2

### 步骤

1. **求割边**：使用Tarjan算法求所有割边
2. **求e-DCC**：使用Tarjan算法求所有边双连通分量
3. **缩点**：将e-DCC缩为节点，割边作为树的边
4. **统计叶子节点**：统计缩点后树中度为1的节点数量
5. **计算答案**：(leaf + 1) / 2

## 完整代码实现（C++）

```cpp
#include <bits/stdc++.h>
using namespace std;

// ==================== 洛谷P2860 冗余路径 ====================
// 适用场景：求最少添加边数使图变为边双连通
// 考察点：e-DCC、缩点、树的叶子节点统计
// 时间复杂度：O(n + m)
// 空间复杂度：O(n + m)

// ==================== 常量定义 ====================
// 数组大小设置：根据题目数据范围F ≤ 5000
// 面试中需说明：为何取这个值（根据数据范围+安全边界）
const int MAXN = 5005;        // 最大节点数 + 5
const int MAXM = 100005;     // 最大边数（无向图需乘2）

// ==================== 边的结构体定义 ====================
// 存储边的终点、边编号、反向边索引
// 面试问题：为什么需要反向边索引？
// 答：便于在O(1)时间内找到任意边的反向边
struct Edge {
    int to;     // 边的终点节点编号
    int id;     // 边的唯一编号，从1开始
    int rev;    // 反向边在邻接表中的索引位置
    Edge(int _to, int _id, int _rev) : to(_to), id(_id), rev(_rev) {}
};

// ==================== 全局变量声明 ====================
// 原始无向图邻接表
vector<Edge> adj[MAXN];

// 缩点后树的邻接表
vector<int> tree_adj[MAXN];

// ==================== Tarjan算法核心数组 ====================
// dfn[u]：节点u的发现时间（DFS序），0表示未访问
int dfn[MAXN];

// low[u]：节点u及其子树中所有节点能回溯到的最小dfn值
int low[MAXN];

int timestamp = 0;  // 全局时间戳

// ==================== 割边标记数组 ====================
// is_bridge[id] = true 表示编号为id的边是割边
// 面试问题：为什么按边编号标记？
// 答：割边是边的属性，每条边有唯一编号
bool is_bridge[MAXM];

// 割边数量统计
int bridge_cnt = 0;

// ==================== 边双连通分量相关数组 ====================
// e_dcc_id[u]：节点u所属的边双连通分量编号
int e_dcc_id[MAXN];

// dcc_cnt：边双连通分量的总数
int dcc_cnt = 0;

// 每个e-DCC的节点数量（可选，用于调试）
int dcc_size[MAXN];

// 栈：用于在Tarjan过程中保存遍历过的节点
// 面试问题：为什么需要栈？
// 答：当dfn[u] == low[u]时，需要弹出栈中节点构成一个e-DCC
stack<int> st;

// ==================== Tarjan算法核心函数 ====================
// 核心原理：
// 1. 使用dfn和low数组判断割边（同割边模板）
// 2. 当dfn[u] == low[u]时，从栈中弹出节点直到u，这些节点构成一个e-DCC
// 3. 割边不属于任何e-DCC
void tarjan(int u, int edge_id) {
    // 初始化当前节点的时间戳
    // 节点首次访问时，dfn和low都设置为当前时间戳
    dfn[u] = low[u] = ++timestamp;
    
    // 将当前节点入栈，用于后续e-DCC的构建
    st.push(u);
    
    // 遍历节点u的所有邻接边
    for (auto &e : adj[u]) {
        int v = e.to;   // 边的终点
        int id = e.id;  // 边的编号
        
        // 判断邻接节点v是否已被访问
        if (!dfn[v]) {
            // 树边：v未被访问，递归进入v
            tarjan(v, id);
            
            // 回溯阶段：用子节点v的low值更新父节点u的low值
            low[u] = min(low[u], low[v]);
            
            // 割边判定定理：low[v] > dfn[u]
            // 含义：子节点v无法通过任何回边回到父节点u或u的祖先
            // 因此删除边(u,v)后，v所在的子树将与图的其他部分断开
            if (low[v] > dfn[u]) {
                is_bridge[id] = true;  // 标记该边为割边
                bridge_cnt++;           // 割边数量+1
            }
        } 
        // 已访问的节点：可能是回边或弃边
        // 需要排除当前边的反向边（处理重边场景）
        else if (id != edge_id) {
            // 用已访问节点的发现时间更新low[u]
            low[u] = min(low[u], dfn[v]);
        }
    }
    
    // 判断是否发现一个新的边双连通分量
    // 面试问题：为什么dfn[u] == low[u]时弹出？
    // 答：这表示u是某个e-DCC的根，其子树无法回到u的祖先
    // 从栈中弹出节点直到u，这些节点构成一个完整的e-DCC
    if (dfn[u] == low[u]) {
        dcc_cnt++;  // e-DCC数量+1
        int pop;
        // 弹出栈中节点直到u
        do {
            pop = st.top();
            st.pop();
            e_dcc_id[pop] = dcc_cnt;  // 标记节点所属的e-DCC
            dcc_size[dcc_cnt]++;       // 统计该e-DCC的节点数
        } while (pop != u);
    }
}

// ==================== 边双缩点核心函数 ====================
// 将每个e-DCC缩为一个节点，割边作为树的边
// 面试高频考点：缩点后的一定是树（森林）
void shrink() {
    // 遍历原图所有边，构建缩点树
    for (int u = 1; u <= MAXN; u++) {
        for (auto &e : adj[u]) {
            int v = e.to;
            int id = e.id;
            
            // 割边连接两个不同的e-DCC
            if (is_bridge[id] && e_dcc_id[u] != e_dcc_id[v]) {
                // 在缩点树中添加边（需要去重，但本题可直接添加）
                tree_adj[e_dcc_id[u]].push_back(e_dcc_id[v]);
                tree_adj[e_dcc_id[v]].push_back(e_dcc_id[u]);
            }
        }
    }
}

// ==================== 统计叶子节点 ====================
// 缩点后树的叶子节点：度为1的节点
// 面试问题：为什么只统计度为1的节点？
// 答：度为1的节点表示原图中只有一个割边连接其他e-DCC
//     这些节点是两两配对添加边的关键
int count_leaf_nodes() {
    int leaf_cnt = 0;
    for (int i = 1; i <= dcc_cnt; i++) {
        // 统计度为1的节点数量
        if (tree_adj[i].size() == 1) {
            leaf_cnt++;
        }
    }
    return leaf_cnt;
}

// ==================== 主函数 - 程序入口 ====================
int main() {
    // 初始化核心数组：避免脏数据
    memset(dfn, 0, sizeof(dfn));
    memset(is_bridge, false, sizeof(is_bridge));
    memset(e_dcc_id, 0, sizeof(e_dcc_id));
    
    int n, m;  // n: 节点数(F), m: 边数(R)
    cin >> n >> m;
    
    // 构建无向图邻接表
    // 每条无向边需要存储为两条有向边（正向和反向）
    for (int i = 1; i <= m; i++) {
        int u, v;
        cin >> u >> v;
        
        // 正向边：u -> v
        adj[u].push_back(Edge(v, i, adj[v].size()));
        
        // 反向边：v -> u
        adj[v].push_back(Edge(u, i, adj[u].size() - 1));
    }
    
    // 遍历所有连通块：处理非连通图
    for (int i = 1; i <= n; i++) {
        if (!dfn[i]) {
            tarjan(i, 0);  // edge_id = 0 表示没有需要排除的边
        }
    }
    
    // 执行边双缩点
    shrink();
    
    // 统计叶子节点数量
    int leaf_cnt = count_leaf_nodes();
    
    // 计算答案：最少添加的边数 = (leaf + 1) / 2
    // 面试问题：为什么是这个公式？
    // 答：将叶子节点两两配对连边形成环，每对需要1条边
    //     奇数个叶子时，单独一个需要额外1条边
    //     上取整公式：⌈leaf/2⌉ = (leaf + 1) / 2
    int answer = (leaf_cnt + 1) / 2;
    
    cout << answer << endl;
    
    return 0;
}
```

## 代码逐行注释

### 核心注释要点

1. **Tarjan算法流程**：
   - 初始化dfn和low
   - 遍历邻接边，递归访问子节点
   - 回溯更新low值
   - 割边判定和e-DCC弹出

2. **缩点原理**：
   - e_dcc_id数组记录节点所属分量
   - 割边连接不同分量，形成树

3. **答案公式推导**：
   - 叶子节点两两配对
   - 上取整处理奇数情况

## 时间空间复杂度分析

- **时间复杂度**：O(n + m)
  - Tarjan算法：O(n + m)
  - 缩点构建：O(m)
  - 叶子统计：O(k)，k为e-DCC数量

- **空间复杂度**：O(n + m)
  - 邻接表：O(n + m)
  - Tarjan数组：O(n)
  - 栈：O(n)
