# 洛谷-P1656-割边-入门

## 题目信息

- **题目链接**: https://www.luogu.com.cn/problem/P1656
- **难度**: 入门
- **考察点**: 割边（桥）模板、Tarjan算法基础

## 题目描述

### 题目背景

炸铁路

### 题目描述

给定一个无向图，求出所有割边（桥）。

### 输入格式

第一行包含两个整数 n 和 m，表示图的节点数和边数。
接下来 m 行，每行包含两个整数 u, v，表示一条无向边 (u, v)。

### 输出格式

按边端点字典序升序输出所有割边。每行输出一个割边的两个端点，小端点在前。

### 数据范围

对于 100% 的数据，1 ≤ n ≤ 5000, 1 ≤ m ≤ 100000

### 样例输入

```
5 5
1 2
2 3
3 1
2 4
4 5
```

### 样例输出

```
2 4
2 5
```

## 笔试面试考察点分析

1. **割边定义理解**：无向图中删除后使图不连通的边
2. **Tarjan算法核心**：dfn数组和low数组的作用与更新逻辑
3. **割边判定定理**：`low[v] > dfn[u]` 的数学原理
4. **重边处理技巧**：通过边编号而非节点编号排除反向边
5. **输出格式注意**：按字典序排序输出

## 解题思路

### 步骤1：Tarjan算法求割边

使用Tarjan算法遍历图，维护两个核心数组：
- `dfn[u]`：节点u的发现时间（DFS序）
- `low[u]`：节点u及其子树能回溯到的最小dfn值

对于边(u, v)，如果`low[v] > dfn[u]`，则该边是割边。

### 步骤2：排序输出

将所有割边按端点字典序排序后输出。

## 完整代码实现（C++）

```cpp
#include <bits/stdc++.h>
using namespace std;

// ==================== 割边（桥）模板 - 洛谷P1656 ====================
// 适用场景：无向图割边识别与统计
// 考察点：Tarjan算法、割边判定、重边处理
// 时间复杂度：O(n + m)
// 空间复杂度：O(n + m)

// ==================== 常量定义 ====================
// 数组最大长度：节点数最大值 + 5
// 边的存储需要双向，故MAXM为边的最大数量的2倍
// 面试中需说明取值依据：n ≤ 5000, m ≤ 100000
const int MAXN = 5005;        // 最大节点数 + 5
const int MAXM = 100005;      // 最大边数

// ==================== 边的结构体定义 ====================
// to: 边的终点节点
// id: 边的唯一编号，从1开始，用于唯一标识每条输入的边
// rev: 反向边在邻接表中的索引位置，用于快速定位反向边（本题可选）
struct Edge {
    int to;     // 边的终点，指向的节点编号
    int id;     // 边的编号，从1开始，用于唯一标识每条输入的边
    int rev;    // 反向边索引，指向to节点邻接表中对应的正向边位置
    Edge(int _to, int _id, int _rev) : to(_to), id(_id), rev(_rev) {}  // 构造函数
};

// ==================== 全局变量声明 ====================
// adj: 原始无向图的邻接表，存储所有边信息
// 面试中需说明：使用邻接表而非邻接矩阵的原因（空间效率）
vector<Edge> adj[MAXN];

// ==================== Tarjan算法核心数组 ====================
// dfn[u]：节点u的发现时间（DFS序），0表示未访问
// 面试高频问题：dfn数组的作用是什么？
// 答：记录节点在DFS遍历中的访问顺序，用于判断割边
int dfn[MAXN];

// low[u]：节点u及其子树中所有节点能回溯到的最小dfn值
// 面试高频问题：low数组的作用是什么？
// 答：用于判断子节点能否通过回边回到当前节点的祖先
int low[MAXN];

int timestamp = 0;  // 全局时间戳，每访问一个新节点+1，初始为0

// ==================== 割边标记数组 ====================
// is_bridge[id] = true 表示编号为id的边是割边
// 面试高频问题：为什么按边编号而非节点编号标记？
// 答：割边是边的属性，每条边有唯一编号；节点可能属于多个边
bool is_bridge[MAXM];

// ==================== 割边结果存储 ====================
// 使用vector存储所有割边，便于后续排序输出
vector<pair<int, int>> bridges;  // pair<小端点, 大端点>

// ==================== Tarjan算法核心函数 ====================
// 核心原理：无向边(u,v)是割边当且仅当low[v] > dfn[u]
// 这表示子节点v无法通过任何回边回到父节点u或更早的节点
// 兼容重边场景：通过边编号而非节点编号来排除反向边
void tarjan(int u, int edge_id) {
    // 初始化当前节点的时间戳
    // 节点首次访问时，dfn和low都设置为当前时间戳
    // 面试问题：为什么初始化时dfn[u] = low[u]？
    // 答：节点刚被发现时，其能回溯到的最早节点就是自己
    dfn[u] = low[u] = ++timestamp;
    
    // 遍历节点u的所有邻接边
    for (auto &e : adj[u]) {
        int v = e.to;     // 边的终点
        int id = e.id;    // 边的编号
        
        // 判断邻接节点v是否已被访问
        if (!dfn[v]) {
            // 树边：v未被访问，递归进入v
            // 传入当前边编号id，用于在v中排除这条边的反向边
            // 面试问题：为什么要传入edge_id？
            // 答：避免将当前边的反向边误判为回边，导致low值错误
            tarjan(v, id);
            
            // 回溯阶段：用子节点v的low值更新父节点u的low值
            // low[u] = min(low[u], low[v]) 表示u及其子树能追溯到的最早节点
            // 面试问题：为什么取min而非直接赋值？
            // 答：v的子树可能通过回边连接到u的祖先，low[v]可能更小
            low[u] = min(low[u], low[v]);
            
            // ==================== 割边判定定理 ====================
            // 条件：low[v] > dfn[u]
            // 含义：子节点v无法通过任何回边回到父节点u或u的祖先
            // 数学原理：如果v能回到u或更早的节点，则删除(u,v)后v仍能与图的其余部分连通
            // 因此删除(u,v)后，v所在的子树将与图的其他部分断开
            if (low[v] > dfn[u]) {
                is_bridge[id] = true;  // 标记该边为割边
                
                // 存储割边结果，按小端点在前排序
                int a = min(u, v);
                int b = max(u, v);
                bridges.emplace_back(a, b);
            }
        } 
        // 已访问的节点：可能是回边或弃边
        // 需要排除当前边的反向边（处理重边场景）
        // 面试问题：为什么不能仅通过父节点编号排除？
        // 答：重边情况下，父节点可能有多条边连接到子节点
        else if (id != edge_id) {
            // 用已访问节点的发现时间更新low[u]
            // 这是Tarjan算法中处理回边的标准做法
            // 面试问题：为什么用dfn[v]而非low[v]？
            // 答：回边连接到的是已访问节点，其dfn就是该节点的最早访问时间
            low[u] = min(low[u], dfn[v]);
        }
    }
}

// ==================== 主函数 - 程序入口 ====================
int main() {
    // 初始化核心数组：笔试中必须注意初始化，避免脏数据导致错误
    memset(dfn, 0, sizeof(dfn));      // 0表示未访问
    memset(is_bridge, false, sizeof(is_bridge));  // false表示非割边
    
    int n, m;
    cin >> n >> m;
    
    // 构建无向图邻接表
    // 每条无向边需要存储为两条有向边（正向和反向）
    // 边的编号从1开始，与输入顺序对应
    for (int i = 1; i <= m; i++) {
        int u, v;
        cin >> u >> v;
        
        // 正向边：u -> v
        // rev指向v的邻接表中当前边的位置（待后续填充）
        adj[u].push_back(Edge(v, i, adj[v].size()));
        
        // 反向边：v -> u
        // rev指向u的邻接表中正向边的位置
        adj[v].push_back(Edge(u, i, adj[u].size() - 1));
    }
    
    // 遍历所有连通块：处理非连通图场景
    // 面试问题：为什么要遍历所有节点？
    // 答：图可能不连通，需要从每个未访问的节点开始DFS
    for (int i = 1; i <= n; i++) {
        if (!dfn[i]) {
            tarjan(i, 0);  // edge_id = 0 表示没有需要排除的边（根节点）
        }
    }
    
    // 对割边按字典序排序
    sort(bridges.begin(), bridges.end());
    
    // 输出所有割边
    for (auto &bridge : bridges) {
        cout << bridge.first << " " << bridge.second << endl;
    }
    
    return 0;
}
```

## 代码逐行注释

### 核心注释要点

1. **dfn和low数组**：
   - `dfn[u]`：记录节点u在DFS中的访问顺序
   - `low[u]`：记录u及其子树能回溯到的最小dfn值

2. **割边判定**：`low[v] > dfn[u]` 意味着v无法回到u或u的祖先

3. **重边处理**：通过边编号 `id != edge_id` 排除反向边，而非通过父节点编号

4. **时间戳**：使用递增的时间戳记录DFS访问顺序

## 时间空间复杂度分析

- **时间复杂度**：O(n + m)
  - Tarjan算法每个节点访问一次，每条边访问两次
  - 排序：O(k log k)，k为割边数量

- **空间复杂度**：O(n + m)
  - 邻接表：O(n + m)
  - Tarjan数组：O(n)
  - 割边结果：O(k)
