# 洛谷-P8436-边双连通分量模板-入门

## 题目信息

- **题目链接**: https://www.luogu.com.cn/problem/P8436
- **难度**: 入门
- **考察点**: 边双连通分量(e-DCC)模板、Tarjan算法、割边判定

## 题目描述

### 题目背景

【模板】边双连通分量

### 题目描述

给定一个 n 个点 m 条边的无向图，求边双连通分量(e-dcc)数量。

### 输入格式

第一行，n, m
接下来 m 行，每行两个整数 u, v，表示一条无向边 (u, v)

### 输出格式

共一行，输出边双连通分量数量。

### 数据范围

对于 100% 的数据，n ≤ 5 × 10⁴, m ≤ 3 × 10⁵

### 样例输入

```
5 6
1 2
2 3
3 1
2 4
4 5
5 2
```

### 样例输出

```
2
```

## 笔试面试考察点分析

1. **Tarjan算法核心概念**：dfn数组和low数组的作用
2. **割边判定定理**：low[v] > dfn[u] 是割边的充要条件
3. **边双连通分量定义**：极大无边双通子图
4. **栈的应用**：通过栈保存遍历过程中的节点
5. **重边处理技巧**：通过边编号而非节点编号排除反向边

## 解题思路

### 步骤1：Tarjan算法求割边

使用Tarjan算法遍历图，维护两个核心数组：
- `dfn[u]`：节点u的发现时间（DFS序）
- `low[u]`：节点u及其子树能回溯到的最小dfn值

对于边(u, v)，如果`low[v] > dfn[u]`，则该边是割边。

### 步骤2：求边双连通分量

Tarjan算法中，当`dfn[u] == low[u]`时，从栈中弹出的节点构成一个e-DCC。

### 步骤3：统计结果

遍历所有连通块，统计e-DCC数量。

## 完整代码实现（C++）

```cpp
#include <bits/stdc++.h>
using namespace std;

// ==================== 边双连通分量模板 ====================
// 适用场景：求无向图中所有边双连通分量
// 考察点：Tarjan算法、割边判定、e-DCC定义
// 时间复杂度：O(n + m)
// 空间复杂度：O(n + m)

// 定义最大节点数和最大边数
// 根据题目数据范围：n ≤ 5e4, m ≤ 3e5
// 无向图每条边存两条有向边，故数组大小需乘2
const int MAXN = 50005;        // 最大节点数 + 5
const int MAXM = 300005;       // 最大边数

// 边的结构体：存储目标节点、边权（本题无需）、反向边索引、边编号
struct Edge {
    int to;     // 边的终点节点
    int w;      // 边权，带权图时使用
    int rev;    // 反向边在邻接表中的索引位置
    int id;     // 边的编号，从1开始唯一标识每条输入的边
    Edge(int _to, int _w, int _rev, int _id) : to(_to), w(_w), rev(_rev), id(_id) {}
};

// 邻接表：adj[u]存储从节点u出发的所有边
vector<Edge> adj[MAXN];

// Tarjan算法核心数组
// dfn[u]：节点u的发现时间（DFS序），0表示未访问
// low[u]：节点u及其子树中所有节点能回溯到的最小dfn值
int dfn[MAXN], low[MAXN];
int timestamp = 0;  // 全局时间戳，每访问一个新节点+1

// 标记数组：is_bridge[i] = true 表示编号为i的边是割边
bool is_bridge[MAXM];
int bridge_cnt = 0;  // 割边总数

// 边双连通分量相关数组
// e_dcc_id[u]：节点u所属的边双连通分量编号
// dcc_cnt：边双连通分量的总数
int e_dcc_id[MAXN];
int dcc_cnt = 0;

// 栈：用于在Tarjan过程中保存遍历过的节点
// 当dfn[u] == low[u]时，弹出栈中节点直到u，构成一个e-DCC
stack<int> st;

/**
 * Tarjan算法核心函数 - 求割边和边双连通分量
 * 
 * 核心原理：
 * 1. dfn[u]记录DFS遍历中节点的访问顺序
 * 2. low[u]记录节点u及其子树能回溯到的最早访问时间
 * 3. 当low[v] > dfn[u]时，边(u,v)是割边
 * 4. 当dfn[u] == low[u]时，从栈中弹出的节点构成一个e-DCC
 * 
 * 参数说明：
 * u: 当前访问的节点
 * edge_id: 从父节点到u的边编号，用于排除这条边的反向边（处理重边）
 */
void tarjan(int u, int edge_id) {
    // 初始化当前节点的时间戳
    // 节点首次访问时，dfn和low都设置为当前时间戳
    dfn[u] = low[u] = ++timestamp;
    
    // 将当前节点入栈，用于后续e-DCC的构建
    st.push(u);
    
    // 遍历节点u的所有邻接边
    for (auto &e : adj[u]) {
        int v = e.to;   // 边的终点
        int id = e.id;  // 边的编号
        
        // 判断邻接节点v是否已被访问
        if (!dfn[v]) {
            // 树边：v未被访问，递归进入v
            // 传入当前边编号id，用于在v中排除这条边的反向边
            tarjan(v, id);
            
            // 回溯阶段：用子节点v的low值更新父节点u的low值
            // low[u] = min(low[u], low[v]) 表示u及其子树能追溯到的最早节点
            low[u] = min(low[u], low[v]);
            
            // 割边判定定理：low[v] > dfn[u]
            // 含义：子节点v无法通过任何回边回到父节点u或u的祖先
            // 因此删除边(u,v)后，v所在的子树将与图的其他部分断开
            if (low[v] > dfn[u]) {
                is_bridge[id] = true;  // 标记该边为割边
                bridge_cnt++;           // 割边数量+1
            }
        } 
        // 已访问的节点：可能是回边或弃边
        // 需要排除当前边的反向边（处理重边场景）
        else if (id != edge_id) {
            // 用已访问节点的发现时间更新low[u]
            // 这是Tarjan算法中处理回边的标准做法
            low[u] = min(low[u], dfn[v]);
        }
    }
    
    // 判断是否发现一个新的边双连通分量
    // 当dfn[u] == low[u]时，u是某个e-DCC的根
    // 从栈中弹出节点直到u，这些节点构成一个完整的e-DCC
    if (dfn[u] == low[u]) {
        dcc_cnt++;  // e-DCC数量+1
        int pop;
        // 弹出栈中节点直到u
        do {
            pop = st.top();
            st.pop();
            e_dcc_id[pop] = dcc_cnt;  // 标记节点所属的e-DCC
        } while (pop != u);
    }
}

/**
 * 主函数 - 程序入口
 */
int main() {
    // 初始化核心数组，避免脏数据
    memset(dfn, 0, sizeof(dfn));
    memset(is_bridge, false, sizeof(is_bridge));
    
    int n, m;
    cin >> n >> m;
    
    // 构建无向图邻接表
    // 每条无向边需要存储为两条有向边（正向和反向）
    for (int i = 1; i <= m; i++) {
        int u, v;
        cin >> u >> v;
        // 正向边：u -> v
        // rev指向v的邻接表中当前边的位置（待后续填充）
        adj[u].push_back(Edge(v, 0, adj[v].size(), i));
        // 反向边：v -> u
        // rev指向u的邻接表中正向边的位置
        adj[v].push_back(Edge(u, 0, adj[u].size() - 1, i));
    }
    
    // 遍历所有连通块，处理非连通图
    for (int i = 1; i <= n; i++) {
        if (!dfn[i]) {
            tarjan(i, 0);  // edge_id = 0 表示没有需要排除的边
        }
    }
    
    // 输出边双连通分量总数
    cout << dcc_cnt << endl;
    
    return 0;
}
```

## 代码逐行注释

### 核心注释要点

1. **dfn和low数组**：
   - `dfn[u]`：记录节点u在DFS中的访问顺序
   - `low[u]`：记录u及其子树能回溯到的最小dfn值

2. **割边判定**：`low[v] > dfn[u]`意味着v无法回到u或u的祖先

3. **e-DCC判定**：`dfn[u] == low[u]`时，从栈中弹出节点构成e-DCC

4. **重边处理**：通过边编号`id != edge_id`排除反向边，而非通过父节点编号

## 时间空间复杂度分析

- **时间复杂度**：O(n + m)
  - Tarjan算法每个节点访问一次，每条边访问两次
  - 割边判定和e-DCC构建都是O(1)操作

- **空间复杂度**：O(n + m)
  - 邻接表：O(n + m)
  - Tarjan数组：O(n)
  - 栈：O(n)
