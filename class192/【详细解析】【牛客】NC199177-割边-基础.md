### 1.2 题目描述

给定一个无向图，求图中的割边（桥）数量。

**输入格式**：
- 第一行：n, m
- 接下来 m 行：u, v

**输出格式**：
- 输出割边的数量

## 三、解题思路

### 算法流程

```
1. 读取 n, m，构建无向图邻接表
2. 遍历所有未访问节点（处理非连通图）
3. Tarjan 算法求割边
4. 统计割边数量并输出
```

### 割边判定

```cpp
// 割边判定：low[v] > dfn[u]
if (low[v] > dfn[u]) {
    bridgeCount++;  // 割边数量+1
}
```

## 四、代码实现

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 100005;
const int MAXM = 200005;

struct Edge {
    int to;      // 边的终点
    int next;    // 下一条边
    int id;      // 边编号
};

Edge edges[MAXM << 1];
int head[MAXN];
int cnt = 0;

int dfn[MAXN];
int low[MAXN];
int timestamp = 0;
int bridgeCount = 0;

// 添加无向边
void addEdge(int u, int v) {
    edges[cnt].to = v;
    edges[cnt].next = head[u];
    edges[cnt].id = cnt;
    head[u] = cnt++;
    
    edges[cnt].to = u;
    edges[cnt].next = head[v];
    edges[cnt].id = cnt;
    head[v] = cnt++;
}

// Tarjan求割边
void tarjan(int u, int parentEdge) {
    dfn[u] = low[u] = ++timestamp;
    
    for (int e = head[u]; e != -1; e = edges[e].next) {
        int v = edges[e].to;
        int id = edges[e].id;
        
        // 用边编号跳过父边，兼容重边
        if (id == parentEdge) continue;
        
        if (!dfn[v]) {
            tarjan(v, id);
            low[u] = min(low[u], low[v]);
            
            // 割边判定
            if (low[v] > dfn[u]) {
                bridgeCount++;
            }
        } else {
            low[u] = min(low[u], dfn[v]);
        }
    }
}

int main() {
    memset(head, -1, sizeof(head));
    memset(dfn, 0, sizeof(dfn));
    
    int n, m;
    if (!(cin >> n >> m)) return 0;
    
    for (int i = 0; i < m; i++) {
        int u, v;
        cin >> u >> v;
        addEdge(u, v);
    }
    
    // 遍历所有连通块
    for (int i = 1; i <= n; i++) {
        if (!dfn[i]) {
            tarjan(i, -1);
        }
    }
    
    cout << bridgeCount << endl;
    return 0;
}
```

## 六、面试要点

### 必考点

1. **割边判定**：low[v] > dfn[u]
2. **重边处理**：用边编号，不是父节点编号
3. **非连通图**：遍历所有未访问节点

### 面试话术

```
"我使用 Tarjan 算法求割边。
核心是维护 dfn 和 low 两个数组。
dfn[u] 是 u 被访问的时间戳，
low[u] 是 u 能回溯到的最早时间戳。

对于边 (u,v)，如果 low[v] > dfn[u]，
说明 v 无法回到 u 或更早的节点，
则该边是割边。

需要注意重边情况，必须用边编号来判断反向边。"
```
