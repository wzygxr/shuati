## 三、基础模板题

### 1. 割边（桥）模板

**题目**：给定无向图，求所有割边。

**核心代码**：

```cpp
// Tarjan求割边（兼容重边）
void tarjan(int u, int preEdge) {
    dfn[u] = low[u] = ++timestamp;
    for (auto &e : adj[u]) {
        int v = e.to, id = e.id;
        if (id == preEdge) continue; // 跳过父边
        if (!dfn[v]) {
            tarjan(v, id);
            low[u] = min(low[u], low[v]);
            if (low[v] > dfn[u]) {
                // (u, v) 是割边
                isBridge[id] = true;
            }
        } else {
            low[u] = min(low[u], dfn[v]);
        }
    }
}
```

### 2. 边双连通分量模板

**题目**：求所有边双连通分量并缩点。

**核心代码**：

```cpp
// 求边双连通分量
void dfs_dcc(int u) {
    belong[u] = dccCnt;
    for (auto &e : adj[u]) {
        int v = e.to, id = e.id;
        if (!belong[v] && !isBridge[id]) {
            dfs_dcc(v);
        }
    }
}

// 缩点构建树
void shrink() {
    for (int i = 1; i <= n; i++) {
        if (!belong[i]) {
            ++dccCnt;
            dfs_dcc(i);
        }
    }
    // 构建新树
    for (int u = 1; u <= n; u++) {
        for (auto &e : adj[u]) {
            int v = e.to, id = e.id;
            if (isBridge[id] && belong[u] != belong[v]) {
                tree[belong[u]].push_back(belong[v]);
            }
        }
    }
}
```

## 四、进阶综合题

### 1. 边双+树上差分

**题目**：给定多对点，求路径覆盖的割边数量。

**解法**：
- 边双缩点得到树
- 树上差分统计路径经过次数
- 统计被覆盖的割边

### 2. 边双+树形DP

**题目**：树上选择节点，求割边权值最大路径。

**解法**：
- 边双缩点
- 树形DP求最优路径

### 3. 边双+二分答案

**题目**：求满足某种条件的最小割边权值。

**解法**：
- 边双缩点
- 二分+树DP验证

## 五、面试高频题

### 1. 基础概念

| 问题 | 答案要点 |
|------|----------|
| 什么是割边？ | 删除后图不连通的边 |
| 什么是边双？ | 任意两边可分离的极大子图 |
| 割边判定条件？ | low[v] > dfn[u] |
| 边双如何求？ | Tarjan+弹栈 |

### 2. 进阶问题

| 问题 | 答案要点 |
|------|----------|
| 重边如何处理？ | 用边编号而非父节点 |
| 为什么缩点是树？ | 割边不形成环 |
| 边双vs点双？ | 边分离vs点分离 |
| 如何O(1)判割边？ | low数组+时间戳 |

### 3. 复杂度问题

| 问题 | 答案要点 |
|------|----------|
| Tarjan时间？ | O(n+m) |
| 缩点后操作？ | O(n)或O(nlogn) |
| 空间复杂度？ | O(n+m) |
