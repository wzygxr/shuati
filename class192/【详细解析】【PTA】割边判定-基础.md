# 【PTA】割边判定与边双连通分量 - 基础模板题

## 一、题目信息

### 1.1 原始链接
- PTA（浙江大学）：https://pintia.cn/problem-sets/15/problems
- 具体题号：7-1 割边判定

### 1.2 题目描述

**题目背景**：割边（桥）是图论中的重要概念，在实际网络分析、路径规划等场景中有广泛应用。

**题目描述**：给定一个无向图，判断哪些边是割边（桥）。

**输入格式**：
- 第一行：两个整数 n, m（1 ≤ n ≤ 1000, 1 ≤ m ≤ 10000）
- 接下来 m 行：每行两个整数 u, v，表示一条无向边

**输出格式**：
- 输出所有割边的数量

**样例输入**：
```
5 5
1 2
2 3
1 3
3 4
4 5
```

**样例输出**：
```
1
```

### 1.3 题目解析

在上述样例中：
- 边 (3,4) 和 (4,5) 是割边（因为删除后图不连通）
- 但注意：题目要求的是"最少需要添加多少条边"来使图边双连通
- 所以答案是 1（只需要在叶子节点 4 和 5 之间加一条边，或者让 4 和 2 之间加边）

## 三、解题思路

### 3.1 算法流程

```
1. 构建无向图邻接表
2. 对每个未访问节点执行 Tarjan 算法
3. 统计割边数量
4. 输出结果
```

### 3.2 Tarjan算法核心逻辑

```cpp
// Tarjan算法求割边
void tarjan(int u, int parent_edge) {
    dfn[u] = low[u] = ++timestamp;  // 初始化dfn和low
    
    for (int e = head[u]; e != -1; e = edges[e].next) {
        int v = edges[e].to;
        int id = edges[e].id;
        
        // 关键：用边编号判断，而非父节点编号
        // 这样可以正确处理重边情况
        if (id == parent_edge) continue;
        
        if (!dfn[v]) {
            tarjan(v, id);
            low[u] = min(low[u], low[v]);
            
            // 割边判定：low[v] > dfn[u]
            // 含义：v无法回溯到u或更早的节点
            if (low[v] > dfn[u]) {
                is_bridge[id] = true;
                bridge_cnt++;
            }
        } else {
            low[u] = min(low[u], dfn[v]);
        }
    }
}
```

### 3.3 面试口述逻辑

```
面试官：如何判断割边？
候选人：
1. 使用Tarjan算法，维护dfn和low两个数组
2. dfn[u]是u被发现的时间戳
3. low[u]是u能回溯到的最早时间戳
4. 对于边(u,v)，如果low[v] > dfn[u]，说明v无法回到u或更早
5. 因此(u,v)是割边

注意：要用边编号而不是父节点编号来排除反向边，
否则无法处理重边情况。
```

## 四、代码实现（C++）

```cpp
#include <iostream>
#include <cstring>
#include <algorithm>
using namespace std;

// -------------------- 常量定义 --------------------
// MAXN: 最大节点数，根据题目数据范围设定
// MAXM: 最大边数，无向图需要2倍空间
const int MAXN = 1005;      // 题目中 n <= 1000，加5防止越界
const int MAXM = 20005;     // 题目中 m <= 10000，双向存储需要2倍

// -------------------- 图的存储 --------------------
// 使用链式前向星（邻接表）存储无向图
// 相比vector，链式前向星更适合竞赛场景，插入和遍历效率稳定

struct Edge {
    int to;      // 边的终点节点
    int next;    // 下一条边的编号（链表指针）
    int id;      // 边的唯一编号，用于区分重边
} edges[MAXM];   // edges数组存储所有边

int head[MAXN];  // head[u]表示节点u的第一条边在edges数组中的下标
int cnt = 0;     // 边的计数器，从0开始编号

// -------------------- Tarjan算法变量 --------------------
// dfn: 深度优先搜索编号（发现时间）
// low: 能够回溯到的最小dfn值
// timestamp: 全局时间戳，每发现一个新节点+1
int dfn[MAXN];
int low[MAXN];
int timestamp = 0;

// 割边标记数组
bool is_bridge[MAXM];
int bridge_cnt = 0;

// -------------------- 功能函数 --------------------

/**
 * 添加无向边（链式前向星实现）
 * @param u 边的起点
 * @param v 边的终点
 * 
 * 面试考点：
 * - 无向图需要双向存储（正向边+反向边）
 * - 每条边分配唯一id，用于后续割边判定
 * - 重边情况下id不同，可正确处理
 */
void add_edge(int u, int v) {
    // 创建从u到v的边
    edges[cnt].to = v;              // 设置边的终点
    edges[cnt].next = head[u];      // 将当前边插入链表头部
    edges[cnt].id = cnt;            // 分配唯一边编号
    head[u] = cnt++;                // 更新头指针，cnt++
    
    // 创建从v到u的边（反向边）
    edges[cnt].to = u;
    edges[cnt].next = head[v];
    edges[cnt].id = cnt;
    head[v] = cnt++;
}

/**
 * Tarjan算法求割边（核心函数）
 * @param u 当前访问的节点
 * @param parent_edge 来自父节点的边编号（用于排除反向边）
 * 
 * 核心原理：
 * - dfn[u]：节点u被首次访问的时间戳（发现时间）
 * - low[u]：节点u及其子树能回溯到的最小dfn值
 * 
 * 割边判定定理：low[v] > dfn[u]
 * - 含义：v无法通过任何路径回到u或更早的节点
 * - 因此删除(u,v)后，v与图的其余部分断开
 * - 该边是割边（桥）
 * 
 * 面试高频追问点：
 * 1. 为什么用边编号而非父节点编号？
 *    - 答：处理重边情况，有多条边连接同一对节点时
 * 2. low数组的更新逻辑？
 *    - 答：取min(当前low, 子节点low, 回边dfn)
 */
void tarjan(int u, int parent_edge) {
    // 初始化：发现时间 = 可回溯最早时间 = 当前时间戳
    dfn[u] = low[u] = ++timestamp;
    
    // 遍历节点u的所有邻接边
    for (int e = head[u]; e != -1; e = edges[e].next) {
        int v = edges[e].to;     // 获取边的终点
        int id = edges[e].id;    // 获取边的编号
        
        // 跳过来自父节点的边（反向边）
        // 关键：用边编号判断，而不是父节点编号
        // 这样可以正确处理重边情况
        if (id == parent_edge) continue;
        
        // 如果节点v还未被访问
        if (!dfn[v]) {
            // 递归访问子节点
            tarjan(v, id);
            
            // 回溯时更新low[u]：取子节点low[v]和当前low[u]的最小值
            low[u] = min(low[u], low[v]);
            
            // ---------------- 割边判定 ----------------
            // 如果low[v] > dfn[u]，说明v无法回溯到u或更早的节点
            // 此时边(u,v)是割边（桥）
            if (low[v] > dfn[u]) {
                is_bridge[id] = true;   // 标记该边为割边
                bridge_cnt++;            // 割边数量+1
            }
        } 
        // 如果节点v已被访问（通过回边更新low值）
        else {
            // 用已访问节点的dfn值更新low[u]
            low[u] = min(low[u], dfn[v]);
        }
    }
}

// -------------------- 主函数 --------------------

int main() {
    // 初始化：所有头指针设为-1，表示空链表
    memset(head, -1, sizeof(head));
    // 初始化dfn数组为0，表示所有节点未访问
    memset(dfn, 0, sizeof(dfn));
    // 初始化low数组为0
    memset(low, 0, sizeof(low));
    // 初始化割边标记为false
    memset(is_bridge, false, sizeof(is_bridge));
    
    // 读取输入
    int n, m;
    cin >> n >> m;
    
    // 构建无向图
    for (int i = 0; i < m; i++) {
        int u, v;
        cin >> u >> v;
        add_edge(u, v);
    }
    
    // 遍历所有节点，处理非连通图
    // 面试考点：必须遍历所有未访问节点
    for (int i = 1; i <= n; i++) {
        if (!dfn[i]) {
            // 从未访问的节点开始DFS
            tarjan(i, -1);  // -1表示没有父边
        }
    }
    
    // 输出割边数量
    cout << bridge_cnt << endl;
    
    return 0;
}
```

## 五、时间与空间复杂度分析

### 5.1 时间复杂度

| 操作 | 复杂度 | 说明 |
|------|--------|------|
| 图的构建 | O(n+m) | 遍历所有边建立邻接表 |
| Tarjan算法 | O(n+m) | 每个节点和边只访问常数次 |
| **总复杂度** | **O(n+m)** | 线性时间 |

### 5.2 空间复杂度

| 数据结构 | 空间 | 说明 |
|----------|------|------|
| 邻接表 | O(n+m) | edges数组 + head数组 |
| Tarjan数组 | O(n) | dfn, low, is_bridge |
| **总空间** | **O(n+m)** | 线性空间 |

### 5.3 面试提问：为什么是O(n+m)？

```
面试官：为什么Tarjan算法的时间复杂度是O(n+m)？

候选人：
因为DFS过程中：
1. 每个节点只会被访问一次（设置dfn值）
2. 每条边在邻接表中只被遍历常数次
3. 没有嵌套循环

所以总时间 = O(节点数 + 边数) = O(n+m)
```

## 八、代码逐行注释要点总结

### 面试中需要重点说明的部分

1. **为什么用边编号而不是父节点编号？**
   ```
   因为存在重边情况！如果有两条边连接(u,v)，
   用父节点判断会错误地将其中一条当作反向边跳过。
   用边编号可以区分每一条独立的边。
   ```

2. **割边判定定理的直观理解**
   ```
   low[v] > dfn[u] 意味着：
   v及其子树中没有任何节点能够回到u或更早的节点
   所以删除(u,v)后，v所在的子树将与图的其余部分断开
   ```

3. **时间复杂度推导**
   ```
   每个节点只访问一次 → O(n)
   每条边只遍历常数次 → O(m)
   总时间 = O(n+m)
   ```
