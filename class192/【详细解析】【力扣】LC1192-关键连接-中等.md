# 【力扣】LC1192 - 关键连接（Critical Connections）

## 一、题目信息

### 1.1 原始链接
- 力扣（LeetCode）：https://leetcode.cn/problems/critical-connections-in-a-network/
- 题目难度：中等

### 1.2 题目描述

**题目背景**：在计算机网络中，关键连接指的是通信网络中的关键链路。

**题目描述**：
- 给定 n 个服务器，编号为 0 到 n-1
- 给定 connections[i] = [u, v]，表示服务器 u 和 v 之间的直接连接
- 返回所有关键连接（割边）

**输入格式**：
- n：服务器数量
- connections：二维数组，每行是 [u, v]

**输出格式**：
- 返回所有割边

**样例输入**：
```
n = 4
connections = [[0,1],[1,2],[2,0],[1,3]]
```

**样例输出**：
```
[[1,3]]
```

**样例解释**：
- 边 (1,3) 是割边，因为去掉它后，服务器3无法与其他服务器通信

## 三、解题思路

### 3.1 算法流程

```
1. 构建邻接表
2. 遍历所有未访问节点
3. Tarjan算法求割边
4. 收集结果并排序
```

### 3.2 核心原理

**Tarjan割边算法**：
- dfn[u]：节点u被发现的时间
- low[u]：u能回溯到的最小时间
- 割边判定：low[v] > dfn[u]

## 四、代码实现

### 4.1 Python实现

```python
from collections import defaultdict
from typing import List

class Solution:
    def criticalConnections(self, n: int, connections: List[List[int]]) -> List[List[int]]:
        # 邻接表
        graph = defaultdict(list)
        for u, v in connections:
            graph[u].append(v)
            graph[v].append(u)
        
        # Tarjan变量
        dfn = [-1] * n      # 发现时间
        low = [-1] * n      # 最低可达时间
        self.time = 0
        
        # 结果
        bridges = []
        
        def tarjan(u: int, parent: int):
            dfn[u] = low[u] = self.time
            self.time += 1
            
            for v in graph[u]:
                if dfn[v] == -1:  # 未访问
                    tarjan(v, u)
                    low[u] = min(low[u], low[v])
                    
                    # 割边判定
                    if low[v] > dfn[u]:
                        bridges.append([u, v])
                elif v != parent:  # 回边（排除父节点）
                    low[u] = min(low[u], dfn[v])
        
        # 遍历所有连通块
        for i in range(n):
            if dfn[i] == -1:
                tarjan(i, -1)
        
        # 排序结果
        bridges.sort()
        return bridges
```

### 4.2 Java实现

```java
import java.util.*;

class Solution {
    // 邻接表
    List<Integer>[] graph;
    // Tarjan变量
    int[] dfn, low;
    int timestamp = 0;
    // 结果
    List<List<Integer>> bridges;
    // 节点是否访问过
    boolean[] visited;
    
    public List<List<Integer>> criticalConnections(int n, List<List<Integer>> connections) {
        // 初始化
        graph = new ArrayList[n];
        for (int i = 0; i < n; i++) {
            graph[i] = new ArrayList<>();
        }
        
        // 构建邻接表
        for (List<Integer> conn : connections) {
            int u = conn.get(0);
            int v = conn.get(1);
            graph[u].add(v);
            graph[v].add(u);
        }
        
        dfn = new int[n];
        low = new int[n];
        visited = new boolean[n];
        bridges = new ArrayList<>();
        Arrays.fill(dfn, -1);
        
        // Tarjan
        for (int i = 0; i < n; i++) {
            if (dfn[i] == -1) {
                tarjan(i, -1);
            }
        }
        
        return bridges;
    }
    
    private void tarjan(int u, int parent) {
        dfn[u] = low[u] = timestamp++;
        visited[u] = true;
        
        for (int v : graph[u]) {
            if (v == parent) continue;  // 跳过父节点
            
            if (!visited[v]) {
                tarjan(v, u);
                low[u] = Math.min(low[u], low[v]);
                
                // 割边判定
                if (low[v] > dfn[u]) {
                    bridges.add(Arrays.asList(u, v));
                }
            } else {
                low[u] = Math.min(low[u], dfn[v]);
            }
        }
    }
}
```

### 4.3 C++实现

```cpp
#include <vector>
#include <iostream>
using namespace std;

class Solution {
public:
    // 邻接表
    vector<vector<int>> graph;
    // Tarjan变量
    vector<int> dfn, low;
    int timestamp = 0;
    // 结果
    vector<vector<int>> bridges;
    
    vector<vector<int>> criticalConnections(int n, vector<vector<int>>& connections) {
        graph.resize(n);
        
        // 构建邻接表
        for (auto& conn : connections) {
            int u = conn[0], v = conn[1];
            graph[u].push_back(v);
            graph[v].push_back(u);
        }
        
        dfn.assign(n, -1);
        low.assign(n, 0);
        
        // Tarjan
        for (int i = 0; i < n; i++) {
            if (dfn[i] == -1) {
                tarjan(i, -1);
            }
        }
        
        return bridges;
    }
    
    void tarjan(int u, int parent) {
        dfn[u] = low[u] = timestamp++;
        
        for (int v : graph[u]) {
            if (v == parent) continue;  // 跳过父节点
            
            if (dfn[v] == -1) {
                tarjan(v, u);
                low[u] = min(low[u], low[v]);
                
                // 割边判定
                if (low[v] > dfn[u]) {
                    bridges.push_back({u, v});
                }
            } else {
                low[u] = min(low[u], dfn[v]);
            }
        }
    }
};
```

```

候选人：
使用Tarjan算法，维护dfn和low两个数组。
dfn[u]是u被发现的时间，low[u]是u能回溯到的最小时间。
对于边(u,v)，如果low[v] > dfn[u]，说明v无法回到u或更早，
则该边是割边。
```
