# 【洛谷】P3388 - 割点与桥（模板题）

## 一、题目信息

### 1.1 原始链接
- 洛谷：https://www.luogu.com.cn/problem/P3388
- 原题可能来源于其他OJ

### 1.2 题目描述

给定一张无向图，输出图中所有的割点（割顶）和割边（桥）。

**输入格式**：
- 第一行：两个整数 n, m（1 ≤ n ≤ 10^5, 1 ≤ m ≤ 10^6）
- 接下来 m 行：每行两个整数 u, v，表示一条无向边

**输出格式**：
- 第一行：一个整数 k，表示割点数量
- 第二行：k 个割点编号（按从小到大排序）
- 第三行：一个整数 l，表示割边数量
- 接下来 l 行：每行一条割边的两个端点（按端点字典序排序）

**数据范围**：
- n ≤ 10^5, m ≤ 10^6
- 图可能不连通

### 1.3 样例输入

```
6 7
1 2
1 3
1 4
2 5
3 5
4 5
5 6
```

### 1.4 样例输出

```
2
1 5
3
1 2
1 4
5 6
```

## 三、解题思路

### 3.1 算法流程

```
1. 建立邻接表存储无向图
2. 遍历所有未访问节点（处理非连通图）
3. 对每个连通块执行 Tarjan 算法
   - 计算 dfn[u] 和 low[u]
   - 判定割边：low[v] > dfn[u]
   - 判定割点：low[v] >= dfn[u]（根节点需特殊处理）
4. 输出结果
```

### 3.2 割边判定定理证明

**定理**：在无向图中，边 (u, v)（u 是 v 的父节点）是割边，当且仅当 low[v] > dfn[u]。

**证明**：
- low[v] 表示 v 及 v 的子树能回溯到的最早节点时间戳
- 如果 low[v] > dfn[u]，说明 v 无法通过任何路径回到 u 或更早的节点
- 因此删除边 (u, v) 后，v 所在子树与图的其余部分断开
- 该边为割边

### 3.3 面试口述逻辑

```
面试官：如何求割边？
候选人：使用 Tarjan 算法，核心是维护两个数组 dfn 和 low。
        dfn[u] 是 u 被首次访问的时间戳，
        low[u] 是 u 能回溯到的最早时间戳。
        
        对于边 (u, v)，如果 low[v] > dfn[u]，说明 v 无法回到 u 或更早，
        那么 (u, v) 就是割边。
        
        需要注意重边情况，不能用父节点编号排除反向边，
        必须用边编号来判断。
```

## 四、代码实现（C++）

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
#include <cstring>
using namespace std;

// -------------------- 变量定义 --------------------

// 最大节点数和最大边数（无向图需2倍空间）
const int MAXN = 100005;      // 最大节点数，加1用于数组下标从1开始
const int MAXM = 1000005;     // 最大边数，乘2用于无向图存储

// 链式前向星邻接表
struct Edge {
    int to;     // 边的终点节点
    int next;  // 下一条边的编号
    int id;    // 边的唯一编号，用于区分重边
} edges[MAXM << 1];  // 无向图需要2倍的边空间

int head[MAXN];       // head[u]表示节点u的第一条边在edges数组中的下标
int cnt = 0;          // 边的计数器，从0或1开始

// Tarjan算法核心数组
int dfn[MAXN];        // dfn[u]：节点u被访问的时间戳（发现时间）
int low[MAXN];        // low[u]：节点u及其子树能回溯到的最早dfn值
int timestamp = 0;    // 全局时间戳计数器

// 割边和割点标记
bool is_bridge[MAXM];        // is_bridge[id]：标记编号为id的边是否为割边
bool is_cut_vertex[MAXN];    // is_cut_vertex[u]：标记节点u是否为割点

// -------------------- 核心函数 --------------------

/**
 * 添加无向边到邻接表
 * @param u 边的起点
 * @param v 边的终点
 * 
 * 面试考点：
 * - 无向图需要双向存储
 * - 每条边分配唯一id，用于后续割边判定
 * - 重边情况下，id不同，可正确处理
 */
void add_edge(int u, int v) {
    // 创建从u到v的边
    edges[cnt].to = v;           // 设置边的终点为v
    edges[cnt].next = head[u];   // 将当前边插入到邻接表头部
    edges[cnt].id = cnt;         // 分配唯一边编号
    head[u] = cnt++;             // 更新头指针，指向新边
    
    // 创建从v到u的边（反向边）
    edges[cnt].to = u;            // 设置边的终点为u
    edges[cnt].next = head[v];    // 将当前边插入到邻接表头部
    edges[cnt].id = cnt;         // 分配唯一边编号（与正向边不同）
    head[v] = cnt++;             // 更新头指针，指向新边
}

/**
 * Tarjan算法求割边和割点
 * @param u 当前访问的节点
 * @param parent_edge 来自父节点的边编号（用于排除反向边）
 * @param is_root 当前节点是否为DFS树的根节点
 * 
 * 核心原理：
 * - dfn[u]：u被发现的时间
 * - low[u]：u能回溯到的最小dfn（包括通过回边和非父边的树边）
 * 
 * 割边判定：low[v] > dfn[u]，即v无法绕回u或更早的节点
 * 割点判定：low[v] >= dfn[u]（根节点需特殊处理）
 */
void tarjan(int u, int parent_edge, bool is_root) {
    dfn[u] = low[u] = ++timestamp;    // 初始化：发现时间 = 可回溯最早时间 = 当前时间戳
    
    int child_count = 0;              // 统计当前节点的子节点数量（用于根节点割点判定）
    
    // 遍历节点u的所有邻接边
    for (int e = head[u]; e != -1; e = edges[e].next) {
        int v = edges[e].to;          // 获取边的终点节点
        int edge_id = edges[e].id;    // 获取边的唯一编号
        
        // 如果这条边是来自父节点的边（反向边），跳过
        // 注意：这里用边编号判断，而不是父节点编号，可以正确处理重边情况
        if (edge_id == parent_edge) {
            continue;
        }
        
        // 如果节点v还未被访问
        if (dfn[v] == 0) {
            child_count++;             // 子节点数量+1
            
            // 递归访问子节点，传入当前边的编号作为父边
            tarjan(v, edge_id, false);
            
            // 回溯时更新low[u]：取子节点low[v]和当前low[u]的最小值
            low[u] = min(low[u], low[v]);
            
            // ---------------- 割边判定 ----------------
            // 如果 low[v] > dfn[u]，说明v无法回溯到u或更早的节点
            // 此时边(u,v)是割边（桥）
            if (low[v] > dfn[u]) {
                is_bridge[edge_id] = true;   // 标记该边为割边
            }
            
            // ---------------- 割点判定 ----------------
            // 如果 low[v] >= dfn[u]，说明v无法回溯到u之前的节点
            // 此时u是割点（但根节点需要特殊处理）
            if (!is_root && low[v] >= dfn[u]) {
                is_cut_vertex[u] = true;     // 标记u为割点
            }
        } 
        // 如果节点v已被访问（通过回边更新low值）
        else {
            // 用已访问节点的dfn值更新low[u]
            low[u] = min(low[u], dfn[v]);
        }
    }
    
    // 根节点特殊处理：如果根节点有超过1个子节点，则根节点是割点
    if (is_root && child_count > 1) {
        is_cut_vertex[u] = true;
    }
}

/**
 * 收集割边结果
 * @param result 存储割边结果的向量，每条割边用两个端点表示
 */
void collect_bridges(vector<pair<int, int>>& result) {
    // 遍历所有边，收集割边
    for (int i = 0; i < cnt; i++) {
        if (is_bridge[i]) {
            // 对于每条割边，获取其两个端点
            // 注意：无向图中，一条割边存储两次（正向和反向）
            // 这里只取编号较小的那条（偶数编号），避免重复
            if (edges[i].id % 2 == 0) {
                result.push_back({edges[i].to, edges[i ^ 1].to});
            }
        }
    }
}

// -------------------- 主函数 --------------------

int main() {
    // 初始化
    memset(head, -1, sizeof(head));    // 初始化邻接表头指针为-1
    memset(dfn, 0, sizeof(dfn));       // 初始化dfn数组为0（表示未访问）
    memset(low, 0, sizeof(low));       // 初始化low数组为0
    memset(is_bridge, false, sizeof(is_bridge));   // 初始化割边标记
    memset(is_cut_vertex, false, sizeof(is_cut_vertex)); // 初始化割点标记
    
    // 读取输入
    int n, m;
    cin >> n >> m;
    
    // 构建无向图
    for (int i = 0; i < m; i++) {
        int u, v;
        cin >> u >> v;
        add_edge(u, v);
    }
    
    // 遍历所有节点，处理非连通图
    for (int i = 1; i <= n; i++) {
        if (dfn[i] == 0) {
            // 从未访问的节点开始DFS
            tarjan(i, -1, true);
        }
    }
    
    // 收集割点结果
    vector<int> cut_vertices;
    for (int i = 1; i <= n; i++) {
        if (is_cut_vertex[i]) {
            cut_vertices.push_back(i);
        }
    }
    
    // 收集割边结果
    vector<pair<int, int>> bridges;
    collect_bridges(bridges);
    
    // 按端点字典序排序割边
    sort(bridges.begin(), bridges.end(), [](const pair<int,int>& a, const pair<int,int>& b) {
        if (a.first != b.first) return a.first < b.first;
        return a.second < b.second;
    });
    
    // 输出结果
    cout << cut_vertices.size() << endl;
    for (size_t i = 0; i < cut_vertices.size(); i++) {
        if (i > 0) cout << " ";
        cout << cut_vertices[i];
    }
    if (!cut_vertices.empty()) cout << endl;
    
    cout << bridges.size() << endl;
    for (auto& e : bridges) {
        cout << e.first << " " << e.second << endl;
    }
    
    return 0;
}
```

## 五、时间与空间复杂度分析

### 5.1 时间复杂度

| 操作 | 复杂度 | 说明 |
|------|--------|------|
| 图的构建 | O(n+m) | 遍历所有边建立邻接表 |
| Tarjan算法 | O(n+m) | 每个节点和每条边只访问常数次 |
| 结果排序 | O(k log k) | k为割边数量 |
| **总复杂度** | **O(n+m)** | 线性时间 |

### 5.2 空间复杂度

| 数据结构 | 空间 | 说明 |
|----------|------|------|
| 邻接表 | O(n+m) | edges数组2*m + head数组n |
| Tarjan数组 | O(n) | dfn, low, is_cut_vertex |
| 割边标记 | O(m) | is_bridge数组 |
| **总空间** | **O(n+m)** | 线性空间 |

### 5.3 面试提问：为什么是O(n+m)？

```
面试官：为什么Tarjan算法的时间复杂度是O(n+m)？
候选人：
因为在DFS过程中，每个节点只会被访问一次（设置dfn值），
每条边也只会被遍历常数次（在邻接表中检查）。
具体来说：
1. 对于树边，会递归处理子节点
2. 对于回边，会更新low值
3. 每条边的检查是O(1)的

所以总时间 = O(节点数 + 边数) = O(n+m)
```

## 八、代码逐行注释要点总结

### 面试中需要重点说明的部分

1. **为什么用边编号而不是父节点编号？**
   ```
   因为存在重边情况！如果有两条边连接(u,v)，
   用父节点判断会错误地将其中一条当作反向边跳过。
   用边编号可以区分每一条独立的边。
   ```

2. **割边判定定理的直观理解**
   ```
   low[v] > dfn[u] 意味着：
   v及其子树中没有任何节点能够回到u或更早的节点
   所以删除(u,v)后，v所在的子树将与图的其余部分断开
   ```

3. **割点判定与根节点特殊处理**
   ```
   根节点是割点的条件是：有 >= 2 个子节点
   因为根节点没有父边，无法通过low[v] >= dfn[u]判断
   ```
