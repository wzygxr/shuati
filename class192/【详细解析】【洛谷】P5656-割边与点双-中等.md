# 【洛谷】P5656 - 割边与点双（边双vs点双对比）

## 一、题目信息

### 1.1 原始链接
- 洛谷：https://www.luogu.com.cn/problem/P5656
- 难度：中等

### 1.2 题目描述

给定一张无向图，求出所有的割边、割点、边双连通分量和点双连通分量。

**输入格式**：
- n, m
- m行：u, v

**输出格式**：
- 割边数量
- 割边列表
- 割点数量
- 割点列表
- 边双连通分量数量
- 点双连通分量数量

---

## 二、核心考察点

| 考察点 | 说明 |
|--------|------|
| 割边判定 | low[v] > dfn[u] |
| 割点判定 | low[v] >= dfn[u]（根节点除外） |
| 边双连通分量 | 任意两边可分离 |
| 点双连通分量 | 任意两点可分离 |
| 双连通对比 | 边分离 vs 点分离 |

---

## 三、边双vs点双对比

### 3.1 定义对比

| 类型 | 分离对象 | 关键元素 | 内部结构 |
|------|----------|----------|----------|
| 边双 | 边 | 割边 | 必有环 |
| 点双 | 点 | 割点 | 可能为树 |

### 3.2 面试高频提问

**Q: 边双和点双有什么区别？**

```
边双连通分量（E-DCC）：
- 任意去掉一条边后仍然连通
- 图中不含割边
- 内部是"环状"结构

点双连通分量（V-DCC/BCC）：
- 任意去掉一个点后仍然连通
- 图中不含割点
- 可能包含割点作为连接点

面试选型建议：
- 如果需要分析边的关键性 → 边双
- 如果需要分析点的重要性 → 点双
- 如果需要图简化 → 边双（缩点后是树）
```

## 四、代码实现（C++）

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 100005;
const int MAXM = 200005;

// 边的结构体
struct Edge {
    int to;
    int next;
    int id;
} edges[MAXM * 2];

int head[MAXN];
int cnt = 0;

// Tarjan割边割点
int dfn[MAXN];
int low[MAXN];
int timestamp = 0;
bool is_bridge[MAXM];
bool is_cut[MAXN];

// 边双连通分量
int belong[MAXN];
int ebcc_cnt = 0;

// 点双连通分量
vector<int> vbcc[MAXN];
int vbcc_cnt = 0;
stack<pair<int, int>> st;

/**
 * 添加无向边
 */
void add_edge(int u, int v) {
    edges[cnt].to = v;
    edges[cnt].next = head[u];
    edges[cnt].id = cnt;
    head[u] = cnt++;
    
    edges[cnt].to = u;
    edges[cnt].next = head[v];
    edges[cnt].id = cnt;
    head[v] = cnt++;
}

/**
 * Tarjan算法求割边、割点、边双、点双
 */
void tarjan(int u, int parent_edge) {
    dfn[u] = low[u] = ++timestamp;
    int child_cnt = 0;
    
    for (int e = head[u]; e != -1; e = edges[e].next) {
        int v = edges[e].to;
        int id = edges[e].id;
        
        if (id == parent_edge) continue;
        
        if (!dfn[v]) {
            child_cnt++;
            st.push({u, v});
            tarjan(v, id);
            low[u] = min(low[u], low[v]);
            
            // 割边判定
            if (low[v] > dfn[u]) {
                is_bridge[id] = true;
            }
            
            // 割点判定
            if (low[v] >= dfn[u]) {
                is_cut[u] = true;
            }
            
            // 边双连通分量
            if (low[v] >= dfn[u]) {
                ebcc_cnt++;
                while (!st.empty()) {
                    auto [x, y] = st.top();
                    st.pop();
                    belong[x] = ebcc_cnt;
                    if (x == u && y == v) break;
                    if (y == u) belong[y] = ebcc_cnt;
                }
            }
        } else if (dfn[v] < dfn[u]) {
            // 回边
            low[u] = min(low[u], dfn[v]);
            st.push({u, v});
        }
    }
    
    // 根节点特殊处理
    if (parent_edge == -1 && child_cnt > 1) {
        is_cut[u] = true;
    }
}

/**
 * 收集割边
 */
vector<pair<int, int>> get_bridges() {
    vector<pair<int, int>> bridges;
    for (int i = 0; i < cnt; i++) {
        if (is_bridge[i] && i % 2 == 0) {
            bridges.push_back({edges[i].to, edges[i^1].to});
        }
    }
    return bridges;
}

int main() {
    memset(head, -1, sizeof(head));
    
    int n, m;
    cin >> n >> m;
    
    for (int i = 0; i < m; i++) {
        int u, v;
        cin >> u >> v;
        add_edge(u, v);
    }
    
    // Tarjan
    for (int i = 1; i <= n; i++) {
        if (!dfn[i]) {
            tarjan(i, -1);
        }
    }
    
    // 输出割边
    auto bridges = get_bridges();
    cout << "割边数量: " << bridges.size() << endl;
    for (auto &e : bridges) {
        cout << e.first << " " << e.second << endl;
    }
    
    // 输出割点
    vector<int> cuts;
    for (int i = 1; i <= n; i++) {
        if (is_cut[i]) cuts.push_back(i);
    }
    cout << "割点数量: " << cuts.size() << endl;
    
    // 输出边双
    cout << "边双连通分量数量: " << ebcc_cnt << endl;
    
    return 0;
}
```

## 五、面试高频问题

### Q1: 边双和点双的核心区别？

```
边双（E-DCC）：
- 关注边的连通性
- 分离对象：边
- 关键元素：割边
- 内部结构：必有环

点双（V-DCC）：
- 关注点的连通性
- 分离对象：点
- 关键元素：割点
- 内部结构：可能为树

面试选型：
- 分析边的重要性 → 边双
- 分析点的重要性 → 点双
- 图简化（降维）→ 边双（缩点后是树）
```

### Q2: 什么时候用边双？什么时候用点双？

```
使用边双的场景：
1. 需要识别关键连接（割边）
2. 需要将图简化为树
3. 边的属性比点更重要
4. 需要计算树的直径等树操作

使用点双的场景：
1. 需要识别关键节点（割点）
2. 需要分析节点的重要性
3. 需要进行社区检测
4. 点删除对图连通性的影响
```
