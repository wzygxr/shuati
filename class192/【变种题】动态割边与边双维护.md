# 变种题：动态割边与边双连通分量维护

## 一、动态场景概述

### 1.1 什么是动态割边？

静态场景：给定图，求割边（一次性求解）
动态场景：支持加边/删边操作，需要维护割边信息

### 1.2 面试问题

```
面试官：动态加边/删边如何维护边双连通分量？

候选人：

静态求解：Tarjan O(n+m)

动态维护（进阶问题）：

1. 删边：
   - 如果删除的边不是割边 → 无影响
   - 如果删除的是割边 → 需要重新计算
   - 可用 Link-Cut Tree 维护

2. 加边：
   - 如果两端已连通 → 无影响
   - 如果两端不连通 → 连接两个分量
   - 可用并查集 + Tarjan 增量求解

面试回答策略：
"静态场景下，直接用 Tarjan 重新求解即可"
"如果面试官追问动态维护，可以提到 LCT、CDQ 分治等高级数据结构"
```

## 三、面试高频问题

### Q1: 动态加边场景下，如何判断是否需要重新计算？

```
答案：
1. 如果加边前两端已连通（属于同一连通分量）
   - 不会产生新的割边
   - 可能消除已有的割边（形成环）
   - 需要检查

2. 如果加边前两端不连通
   - 一定会产生新的割边
   - 连接两个连通分量
```

### Q2: 动态删边场景下，如何判断影响？

```
答案：
1. 如果删除的边不是割边
   - 无影响，图仍然连通

2. 如果删除的是割边
   - 需要重新计算
   - 可能分裂为多个连通分量
```

### Q3: 大规模动态图如何处理？

```
答案：
1. 离线处理：所有操作完成后再统一求解
2. 分块处理：将图分成若干块，每块单独维护
3. 近似算法：采样+估计（适用于超大规模）
4. 增量更新：只更新变化部分（理想情况）
```

## 四、代码实现（简化版）

```cpp
#include <bits/stdc++.h>
using namespace std;

// 并查集
class DSU {
    vector<int> parent, rank;
public:
    DSU(int n) {
        parent.resize(n + 1);
        rank.resize(n + 1, 0);
        for (int i = 1; i <= n; i++) parent[i] = i;
    }
    
    int find(int x) {
        if (parent[x] == x) return x;
        return parent[x] = find(parent[x]);
    }
    
    void unite(int x, int y) {
        x = find(x);
        y = find(y);
        if (x == y) return;
        if (rank[x] < rank[y]) swap(x, y);
        parent[y] = x;
        if (rank[x] == rank[y]) rank[x]++;
    }
    
    bool same(int x, int y) {
        return find(x) == find(y);
    }
};

int main() {
    cout << "动态割边维护" << endl;
    cout << "面试要点：" << endl;
    cout << "1. 静态场景：直接用Tarjan O(n+m)" << endl;
    cout << "2. 动态删边：如果不是割边则无影响" << endl;
    cout << "3. 动态加边：如果两端已连通可能消除割边" << endl;
    cout << "4. 进阶方法：LCT、CDQ分治" << endl;
    return 0;
}
```

## 五、复杂度分析

| 操作 | 静态Tarjan | 并查集+LCT | 增量更新 |
|------|------------|------------|----------|
| 初始化 | O(n+m) | O(n+m) | O(n+m) |
| 加边 | O(n+m) | O(log n) | O(变化部分) |
| 删边 | O(n+m) | O(log n) | O(变化部分) |
| 查询割边 | O(1) | O(1) | O(1) |
