# 变种题：重边场景下的割边判定

## 一、重边问题概述

### 1.1 什么是重边？

重边（Parallel Edges）是指在同一对节点之间存在多条边。

### 1.2 重边对割边判定的影响

**错误做法**：
```cpp
// 错误：用父节点编号判断
if (v == parent) continue;
```

**原因**：如果有重边，用父节点判断会错误地将其中一条当作反向边跳过。

### 1.3 正确做法

```cpp
// 正确：用边编号判断
if (id == parent_edge) continue;
```

## 二、面试高频问题

### Q1: 为什么不能用父节点编号排除反向边？

```
问题场景：在 Tarjan 算法中，我们需要跳过从父节点来的边

错误做法：
if (v == parent) continue;

错误原因：无法处理重边

举例：
节点 1 和 2 之间有两条边
- 边 A：id=0
- 边 B：id=1

DFS 从 1 到 2 时：
- 遍历边 A：作为树边处理，parent = 0
- 遍历边 B：v=2, parent=2，条件成立，错误跳过！
- 结果：漏判了边 B

正确做法：
if (id == parent_edge) continue;

用边编号而不是节点编号区分：
- 每条边有唯一编号
- 只有当前边的反向边（id^1）才跳过
- 可以正确处理重边情况
```

### Q2: 重边情况下如何判断割边？

```
情况1：节点1-2之间只有一条边
- 如果 low[2] > dfn[1]，则(1,2)是割边

情况2：节点1-2之间有两条边
- 边A和边B都不是割边
- 因为删除任意一条，1和2仍然连通

原因：
- 遍历边A时，会将边B作为回边处理
- low[2]会被dfn[1]更新
- low[2]不会大于dfn[1]
- 所以边A和边B都不是割边

代码关键点：
- 每条边分配唯一id
- 用 id != preEdge 判断
- 不是用 v != parent 判断
```

## 三、代码实现

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 100005;
const int MAXM = 200005;

struct Edge {
    int to;
    int next;
    int id;
} edges[MAXM * 2];

int head[MAXN];
int cnt = 0;

int dfn[MAXN];
int low[MAXN];
int timestamp = 0;
bool is_bridge[MAXM];

/**
 * 添加无向边（正确处理重边）
 */
void add_edge(int u, int v) {
    edges[cnt].to = v;
    edges[cnt].next = head[u];
    edges[cnt].id = cnt;
    head[u] = cnt++;
    
    edges[cnt].to = u;
    edges[cnt].next = head[v];
    edges[cnt].id = cnt;
    head[v] = cnt++;
}

/**
 * Tarjan求割边（兼容重边）
 * 
 * 关键点：
 * - 用边编号判断，而非父节点编号
 * - 每条边有唯一id，可以正确处理重边
 */
void tarjan(int u, int parent_edge) {
    dfn[u] = low[u] = ++timestamp;
    
    for (int e = head[u]; e != -1; e = edges[e].next) {
        int v = edges[e].to;
        int id = edges[e].id;
        
        // 关键：用边编号判断，而不是父节点编号
        // 这样可以正确处理重边情况
        if (id == parent_edge) continue;
        
        if (!dfn[v]) {
            tarjan(v, id);
            low[u] = min(low[u], low[v]);
            
            // 割边判定
            if (low[v] > dfn[u]) {
                is_bridge[id] = true;
            }
        } else {
            low[u] = min(low[u], dfn[v]);
        }
    }
}

int main() {
    memset(head, -1, sizeof(head));
    
    int n, m;
    cin >> n >> m;
    
    for (int i = 0; i < m; i++) {
        int u, v;
        cin >> u >> v;
        add_edge(u, v);
    }
    
    // 遍历所有连通块
    for (int i = 1; i <= n; i++) {
        if (!dfn[i]) {
            tarjan(i, -1);
        }
    }
    
    // 输出割边
    for (int i = 0; i < cnt; i += 2) {
        if (is_bridge[i]) {
            cout << edges[i].to << " " << edges[i^1].to << endl;
        }
    }
    
    return 0;
}
```

## 五、面试话术

```
面试官：如何处理重边情况下的割边判定？
候选人：

在Tarjan算法中，我们需要跳过从父节点来的边，避免误判。

常见的错误做法是用父节点编号判断：
if (v == parent) continue;

这种方法在有重边的情况下会出错。假设1-2之间有两条边，DFS从1到2遍历第一条边作为树边，第二条边会被错误地跳过。

正确的做法是用边编号判断：
if (id == parent_edge) continue;

因为每条边都有唯一编号，只有当前边的反向边才会被跳过，可以正确处理重边情况。

在有重边的情况下，两条边都不是割边。因为遍历第一条边时，第二条边会被作为回边处理，low[2]会被dfn[1]更新，low[2]不会大于dfn[1]。
```
