# 【洛谷】P1121 - 环状染色（边双连通分量+生成树）

## 一、题目信息

### 1.1 原始链接
- 洛谷：https://www.luogu.com.cn/problem/P1121
- 来源：可能为竞赛题
- 难度：中等

### 1.2 题目描述

给定一个无向图，图中可能有一些环。求至少需要删除多少条边，才能使得图中没有环？

**输入格式**：
- n, m
- m行：u, v

**输出格式**：
- 最少需要删除的边数

## 三、解题思路

### 3.1 算法流程

```
1. 统计连通块数量
2. 对于每个连通块，计算需要删除的边数 = 边数 - 节点数 + 1
3. 累加所有连通块的答案
```

### 3.2 公式推导

- 对于一个连通块，如果边数 = 节点数 - 1，则是一棵树（无环）
- 如果边数 > 节点数 - 1，则有多余的边形成环
- 需要删除的边数 = 边数 - (节点数 - 1) = m - n + 1

## 四、代码实现（C++）

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 100005;
const int MAXM = 200005;

// 并查集
int fa[MAXN];
int n, m;

/**
 * 并查集查找（路径压缩）
 * 
 * 面试考点：
 * - 路径压缩优化
 * - 均摊复杂度接近O(1)
 */
int find(int x) {
    if (fa[x] == x) return x;
    return fa[x] = find(fa[x]);
}

/**
 * 并查集合并
 */
void union_set(int x, int y) {
    x = find(x);
    y = find(y);
    if (x != y) {
        fa[x] = y;
    }
}

// -------------------- 主函数 --------------------

int main() {
    cin >> n >> m;
    
    // 初始化并查集
    for (int i = 1; i <= n; i++) {
        fa[i] = i;
    }
    
    // 统计每个连通块的边数和节点数
    // 这里使用并查集来统计连通块
    for (int i = 0; i < m; i++) {
        int u, v;
        cin >> u >> v;
        union_set(u, v);
    }
    
    // 统计每个连通块的节点数
    unordered_map<int, int> comp_nodes;
    for (int i = 1; i <= n; i++) {
        int root = find(i);
        comp_nodes[root]++;
    }
    
    // 答案 = 总边数 - 总节点数 + 连通块数量
    // = m - n + comp_cnt
    int comp_cnt = comp_nodes.size();
    int ans = m - n + comp_cnt;
    
    cout << ans << endl;
    
    return 0;
}
```

## 五、时间与空间复杂度分析

### 5.1 时间复杂度

| 操作 | 复杂度 | 说明 |
|------|--------|------|
| 并查集操作 | O(m α(n)) | α为反阿克曼函数 |
| 统计节点数 | O(n) | 遍历节点 |
| **总复杂度** | **O(n + m)** | 线性时间 |

### 5.2 空间复杂度

| 数据结构 | 空间 | 说明 |
|----------|------|------|
| 并查集 | O(n) | fa数组 |
| 统计表 | O(n) | 哈希表 |
| **总空间** | **O(n)** | 线性空间 |
