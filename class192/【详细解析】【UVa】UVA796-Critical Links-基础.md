# 【UVa】UVA796 - Critical Links（割边/桥）

## 一、题目信息

### 1.1 原始链接
- UVa Online Judge：https://onlinejudge.org/index.php?option=com_onlinejudge&Itemid=8&page=show_problem&problem=737
- 题目编号：UVA 796
- 难度：基础

### 1.2 题目描述

给定一个无向图（可能有重边），求出所有的割边（桥），并按要求输出。

**输入格式**：
- 多组测试数据，每组数据：
  - 第一行：整数 n（节点数，0表示结束）
  - 接下来 n 行，每行格式：server (k) [list of servers]
  - k 表示与该服务器相连的服务器数量，后面是 k 个服务器编号

**输出格式**：
- 每组数据先输出 "X critical links"（X为割边数量）
- 接下来每行输出一个割边，格式：u-v（u < v，按u升序，u相同按v升序）
- 最后输出一个空行

**数据范围**：
- 节点数 ≤ 100
- 每组数据独立处理

### 1.3 样例输入

```
8
0 (1): 1
1 (1): 0
2 (1): 3
3 (1): 2
4 (1): 5
5 (1): 4
6 (1): 7
7 (1): 6
8
0 (1): 1
1 (1): 0
2 (2): 3 5
3 (1): 2
4 (1): 6
5 (1): 2
6 (1): 4
7 (1): 6
0
```

### 1.4 样例输出

```
3 critical links
0-1
3-4
6-7

2 critical links
2-3
4-6
```

## 三、解题思路

### 3.1 算法流程

```
1. 解析特殊输入格式，构建无向图邻接表
2. 遍历所有未访问节点（处理非连通图）
3. 对每个连通块执行 Tarjan 算法
   - 计算 dfn[u] 和 low[u]
   - 判定割边：low[v] > dfn[u]
4. 收集所有割边，按要求排序输出
```

### 3.2 割边判定定理证明

**定理**：在无向图中，边 (u, v)（u 是 v 的父节点）是割边，当且仅当 low[v] > dfn[u]。

**证明**：
- low[v] 表示 v 及 v 的子树能回溯到的最早节点时间戳
- 如果 low[v] > dfn[u]，说明 v 无法通过任何路径回到 u 或更早的节点
- 因此删除边 (u, v) 后，v 所在子树与图的其余部分断开
- 该边为割边

### 3.3 重边处理（本题关键）

本题需要特别注意重边的处理：
- 如果同一对节点之间有多条边，这些边都不是割边
- 在代码中，必须用边编号（而非父节点编号）来判断反向边
- 这样可以正确处理：1-2之间有两条边的情况

### 3.4 面试口述逻辑

```
面试官：如何求割边？
候选人：使用 Tarjan 算法，核心是维护两个数组 dfn 和 low。
        dfn[u] 是 u 被首次访问的时间戳，
        low[u] 是 u 能回溯到的最早时间戳。
        
        对于边 (u, v)，如果 low[v] > dfn[u]，说明 v 无法回到 u 或更早，
        那么 (u, v) 就是割边。
        
        需要注意重边情况，不能用父节点编号排除反向边，
        必须用边编号来判断。
```

## 四、代码实现（C++）

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
#include <cstring>
#include <sstream>
using namespace std;

// -------------------- 变量定义 --------------------

// 最大节点数（本题数据范围较小）
const int MAXN = 105;

// 链式前向星邻接表
struct Edge {
    int to;     // 边的终点节点
    int next;   // 下一条边的编号
    int id;     // 边的唯一编号，用于区分重边
} edges[MAXN * MAXN * 2];  // 预留足够的边空间

int head[MAXN];       // head[u]表示节点u的第一条边在edges数组中的下标
int cnt = 0;          // 边的计数器

// Tarjan算法核心数组
int dfn[MAXN];        // dfn[u]：节点u被访问的时间戳（发现时间）
int low[MAXN];        // low[u]：节点u及其子树能回溯到的最早dfn值
int timestamp = 0;    // 全局时间戳计数器

// 割边标记数组（按边编号标记）
bool is_bridge[10005];

// 存储所有割边
vector<pair<int, int>> bridges;

// -------------------- 核心函数 --------------------

/**
 * 添加无向边到邻接表
 * @param u 边的起点
 * @param v 边的终点
 * 
 * 面试考点：
 * - 无向图需要双向存储
 * - 每条边分配唯一id，用于后续割边判定
 * - 重边情况下，id不同，可正确处理
 */
void add_edge(int u, int v) {
    // 创建从u到v的边
    edges[cnt].to = v;           // 设置边的终点为v
    edges[cnt].next = head[u];   // 将当前边插入到邻接表头部
    edges[cnt].id = cnt;         // 分配唯一边编号
    head[u] = cnt++;             // 更新头指针，指向新边
    
    // 创建从v到u的边（反向边）
    edges[cnt].to = u;           // 设置边的终点为u
    edges[cnt].next = head[v];    // 将当前边插入到邻接表头部
    edges[cnt].id = cnt;         // 分配唯一边编号（与正向边不同）
    head[v] = cnt++;             // 更新头指针，指向新边
}

/**
 * Tarjan算法求割边
 * @param u 当前访问的节点
 * @param parent_edge 来自父节点的边编号（用于排除反向边）
 * 
 * 核心原理：
 * - dfn[u]：u被发现的时间
 * - low[u]：u能回溯到的最小dfn（包括通过回边和非父边的树边）
 * 
 * 割边判定：low[v] > dfn[u]，即v无法绕回u或更早的节点
 * 
 * ML/ML关联：
 * - 割边识别可作为图结构分析的关键特征
 * - 用于图神经网络的边注意力机制
 */
void tarjan(int u, int parent_edge) {
    dfn[u] = low[u] = ++timestamp;    // 初始化：发现时间 = 可回溯最早时间 = 当前时间戳
    
    // 遍历节点u的所有邻接边
    for (int e = head[u]; e != -1; e = edges[e].next) {
        int v = edges[e].to;          // 获取边的终点节点
        int edge_id = edges[e].id;    // 获取边的唯一编号
        
        // 如果这条边是来自父节点的边（反向边），跳过
        // 注意：这里用边编号判断，而不是父节点编号，可以正确处理重边情况
        // 这是面试高频考点：重边情况下不能用父节点判断
        if (edge_id == parent_edge) {
            continue;
        }
        
        // 如果节点v还未被访问
        if (dfn[v] == 0) {
            // 递归访问子节点，传入当前边的编号作为父边
            tarjan(v, edge_id);
            
            // 回溯时更新low[u]：取子节点low[v]和当前low[u]的最小值
            low[u] = min(low[u], low[v]);
            
            // ---------------- 割边判定 ----------------
            // 如果 low[v] > dfn[u]，说明v无法回溯到u或更早的节点
            // 此时边(u,v)是割边（桥）
            // 这是Tarjan算法最核心的判定定理
            if (low[v] > dfn[u]) {
                // 标记该边为割边
                is_bridge[edge_id] = true;
            }
        } 
        // 如果节点v已被访问（通过回边更新low值）
        else {
            // 用已访问节点的dfn值更新low[u]
            // 这是处理回边的重要步骤
            low[u] = min(low[u], dfn[v]);
        }
    }
}

/**
 * 收集割边结果
 * 
 * 面试考点：
 * - 无向图中一条割边存储两次（正向和反向）
 * - 只取编号较小的那条（偶数编号），避免重复输出
 */
void collect_bridges() {
    // 遍历所有边，收集割边
    for (int i = 0; i < cnt; i++) {
        if (is_bridge[i]) {
            // 对于每条割边，获取其两个端点
            // edges[i]和edges[i^1]是一对反向边
            // 取较小端点作为起点，保证输出格式正确
            int u = edges[i].to;
            int v = edges[i ^ 1].to;
            // 只取编号为偶数的边（避免重复）
            if (i % 2 == 0) {
                bridges.push_back({min(u, v), max(u, v)});
            }
        }
    }
}

/**
 * 解析特殊输入格式
 * 格式：server (k): list
 * 例如：0 (1): 1
 * 
 * 面试考点：
 * - 输入格式解析是本题的难点之一
 * - 需要处理括号和冒号
 */
void parse_input_line(string line, int &server, vector<int> &connects) {
    // 使用stringstream解析输入
    stringstream ss(line);
    string tmp;
    int num;
    
    // 读取服务器编号
    ss >> server;
    
    // 跳过 "(k):" 部分
    // 读取直到遇到 ':'
    while (ss >> tmp) {
        if (tmp.find(':') != string::npos) {
            break;
        }
    }
    
    // 读取连接列表
    while (ss >> num) {
        connects.push_back(num);
    }
}

// -------------------- 主函数 --------------------

int main() {
    // 初始化
    memset(head, -1, sizeof(head));    // 初始化邻接表头指针为-1
    memset(dfn, 0, sizeof(dfn));       // 初始化dfn数组为0（表示未访问）
    memset(low, 0, sizeof(low));       // 初始化low数组为0
    memset(is_bridge, false, sizeof(is_bridge));   // 初始化割边标记
    
    int n;
    // 读取第一组数据的节点数
    while (cin >> n && n != 0) {
        // 清空上一组数据的影响
        cnt = 0;
        timestamp = 0;
        bridges.clear();
        memset(head, -1, sizeof(head));
        memset(dfn, 0, sizeof(dfn));
        memset(low, 0, sizeof(low));
        memset(is_bridge, false, sizeof(is_bridge));
        
        // 读取换行符
        string line;
        getline(cin, line);
        
        // 解析每一行
        for (int i = 0; i < n; i++) {
            getline(cin, line);
            int server;
            vector<int> connects;
            parse_input_line(line, server, connects);
            
            // 添加边
            for (int v : connects) {
                add_edge(server, v);
            }
        }
        
        // 遍历所有节点，处理非连通图
        for (int i = 0; i < n; i++) {
            if (dfn[i] == 0) {
                tarjan(i, -1);
            }
        }
        
        // 收集割边结果
        collect_bridges();
        
        // 按端点字典序排序
        sort(bridges.begin(), bridges.end());
        
        // 输出结果
        cout << bridges.size() << " critical links" << endl;
        for (auto &e : bridges) {
            cout << e.first << "-" << e.second << endl;
        }
        cout << endl;
    }
    
    return 0;
}
```

## 五、时间与空间复杂度分析

### 5.1 时间复杂度

| 操作 | 复杂度 | 说明 |
|------|--------|------|
| 图的构建 | O(n+m) | 遍历所有边建立邻接表 |
| Tarjan算法 | O(n+m) | 每个节点和每条边只访问常数次 |
| 结果排序 | O(k log k) | k为割边数量 |
| **总复杂度** | **O(n+m)** | 线性时间 |

### 5.2 空间复杂度

| 数据结构 | 空间 | 说明 |
|----------|------|------|
| 邻接表 | O(n+m) | edges数组 + head数组 |
| Tarjan数组 | O(n) | dfn, low |
| 割边标记 | O(m) | is_bridge数组 |
| **总空间** | **O(n+m)** | 线性空间 |

### 5.3 面试提问：为什么是O(n+m)？

```
面试官：为什么Tarjan算法的时间复杂度是O(n+m)？
候选人：
因为在DFS过程中，每个节点只会被访问一次（设置dfn值），
每条边也只会被遍历常数次（在邻接表中检查）。
具体来说：
1. 对于树边，会递归处理子节点
2. 对于回边，会更新low值
3. 每条边的检查是O(1)的

所以总时间 = O(节点数 + 边数) = O(n+m)
```

## 八、代码逐行注释要点总结

### 面试中需要重点说明的部分

1. **为什么用边编号而不是父节点编号？**
   ```
   因为存在重边情况！如果有两条边连接(u,v)，
   用父节点判断会错误地将其中一条当作反向边跳过。
   用边编号可以区分每一条独立的边。
   ```

2. **割边判定定理的直观理解**
   ```
   low[v] > dfn[u] 意味着：
   v及其子树中没有任何节点能够回到u或更早的节点
   所以删除(u,v)后，v所在的子树将与图的其余部分断开
   ```

3. **重边情况下割边的判定**
   ```
   如果1-2之间有两条边：
   - 边A（id=0）
   - 边B（id=1）
   
   从1到2遍历边A时，作为树边处理
   从1到2遍历边B时，v=2但edge_id=1 != parent_edge=0
   不会跳过，low[2]会被dfn[1]更新
   所以low[2]不会大于dfn[1]，边A和边B都不是割边
   ```
