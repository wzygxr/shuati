## 二、核心算法模板

### 1. Tarjan求割边与边双连通分量

```java
// Tarjan核心变量
int[] dfn = new int[MAXN];    // 节点发现时间
int[] low = new int[MAXN];    // 最低可达时间
int[] belong = new int[MAXN]; // 所属边双分量
int[] sta = new int[MAXN];    // 栈
int cntd = 0, top = 0, ebccCnt = 0;

void tarjan(int u, int preEdge) {
    dfn[u] = low[u] = ++cntd;
    sta[++top] = u;
    for (int e = head[u]; e > 0; e = nxt[e]) {
        if ((e ^ 1) == preEdge) continue; // 跳过父边
        int v = to[e];
        if (dfn[v] == 0) {
            tarjan(v, e);
            low[u] = Math.min(low[u], low[v]);
            // 割边判定: low[v] > dfn[u]
        } else {
            low[u] = Math.min(low[u], dfn[v]);
        }
    }
    if (dfn[u] == low[u]) { // 找到E-DCC
        ebccCnt++;
        while (sta[top--] != u) {
            belong[sta[top + 1]] = ebccCnt;
        }
    }
}
```

### 2. 边双缩点

void condense() {
    cntg = 0;

        int ebcc1 = belong[a[i]];
        int ebcc2 = belong[b[i]];
        if (ebcc1 != ebcc2) {

            addEdge(ebcc2, ebcc1);
        }

## 三、笔试面试高频提问清单

### 基础概念
1. **什么是割边（桥）？** 无向图中，删除某条边后图不连通，该边为割边。
2. **什么是边双连通分量？** 图中任意两点存在两条**边**不重复的路径。
3. **割边判定定理**：`low[v] > dfn[u]`，边(u,v)是割边。
4. **边双与点双的区别**：边双要求任意两条边可分离，点双要求任意两点可分离。

### 进阶问题
5. **重边如何处理？** 不能仅靠父节点编号排除，需用边编号判断：`id != preEdge`
6. **为什么缩点后是树？** 割边连接不同E-DCC，不形成环。
7. **如何求树上两点唯一路径必经的割边？** 该路径上的所有边都是割边。

### 复杂度分析
8. **Tarjan时间复杂度**：O(n+m)
9. **边双缩点后树操作**：O(n)或O(n log n)视具体操作而定

### ML/DL关联
10. **割边识别如何辅助GNN？** 提取关键连接，聚焦重要边信息。
11. **边双缩点如何降低计算量？** 将复杂图简化为树，减少消息传递次数。

## 五、机器学习/深度学习关联总结

### 1. 割边（关键边）识别
- **作用**：识别图中结构性最重要的边
- **GNN应用**：边注意力机制、关键信息聚焦
- **异常检测**：割边变化反映网络结构突变

### 2. 边双缩点
- **作用**：将复杂无向图简化为树结构
- **GNN应用**：
  - 降低消息传递计算复杂度
  - 提取社区结构特征
  - 图粗化（Graph Coarsening）

### 3. 图嵌入与特征工程
- **边双特征**：社区规模、环内/环外属性
- **割边特征**：关键连接度、桥接重要性
