# 【洛谷】P3455 - POI2009 SLF（边双连通分量+最短路）

## 一、题目信息

### 1.1 原始链接
- 洛谷：https://www.luogu.com.cn/problem/P3455
- 来源：POI 2009 SLF
- 难度：困难

### 1.2 题目描述

给定一个无向图，某些边上可能有恐怖分子。每个城市有一个防御值。对于每条边，如果这条边被恐怖分子控制，那么必须支付边上守卫的工资才能使用这条边。

求从城市1到城市n的路径中，支付工资最少是多少？

**输入格式**：
- 第一行：n, m
- 接下来m行：u, v, w（w为守卫工资）
- 接下来n行：每个城市的防御值

**输出格式**：
- 最少需要支付的工资

**数据范围**：
- n ≤ 5000, m ≤ 10000

## 三、解题思路

### 3.1 算法流程

```
1. Tarjan算法求割边
2. 边双连通分量缩点，得到一棵树
3. 在缩点后的树上求从1到n的最短路径
```

### 3.2 核心思想

- 首先识别图中的割边
- 将边双连通分量收缩为单个节点
- 割边成为连接这些节点的树边
- 在树上求最短路即可

## 四、代码实现（C++）

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 5005;
const int MAXM = 10005;

// 边的结构体
struct Edge {
    int to;         // 边的终点
    int next;       // 下一条边
    int w;          // 边的权重（工资）
    int id;         // 边的编号
} edges[MAXM * 2];

int head[MAXN];
int cnt = 0;

// Tarjan算法
int dfn[MAXN];
int low[MAXN];
int timestamp = 0;
bool is_bridge[MAXM];

// 边双连通分量
int belong[MAXN];
int dcc_cnt = 0;

// 缩点后的树
vector<pair<int, int>> tree[MAXN];
int dist[MAXN];

/**
 * 添加无向边
 * @param u 起点
 * @param v 终点
 * @param w 权重
 * 
 * 面试考点：
 * - 无向图需要双向存储
 * - 每条边分配唯一id
 */
void add_edge(int u, int v, int w) {
    edges[cnt].to = v;
    edges[cnt].w = w;
    edges[cnt].next = head[u];
    edges[cnt].id = cnt;
    head[u] = cnt++;
    
    edges[cnt].to = u;
    edges[cnt].w = w;
    edges[cnt].next = head[v];
    edges[cnt].id = cnt;
    head[v] = cnt++;
}

/**
 * Tarjan算法求割边
 * @param u 当前节点
 * @param parent_edge 父边编号
 * 
 * 核心原理：
 * - dfn[u]：发现时间
 * - low[u]：能回溯的最早时间
 * - 割边判定：low[v] > dfn[u]
 * 
 * ML关联：
 * - 割边可作为图的"关键连接"特征
 */
void tarjan(int u, int parent_edge) {
    dfn[u] = low[u] = ++timestamp;
    
    for (int e = head[u]; e != -1; e = edges[e].next) {
        int v = edges[e].to;
        int id = edges[e].id;
        
        // 用边编号判断，而非节点编号
        if (id == parent_edge) continue;
        
        if (!dfn[v]) {
            tarjan(v, id);
            low[u] = min(low[u], low[v]);
            
            // 割边判定
            if (low[v] > dfn[u]) {
                is_bridge[id] = true;
            }
        } else {
            low[u] = min(low[u], dfn[v]);
        }
    }
}

/**
 * 求边双连通分量
 * 去掉所有割边后，剩余的每个连通块就是一个边双连通分量
 * 
 * 面试考点：
 * - 如何从割边推导边双
 * - DFS遍历避开割边
 */
void dfs_dcc(int u) {
    belong[u] = dcc_cnt;
    
    for (int e = head[u]; e != -1; e = edges[e].next) {
        int v = edges[e].to;
        int id = edges[e].id;
        
        // 跳过割边，只遍历非割边
        if (!belong[v] && !is_bridge[id]) {
            dfs_dcc(v);
        }
    }
}

/**
 * 缩点构建树
 * 
 * 面试考点：
 * - 边双缩点的核心步骤
 * - 缩点后为什么是树
 */
void shrink() {
    // 求所有边双连通分量
    for (int i = 1; i <= dcc_cnt; i++) {
        if (!belong[i]) {
            dcc_cnt++;
            dfs_dcc(i);
        }
    }
    
    // 构建缩点后的树
    for (int u = 1; u <= dcc_cnt; u++) {
        for (int e = head[u]; e != -1; e = edges[e].next) {
            int v = edges[e].to;
            int id = edges[e].id;
            
            // 割边作为树的边
            if (is_bridge[id] && belong[u] != belong[v]) {
                tree[belong[u]].push_back({belong[v], edges[e].w});
            }
        }
    }
}

/**
 * 在树上求最短路（DFS）
 * 
 * @param u 当前节点
 * @param fa 父节点
 * @param d 当前路径长度
 */
void dfs_shortest(int u, int fa, int d) {
    dist[u] = d;
    
    for (auto &p : tree[u]) {
        int v = p.first;
        int w = p.second;
        
        if (v != fa) {
            dfs_shortest(v, u, d + w);
        }
    }
}

// -------------------- 主函数 --------------------

int main() {
    // 初始化
    memset(head, -1, sizeof(head));
    memset(dfn, 0, sizeof(dfn));
    memset(low, 0, sizeof(low));
    memset(is_bridge, false, sizeof(is_bridge));
    memset(belong, 0, sizeof(belong));
    
    int n, m;
    cin >> n >> m;
    
    // 读取边
    for (int i = 0; i < m; i++) {
        int u, v, w;
        cin >> u >> v >> w;
        add_edge(u, v, w);
    }
    
    // Tarjan求割边
    for (int i = 1; i <= n; i++) {
        if (!dfn[i]) {
            tarjan(i, -1);
        }
    }
    
    // 边双缩点
    shrink();
    
    // 求最短路
    dfs_shortest(belong[1], -1, 0);
    
    cout << dist[belong[n]] << endl;
    
    return 0;
}
```

## 五、时间与空间复杂度分析

### 5.1 时间复杂度

| 操作 | 复杂度 | 说明 |
|------|--------|------|
| Tarjan算法 | O(n+m) | 求割边 |
| 边双缩点 | O(n+m) | DFS遍历 |
| 最短路 | O(n) | DFS/BFS |
| **总复杂度** | **O(n+m)** | 线性时间 |

### 5.2 空间复杂度

| 数据结构 | 空间 | 说明 |
|----------|------|------|
| 邻接表 | O(n+m) | 边数组+头指针 |
| Tarjan数组 | O(n) | dfn, low |
| 缩点树 | O(n) | 树邻接表 |
| **总空间** | **O(n+m)** | 线性空间 |
