   `E_theta = +3 k_e q l^2 cos(2 theta) / r^4`。
2. 55-3 接地导体球的受力修正项必须含 `R^3`，并通过量纲、极限与直接求和核验。

4. 55-6 两平行导线悬浮的小振动周期为
   `T = pi I/g * sqrt(2 mu_0 r/M)`。
