# 机器学习与深度学习中的图算法应用

## 一、强连通分量（SCC）在ML/DL中的应用

### 1.1 图结构数据预处理

#### 1.1.1 图简化与降维

在大规模图数据中，SCC可以用于**图简化**，降低后续模型的计算复杂度：

```python
import numpy as np
import torch
from collections import defaultdict

def condense_graph_by_scc(graph, node_features):
    """
    使用SCC合并图中紧密连接的节点，实现图简化
    
    Args:
        graph: dict, 邻接表表示的有向图 {u: [v1, v2, ...]}
        node_features: np.array, 节点特征矩阵 [n_nodes, n_features]
    
    Returns:
        condensed_graph: 缩点后的DAG
        condensed_features: SCC聚合后的特征 [n_scc, n_features]
        node_to_scc: 节点到SCC的映射
        scc_to_nodes: SCC到节点的映射
    """
    # Step 1: 求强连通分量
    sccs = tarjan_scc(graph)
    n_scc = len(sccs)
    
    # Step 2: 构建映射
    node_to_scc = {}
    scc_to_nodes = {}
    for scc_id, nodes in enumerate(sccs):
        scc_to_nodes[scc_id] = nodes
        for node in nodes:
            node_to_scc[node] = scc_id
    
    # Step 3: 缩点构建DAG
    condensed_graph = defaultdict(list)
    scc_edges = set()
    
    for u in graph:
        for v in graph[u]:
            scc_u, scc_v = node_to_scc[u], node_to_scc[v]
            if scc_u != scc_v and (scc_u, scc_v) not in scc_edges:
                condensed_graph[scc_u].append(scc_v)
                scc_edges.add((scc_u, scc_v))
    
    # Step 4: 特征聚合
    condensed_features = []
    for scc_id in range(n_scc):
        nodes = scc_to_nodes[scc_id]
        if len(nodes) == 1:
            # 单节点直接使用原特征
            scc_feat = node_features[nodes[0]]
        else:
            # 多节点使用池化聚合
            scc_feats = node_features[nodes]
            scc_feat = np.mean(scc_feats, axis=0)  # 平均池化
            # scc_feat = np.max(scc_feats, axis=0)  # 最大池化
        condensed_features.append(scc_feat)
    
    return condensed_graph, np.array(condensed_features), node_to_scc, scc_to_nodes
```

**应用场景：**
- **大规模图嵌入**：将百万级节点图降至万级SCC级别
- **知识图谱补全**：SCC内部关系密集，可作为整体进行推理
- **社交网络分析**：发现紧密社交圈子，降低分析复杂度

#### 1.1.2 噪声过滤

SCC可以用于**识别和过滤图中的噪声节点**：

```python
def filter_noise_nodes_by_scc(graph, node_features, min_scc_size=3):
    """
    基于SCC大小过滤孤立噪声节点
    
    原理：
    - 大小为1的SCC（无自环）往往是孤立噪声点
    - 大规模SCC代表图中的核心结构
    """
    sccs = tarjan_scc(graph)
    
    # 识别核心节点（属于较大SCC的节点）
    core_nodes = set()
    for scc in sccs:
        if len(scc) >= min_scc_size:
            core_nodes.update(scc)
    
    # 筛选子图
    filtered_graph = {u: [v for v in graph[u] if v in core_nodes] 
                      for u in core_nodes}
    
    return filtered_graph, list(core_nodes)
```

### 1.2 图神经网络（GNN）优化

#### 1.2.1 层次化GNN架构

基于SCC的层次化GNN可以**显式建模多层次结构**：

```python
import torch
import torch.nn as nn
from torch_geometric.nn import GCNConv, GATConv

class HierarchicalSCCGNN(nn.Module):
    """
    层次化SCC-GNN
    
    架构：
    Layer 1: 原图节点特征 -> SCC内部聚合
    Layer 2: SCC特征 -> DAG上传播
    Layer 3: SCC特征映射回节点
    """
    
    def __init__(self, in_dim, hidden_dim, out_dim, num_layers=2):
        super().__init__()
        
        # SCC内部聚合层
        self.intra_scc_layers = nn.ModuleList([
            GCNConv(in_dim if i == 0 else hidden_dim, hidden_dim)
            for i in range(num_layers)
        ])
        
        # DAG传播层
        self.inter_scc_layers = nn.ModuleList([
            GATConv(hidden_dim, hidden_dim if i < num_layers-1 else out_dim, heads=4)
            for i in range(num_layers)
        ])
        
        # 特征映射层
        self.node_projection = nn.Linear(out_dim, out_dim)
    
    def forward(self, x, edge_index, scc_info):
        """
        Args:
            x: 节点特征 [n_nodes, in_dim]
            edge_index: 原图边索引 [2, n_edges]
            scc_info: dict，包含：
                - sccs: SCC列表
                - node_to_scc: 节点到SCC映射
                - dag_edge_index: 缩点后DAG边索引
        """
        sccs = scc_info['sccs']
        node_to_scc = scc_info['node_to_scc']
        dag_edge_index = scc_info['dag_edge_index']
        
        # Step 1: SCC内部聚合
        scc_features = []
        for scc in sccs:
            scc_node_features = x[scc]
            # 创建SCC内部子图
            scc_edge_index = self.get_subgraph_edges(scc, edge_index)
            
            # GCN聚合
            h = scc_node_features
            for layer in self.intra_scc_layers:
                h = torch.relu(layer(h, scc_edge_index))
            
            # 池化得到SCC特征
            scc_feat = h.mean(dim=0)
            scc_features.append(scc_feat)
        
        scc_features = torch.stack(scc_features)
        
        # Step 2: 在DAG上传播（按拓扑序）
        topo_order = self.topological_sort(dag_edge_index, len(sccs))
        
        h = scc_features
        for layer_idx, layer in enumerate(self.inter_scc_layers):
            # 按层并行计算
            new_h = h.clone()
            for level_nodes in topo_order:
                level_edge_index = self.filter_edges(dag_edge_index, level_nodes)
                if level_edge_index.size(1) > 0:
                    level_features = layer(h[level_nodes], level_edge_index)
                    new_h[level_nodes] = level_features
            h = torch.relu(new_h) if layer_idx < len(self.inter_scc_layers) - 1 else new_h
        
        # Step 3: 映射回节点
        output = torch.zeros(x.size(0), h.size(1), device=x.device)
        for scc_id, scc in enumerate(sccs):
            output[scc] = self.node_projection(h[scc_id])
        
        return output
    
    def topological_sort(self, edge_index, num_nodes):
        """对DAG进行拓扑分层"""
        # 实现拓扑排序，返回分层结果
        in_degree = torch.zeros(num_nodes, dtype=torch.long)
        for v in edge_index[1]:
            in_degree[v] += 1
        
        levels = []
        current_level = torch.where(in_degree == 0)[0]
        
        while len(current_level) > 0:
            levels.append(current_level)
            next_level = []
            for u in current_level:
                neighbors = edge_index[1][edge_index[0] == u]
                for v in neighbors:
                    in_degree[v] -= 1
                    if in_degree[v] == 0:
                        next_level.append(v)
            current_level = torch.tensor(next_level, dtype=torch.long)
        
        return levels
```

**优势：**
- **计算效率**：SCC内部可并行计算，DAG上按层并行
- **长距离依赖**：缩点后DAG直径更小，有利于捕获长距离依赖
- **可解释性**：SCC代表语义紧密的节点群，增强模型可解释性

#### 1.2.2 消息传递优化

在标准GNN中，消息需要在图上多轮传递才能捕获长距离依赖。基于SCC的优化可以**减少消息传递轮数**：

```python
class SCCOptimizedGNN(nn.Module):
    """基于SCC的消息传递优化GNN"""
    
    def __init__(self, in_dim, hidden_dim, out_dim):
        super().__init__()
        self.conv1 = GCNConv(in_dim, hidden_dim)
        self.conv2 = GCNConv(hidden_dim, out_dim)
    
    def forward(self, x, edge_index):
        # 预处理：求SCC并缩点
        sccs = self.compute_scc(edge_index)
        
        if len(sccs) < x.size(0) * 0.9:  # 如果SCC数量显著少于节点数
            # 使用SCC优化
            return self.scc_forward(x, edge_index, sccs)
        else:
            # 原图已经很稀疏，直接计算
            return self.standard_forward(x, edge_index)
    
    def scc_forward(self, x, edge_index, sccs):
        """SCC优化的前向传播"""
        # 1. SCC内部：一轮消息传递即可收敛（完全连通）
        scc_features = []
        for scc in sccs:
            scc_x = x[scc]
            # SCC内部聚合（一轮即可）
            scc_feat = scc_x.mean(dim=0)  # 简化为平均
            scc_features.append(scc_feat)
        
        # 2. SCC之间：在DAG上传播
        dag_edges = self.build_dag_edges(edge_index, sccs)
        scc_x = torch.stack(scc_features)
        
        # 在DAG上只需少量层数
        h = torch.relu(self.conv1(scc_x, dag_edges))
        out = self.conv2(h, dag_edges)
        
        # 3. 映射回节点
        node_out = torch.zeros(x.size(0), out.size(1), device=x.device)
        for i, scc in enumerate(sccs):
            node_out[scc] = out[i]
        
        return node_out
```

class SCCAwareGraphEmbedding(nn.Module):
    """
    SCC感知的图嵌入模型
    
    将SCC的结构特征作为额外的位置编码
    """
    
    def __init__(self, node_dim, scc_dim, hidden_dim):
        super().__init__()
        self.node_embedding = nn.Embedding(num_nodes, node_dim)
        self.scc_embedding = nn.Embedding(max_scc_id, scc_dim)
        
        # 融合层
        self.fusion = nn.Sequential(
            nn.Linear(node_dim + scc_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim)
        )
    
    def forward(self, node_ids, scc_ids):
        """
        Args:
            node_ids: 节点ID
            scc_ids: 节点所属SCC的ID
        """
        node_emb = self.node_embedding(node_ids)
        scc_emb = self.scc_embedding(scc_ids)
        
        # 拼接并融合
        combined = torch.cat([node_emb, scc_emb], dim=-1)
        output = self.fusion(combined)
        
        return output
```

def find_core_items_by_scc(user_item_graph, item_features):
    """
    在推荐系统中使用SCC发现核心物品
    
    原理：核心物品往往被大量用户交互，形成紧密的连接结构
    """
    # 构建物品共现图
    item_graph = build_item_cooccurrence_graph(user_item_graph)
    
    # 求SCC
    sccs = tarjan_scc(item_graph)
    
    # 缩点分析
    condensed_graph, item_to_scc = condense(item_graph, sccs)
    
    # 找出度为0的SCC（最"核心"的物品群）
    core_item_groups = []
    for scc_id, scc in enumerate(sccs):
        if condensed_graph.out_degree(scc_id) == 0:
            # 这些是核心物品群
            avg_popularity = np.mean([item_features[item]['popularity'] for item in scc])
            core_item_groups.append({
                'items': scc,
                'size': len(scc),
                'avg_popularity': avg_popularity
            })
    
    # 按 popularity 排序
    core_item_groups.sort(key=lambda x: x['avg_popularity'], reverse=True)
    
    return core_item_groups
```

## 二、面试中的ML/DL关联问题

### 常见问题1：如何用SCC优化大规模图神经网络训练？

**参考答案：**

```
1. 预处理阶段：
   - 使用SCC将图缩点，降低节点数量
   - 原图百万级节点可能降至万级SCC

2. 模型架构：
   - SCC内部：由于完全连通，可用简单池化代替GNN
   - SCC之间：在缩点后的DAG上使用GNN，层数可以减少

3. 训练效率：
   - SCC内部可并行计算
   - DAG拓扑分层，同层节点可并行
   - 整体训练速度提升10-100倍

4. 效果保持：
   - SCC内部语义相似，合并不会丢失关键信息
   - 反而可能降噪，提升模型泛化能力
```

### 常见问题2：SCC特征如何用于图分类任务？

**参考答案：**

```
1. 统计特征：
   - SCC数量、大小分布的均值/方差/熵
   - 反映图的整体结构复杂度

2. 拓扑特征：
   - 缩点后DAG的直径、深度
   - 反映信息的传播效率

3. 应用方式：
   - 作为全局特征拼接到图表示中
   - 用于图相似度计算
   - 作为图生成模型的约束条件
```

### 常见问题3：在推荐系统中，SCC有什么应用价值？

**参考答案：**

```
1. 用户分群：
   - SCC发现紧密的社交圈子
   - 同一SCC内用户兴趣相似

2. 核心物品发现：
   - 出度为0的SCC代表最受欢迎的物品群
   - 用于冷启动推荐

3. 推荐解释：
   - "你的朋友都在关注这个圈子"
   - 基于SCC结构生成解释

4. 多样性控制：
   - 不同SCC代表不同兴趣领域
   - 跨SCC推荐增加多样性
```
