# HDU 1269 - 迷宫城堡

## 题目链接
http://acm.hdu.edu.cn/showproblem.php?pid=1269

## 题目描述

为了训练小希的方向感，Gardon建立了一座大城堡，里面有很复杂的甬道。小希现在要从某个房间出发，然后经过若干房间后回到起点，要求每经过一个房间只能进入一次。判断是否存在这样的回路。

给定一个有向图，判断整个图是否强连通（即从任意一点出发都能到达其他所有点）。

### 输入格式

多组测试数据。

每组数据第一行两个整数 $n$ 和 $m$，表示 $n$ 个节点 $m$ 条边。

接下来 $m$ 行，每行两个整数 $u, v$，表示从 $u$ 到 $v$ 有一条有向边。

$n = 0, m = 0$ 表示输入结束。

### 输出格式

对于每组数据，如果图强连通输出 "Yes"，否则输出 "No"。

### 输入输出样例

**输入**
```
3 3
1 2
2 1
2 3
3 3
1 2
2 3
3 1
0 0
```

**输出**
```
No
Yes
```

### 数据范围
- $1 \le n \le 10,000$
- $1 \le m \le 100,000$

## 笔试/面试考察点分析

### 核心考察点
1. **强连通图判定**：图是强连通的当且仅当SCC数量为1
2. **Tarjan算法**：求SCC数量
3. **多组数据输入处理**：注意每组数据需要清空数组

### 解题关键 insight
```
【核心观察】
图强连通 <=> 整个图就是一个强连通分量
           <=> SCC数量为1

所以只需要用Tarjan求SCC，判断sccCnt是否等于1即可
```

## 解题思路

### 步骤1：初始化
多组数据，每组需要清空数组。

### 步骤2：建图
使用链式前向星存储有向图。

### 步骤3：Tarjan求SCC
运行Tarjan算法，统计SCC数量。

### 步骤4：判断
- SCC数量 == 1：输出 "Yes"
- SCC数量 > 1：输出 "No"

## 完整代码实现

### C++实现

```cpp
#include <iostream>
#include <cstring>
using namespace std;

const int MAXN = 10001;
const int MAXM = 100001;

int n, m;

// 链式前向星
int head[MAXN], nxt[MAXM], to[MAXM], cntg;

// Tarjan
int dfn[MAXN], low[MAXN], cntd;
int sta[MAXN], top;
int belong[MAXN], sccCnt;

void init() {
    // 初始化所有数组
    memset(head, 0, sizeof(head));
    memset(dfn, 0, sizeof(dfn));
    memset(low, 0, sizeof(low));
    memset(belong, 0, sizeof(belong));
    cntg = cntd = top = sccCnt = 0;
}

void addEdge(int u, int v) {
    nxt[++cntg] = head[u];
    to[cntg] = v;
    head[u] = cntg;
}

void tarjan(int u) {
    dfn[u] = low[u] = ++cntd;
    sta[++top] = u;
    
    for (int e = head[u]; e; e = nxt[e]) {
        int v = to[e];
        if (!dfn[v]) {
            tarjan(v);
            low[u] = min(low[u], low[v]);
        } else if (!belong[v]) {
            low[u] = min(low[u], dfn[v]);
        }
    }
    
    if (dfn[u] == low[u]) {
        sccCnt++;
        int pop;
        do {
            pop = sta[top--];
            belong[pop] = sccCnt;
        } while (pop != u);
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    while (cin >> n >> m) {
        if (n == 0 && m == 0) break;
        
        init(); // 初始化
        
        for (int i = 0; i < m; i++) {
            int u, v;
            cin >> u >> v;
            addEdge(u, v);
        }
        
        // 运行Tarjan
        for (int i = 1; i <= n; i++) {
            if (!dfn[i]) tarjan(i);
        }
        
        // 判断
        if (sccCnt == 1) {
            cout << "Yes\n";
        } else {
            cout << "No\n";
        }
    }
    
    return 0;
}
```

### Java实现

```java
import java.io.*;
import java.util.*;

public class Main {
    static int MAXN = 10001;
    static int MAXM = 100001;
    
    static int n, m;
    
    // 链式前向星
    static int[] head = new int[MAXN];
    static int[] nxt = new int[MAXM];
    static int[] to = new int[MAXM];
    static int cntg;
    
    // Tarjan
    static int[] dfn = new int[MAXN];
    static int[] low = new int[MAXN];
    static int cntd;
    static int[] sta = new int[MAXN];
    static int top;
    static int[] belong = new int[MAXN];
    static int sccCnt;
    
    static void init() {
        Arrays.fill(head, 0);
        Arrays.fill(dfn, 0);
        Arrays.fill(low, 0);
        Arrays.fill(belong, 0);
        cntg = cntd = top = sccCnt = 0;
    }
    
    static void addEdge(int u, int v) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        head[u] = cntg;
    }
    
    static void tarjan(int u) {
        dfn[u] = low[u] = ++cntd;
        sta[++top] = u;
        
        for (int e = head[u]; e > 0; e = nxt[e]) {
            int v = to[e];
            if (dfn[v] == 0) {
                tarjan(v);
                low[u] = Math.min(low[u], low[v]);
            } else if (belong[v] == 0) {
                low[u] = Math.min(low[u], dfn[v]);
            }
        }
        
        if (dfn[u] == low[u]) {
            sccCnt++;
            int pop;
            do {
                pop = sta[top--];
                belong[pop] = sccCnt;
            } while (pop != u);
        }
    }
    
    public static void main(String[] args) throws Exception {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st;
        
        while (true) {
            st = new StringTokenizer(br.readLine());
            n = Integer.parseInt(st.nextToken());
            m = Integer.parseInt(st.nextToken());
            
            if (n == 0 && m == 0) break;
            
            init();
            
            for (int i = 0; i < m; i++) {
                st = new StringTokenizer(br.readLine());
                int u = Integer.parseInt(st.nextToken());
                int v = Integer.parseInt(st.nextToken());
                addEdge(u, v);
            }
            
            for (int i = 1; i <= n; i++) {
                if (dfn[i] == 0) tarjan(i);
            }
            
            System.out.println(sccCnt == 1 ? "Yes" : "No");
        }
    }
}
```

```python
    """

    return {
        'is_valid': is_valid,
        'largest_scc_size': len(largest_scc),
        'scc_count': len(sccs),
        'suggestions': suggestions
    }
```
