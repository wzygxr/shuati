## 题目描述
给定一张 n 行 m 列的灰度图像，每个像素的灰度值为 0 到 L-1 之间的整数。

对于图像中的每个像素 (i, j)，考虑以其为中心的 (2r+1) × (2r+1) 邻域（边界不足时取图像边界）。

如果邻域内像素的灰度均值大于等于阈值 t，则称该像素为**亮像素**；否则为暗像素。

给定图像和参数 r、t，计算亮像素的数量。

## 输入格式
第一行包含四个整数 n、m、L、r，分别表示图像的行数、列数、灰度级数和邻域半径。

第二行包含一个整数 t，表示阈值。

接下来 n 行，每行 m 个整数，表示图像的灰度值。

## 输出格式
输出一个整数，表示亮像素的数量。

## 样例输入
```
3 4 256 1
100
50 100 150 200
100 150 200 250
150 200 250 300
```

## 样例输出
```
6
```

## 解题思路

### 方法一：暴力枚举（50分做法）
对于每个像素，枚举其(2r+1)×(2r+1)邻域，计算平均值。
时间复杂度：O(n×m×r²)，会超时。

### 方法二：二维前缀和（100分做法）
预处理二维前缀和数组，O(1)查询任意矩形区域和。
时间复杂度：O(n×m)。

### 核心步骤
1. **计算二维前缀和**：`sum[i][j]`表示以(1,1)为左上角，(i,j)为右下角的矩形区域和
2. **确定查询边界**：对于像素(i,j)，确定其邻域的有效边界
3. **查询区域和**：利用前缀和公式计算邻域内像素和
4. **判断是否亮像素**：和/像素数 ≥ t

## 完整代码实现

```cpp
#include <iostream>
#include <vector>
using namespace std;

const int MAXN = 605; // 最大图像尺寸，CSP题目通常n,m ≤ 600

long long prefix[MAXN][MAXN]; // 二维前缀和数组，long long防止溢出

/**
 * 计算二维前缀和
 * @param n 图像行数
 * @param m 图像列数
 * CSP要点：前缀和是CSP高频考点，必须熟练掌握
 * ML关联：二维前缀和类似于图卷积中的感受野计算
 */
void buildPrefixSum(int n, int m) {
    // 前缀和公式：sum[i][j] = sum[i-1][j] + sum[i][j-1] - sum[i-1][j-1] + a[i][j]
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= m; j++) {
            // 当前位置的前缀和 = 上方前缀和 + 左方前缀和 - 左上前缀和 + 当前值
            prefix[i][j] = prefix[i-1][j] + prefix[i][j-1] 
                          - prefix[i-1][j-1] + prefix[i][j];
        }
    }
}

/**
 * 查询矩形区域和
 * @param x1 左上角行坐标
 * @param y1 左上角列坐标
 * @param x2 右下角行坐标
 * @param y2 右下角列坐标
 * @return 矩形区域内像素和
 */
long long querySum(int x1, int y1, int x2, int y2) {
    // 利用容斥原理计算矩形区域和
    return prefix[x2][y2] - prefix[x1-1][y2] - prefix[x2][y1-1] + prefix[x1-1][y1-1];
}

int main() {
    ios::sync_with_stdio(false); // CSP中IO优化很重要
    cin.tie(nullptr);
    
    int n, m, L, r; // n:行数 m:列数 L:灰度级数 r:邻域半径
    cin >> n >> m >> L >> r; // 读取前四个参数
    
    int t; // 阈值
    cin >> t; // 读取阈值
    
    // 读取图像数据，同时构建前缀和数组
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= m; j++) {
            cin >> prefix[i][j]; // 直接读入前缀和数组（原始数据）
        }
    }
    
    // 构建二维前缀和
    buildPrefixSum(n, m);
    
    int brightPixels = 0; // 亮像素计数器
    
    // 遍历每个像素，判断是否为亮像素
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= m; j++) {
            // 计算邻域的有效边界（处理图像边界情况）
            // 左上角坐标：考虑边界，不能小于1
            int x1 = max(1, i - r); // 行坐标下限
            int y1 = max(1, j - r); // 列坐标下限
            // 右下角坐标：考虑边界，不能大于n/m
            int x2 = min(n, i + r); // 行坐标上限
            int y2 = min(m, j + r); // 列坐标上限
            
            // 计算邻域内像素数量
            int count = (x2 - x1 + 1) * (y2 - y1 + 1);
            
            // 查询邻域内像素和
            long long sum = querySum(x1, y1, x2, y2);
            
            // 判断是否满足亮像素条件
            // 注意：整数除法，sum/count >= t 等价于 sum >= t * count
            if (sum >= (long long)t * count) {
                brightPixels++; // 亮像素计数+1
            }
        }
    }
    
    // 输出亮像素数量
    cout << brightPixels << endl;
    
    return 0;
}
```

## Python实现

```python
import sys

def main():
    input = sys.stdin.readline  # 快速输入
    
    # 读取参数
    n, m, L, r = map(int, input().split())
    t = int(input())
    
    # 读取图像，使用1-based索引方便前缀和计算
    # 初始化(n+1) x (m+1)的数组
    prefix = [[0] * (m + 1) for _ in range(n + 1)]
    
    for i in range(1, n + 1):
        row = list(map(int, input().split()))
        for j in range(1, m + 1):
            prefix[i][j] = row[j - 1]  # 读入原始值
    
    # 构建二维前缀和
    # prefix[i][j] = prefix[i-1][j] + prefix[i][j-1] - prefix[i-1][j-1] + a[i][j]
    for i in range(1, n + 1):
        for j in range(1, m + 1):
            prefix[i][j] += prefix[i-1][j] + prefix[i][j-1] - prefix[i-1][j-1]
    
    bright_pixels = 0  # 亮像素计数
    
    # 遍历每个像素
    for i in range(1, n + 1):
        for j in range(1, m + 1):
            # 计算邻域边界
            x1 = max(1, i - r)
            y1 = max(1, j - r)
            x2 = min(n, i + r)
            y2 = min(m, j + r)
            
            # 邻域像素数量
            count = (x2 - x1 + 1) * (y2 - y1 + 1)
            
            # 查询邻域和
            # sum = prefix[x2][y2] - prefix[x1-1][y2] - prefix[x2][y1-1] + prefix[x1-1][y1-1]
            total = (prefix[x2][y2] - prefix[x1-1][y2] 
                    - prefix[x2][y1-1] + prefix[x1-1][y1-1])
            
            # 判断是否为亮像素
            if total >= t * count:
                bright_pixels += 1
    
    print(bright_pixels)

if __name__ == "__main__":
    main()
```
