## 题目描述

给定一个 **无向图** 的节点数 `n` 和边数组 `edges`，其中 `edges[i] = [ui, vi]` 表示节点 `ui` 和节点 `vi` 之间有一条无向边。

请返回图中 **连通分量** 的数量。

### 示例 1

**输入：**
```
n = 5, edges = [[0,1],[1,2],[3,4]]
```

**输出：**
```
2
```

**解释：**
- 连通分量1：{0, 1, 2}
- 连通分量2：{3, 4}

### 示例 2

**输入：**
```
n = 3, edges = [[0,1],[1,2]]
```

**输出：**
```
1
```

**解释：**
- 所有节点都在同一个连通分量中

### 数据范围
- `1 <= n <= 200`
- `0 <= edges.length <= n * (n - 1) / 2`
- `edges[i].length == 2`
- `0 <= ui, vi < n`
- `ui != vi`
- 图中没有重复的边

## 笔试/面试考察点分析

### 核心考察点
1. **连通分量概念**：无向图中的连通分量（与有向图的强连通分量对比）
2. **并查集（Union-Find）**：解决连通性问题的经典数据结构
3. **DFS/BFS**：图的遍历方法

### 与SCC的对比
```
【核心区别】
无向图连通分量 vs 有向图强连通分量：
- 无向图：只要存在路径即连通，双向可达是自动的
- 有向图：需要双向都有路径才叫强连通
- 无向图连通分量可用并查集/DFS解决
- 有向图强连通分量需要Tarjan/Kosaraju算法
```

### 面试口述要点
```
"这道题求无向图的连通分量数量。无向图的连通比有向图简单，
只要两个节点之间有路径就是连通的。我可以用并查集来解决：
初始每个节点是一个集合，遍历每条边时合并两个端点所在的集合，
最后统计不同集合的数量就是连通分量数。也可以用DFS/BFS遍历图，
每次从一个未访问节点开始遍历，遍历次数就是连通分量数。"
```

## 解题思路

### 方法一：并查集（推荐）

**步骤：**
1. 初始化并查集，每个节点是一个独立集合
2. 遍历所有边，合并边的两个端点
3. 统计不同集合的数量

### 方法二：DFS/BFS遍历

**步骤：**
1. 建图（邻接表）
2. 对每个未访问节点进行DFS/BFS
3. 遍历次数就是连通分量数

## 完整代码实现

### Java实现（并查集）

```java
import java.util.*;

/**
 * 牛客网 NC200 - 朋友圈
 * 
 * 核心思路：并查集解决无向图连通分量问题
 * 时间复杂度：O(n + m × α(n))，空间复杂度：O(n)
 */
public class Solution {
    
    /**
     * 主方法：计算连通分量数量
     * 
     * @param n 节点数量（0到n-1）
     * @param edges 边的数组，无向边
     * @return 连通分量数量
     */
    public int findCircleNum(int n, int[][] edges) {
        // 步骤1：初始化并查集
        UnionFind uf = new UnionFind(n);
        
        // 步骤2：遍历所有边，合并集合
        for (int[] edge : edges) {
            int u = edge[0];  // 边的第一个端点
            int v = edge[1];  // 边的第二个端点
            
            // 合并u和v所在的集合
            uf.union(u, v);
        }
        
        // 步骤3：返回连通分量数量
        return uf.getCount();
    }
    
    /**
     * 并查集（Union-Find）数据结构
     * 
     * 用于维护无向图的连通性，支持O(α(n))的合并和查询
     * α(n)是阿克曼函数的反函数，近似常数
     */
    class UnionFind {
        // parent[i]表示节点i的父节点
        // 如果parent[i] == i，说明i是根节点（集合代表）
        private int[] parent;
        
        // rank[i]表示以i为根的集合的秩（近似树高）
        // 用于按秩合并，保持树的平衡
        private int[] rank;
        
        // count表示当前连通分量数量
        private int count;
        
        /**
         * 构造函数：初始化并查集
         * 
         * @param n 节点数量
         */
        public UnionFind(int n) {
            // 初始每个节点是一个独立集合
            this.count = n;
            
            // parent数组初始化：每个节点的父节点是自己
            this.parent = new int[n];
            for (int i = 0; i < n; i++) {
                parent[i] = i;
            }
            
            // rank数组初始化：初始秩为1
            this.rank = new int[n];
            Arrays.fill(rank, 1);
        }
        
        /**
         * 查找节点x所在集合的根节点（带路径压缩）
         * 
         * 路径压缩：将查找路径上的所有节点直接连接到根节点
         * 这样下次查找这些节点时就是O(1)
         * 
         * @param x 要查找的节点
         * @return x所在集合的根节点
         */
        public int find(int x) {
            // 如果x是根节点，直接返回
            if (parent[x] == x) {
                return x;
            }
            
            // 路径压缩：递归查找根节点，并直接将x的父节点设为根
            // 这是递归版本的路径压缩，也可以写成循环版本
            parent[x] = find(parent[x]);
            
            return parent[x];
        }
        
        /**
         * 合并节点x和y所在的集合（按秩合并）
         * 
         * @param x 第一个节点
         * @param y 第二个节点
         */
        public void union(int x, int y) {
            // 找到x和y所在集合的根节点
            int rootX = find(x);
            int rootY = find(y);
            
            // 如果已经在同一集合，不需要合并
            if (rootX == rootY) {
                return;
            }
            
            // 按秩合并：将秩小的树合并到秩大的树下
            // 这样可以保持树的平衡，避免树过高
            if (rank[rootX] < rank[rootY]) {
                // rootX的秩小，将rootX的父节点设为rootY
                parent[rootX] = rootY;
            } else if (rank[rootX] > rank[rootY]) {
                // rootY的秩小，将rootY的父节点设为rootX
                parent[rootY] = rootX;
            } else {
                // 秩相等，任选一个作为根，秩加1
                parent[rootY] = rootX;
                rank[rootX]++;
            }
            
            // 合并后连通分量数减1
            count--;
        }
        
        /**
         * 获取当前连通分量数量
         * 
         * @return 连通分量数
         */
        public int getCount() {
            return count;
        }
    }
}
```

### C++实现（并查集）

```cpp
#include <vector>
using namespace std;

/**
 * 牛客网 NC200 - 朋友圈
 * 并查集实现
 */
class Solution {
public:
    int findCircleNum(int n, vector<vector<int>>& edges) {
        // 初始化并查集
        parent.resize(n);
        rank_arr.resize(n, 1);
        count = n;
        
        for (int i = 0; i < n; i++) {
            parent[i] = i;
        }
        
        // 合并所有边
        for (auto& edge : edges) {
            unite(edge[0], edge[1]);
        }
        
        return count;
    }
    
private:
    vector<int> parent;
    vector<int> rank_arr;
    int count;
    
    // 带路径压缩的查找
    int find(int x) {
        if (parent[x] != x) {
            parent[x] = find(parent[x]);
        }
        return parent[x];
    }
    
    // 按秩合并
    void unite(int x, int y) {
        int rootX = find(x);
        int rootY = find(y);
        
        if (rootX == rootY) return;
        
        if (rank_arr[rootX] < rank_arr[rootY]) {
            parent[rootX] = rootY;
        } else if (rank_arr[rootX] > rank_arr[rootY]) {
            parent[rootY] = rootX;
        } else {
            parent[rootY] = rootX;
            rank_arr[rootX]++;
        }
        
        count--;
    }
};
```

### Python实现（并查集）

```python
from typing import List

class Solution:
    """
    牛客网 NC200 - 朋友圈
    并查集实现
    """
    
    def findCircleNum(self, n: int, edges: List[List[int]]) -> int:
        """
        计算连通分量数量
        
        Args:
            n: 节点数量
            edges: 边的列表
            
        Returns:
            连通分量数量
        """
        # 并查集类
        class UnionFind:
            def __init__(self, n):
                self.parent = list(range(n))
                self.rank = [1] * n
                self.count = n
            
            def find(self, x):
                if self.parent[x] != x:
                    self.parent[x] = self.find(self.parent[x])
                return self.parent[x]
            
            def union(self, x, y):
                root_x = self.find(x)
                root_y = self.find(y)
                
                if root_x == root_y:
                    return
                
                if self.rank[root_x] < self.rank[root_y]:
                    self.parent[root_x] = root_y
                elif self.rank[root_x] > self.rank[root_y]:
                    self.parent[root_y] = root_x
                else:
                    self.parent[root_y] = root_x
                    self.rank[root_x] += 1
                
                self.count -= 1
        
        uf = UnionFind(n)
        
        for u, v in edges:
            uf.union(u, v)
        
        return uf.count
```

### Java实现（DFS）

```java
import java.util.*;

/**
 * DFS方法求连通分量
 */
public class SolutionDFS {
    
    // 邻接表
    private List<Integer>[] graph;
    // 访问标记
    private boolean[] visited;
    
    public int findCircleNum(int n, int[][] edges) {
        // 步骤1：建图
        graph = new ArrayList[n];
        for (int i = 0; i < n; i++) {
            graph[i] = new ArrayList<>();
        }
        
        // 无向图，边要加两次
        for (int[] edge : edges) {
            graph[edge[0]].add(edge[1]);
            graph[edge[1]].add(edge[0]);
        }
        
        // 步骤2：DFS遍历
        visited = new boolean[n];
        int components = 0;
        
        for (int i = 0; i < n; i++) {
            if (!visited[i]) {
                dfs(i);
                components++;
            }
        }
        
        return components;
    }
    
    private void dfs(int u) {
        visited[u] = true;
        
        for (int v : graph[u]) {
            if (!visited[v]) {
                dfs(v);
            }
        }
    }
}
```

## 时间/空间复杂度分析

### 并查集版本

**时间复杂度：**
- 初始化并查集：$O(n)$
- 遍历边并合并：$O(m \times \alpha(n))$，其中$\alpha(n)$是阿克曼函数反函数，近似常数
- **总时间复杂度：** $O(n + m \times \alpha(n)) \approx O(n + m)$

**空间复杂度：**
- parent数组：$O(n)$
- rank数组：$O(n)$
- **总空间复杂度：** $O(n)$

### DFS版本

**时间复杂度：**
- 建图：$O(n + m)$
- DFS遍历：每个节点访问一次，$O(n + m)$
- **总时间复杂度：** $O(n + m)$

**空间复杂度：**
- 邻接表：$O(n + m)$
- 访问标记：$O(n)$
- 递归栈：最坏$O(n)$
- **总空间复杂度：** $O(n + m)$

## ML/DL关联思考

### 1. 图连通性与图神经网络

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class ConnectivityAwareGNN(nn.Module):
    """
    感知连通性的图神经网络
    显式编码连通分量信息
    """
    
    def __init__(self, in_dim, hidden_dim, out_dim):
        super().__init__()
        
        self.encoder = nn.Sequential(
            nn.Linear(in_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim)
        )
        
        # 连通性感知注意力
        self.connectivity_attn = nn.MultiheadAttention(hidden_dim, num_heads=4)
        
        self.classifier = nn.Linear(hidden_dim, out_dim)
    
    def forward(self, x, edge_index, components):
        """
        Args:
            x: 节点特征
            edge_index: 边索引
            components: 连通分量列表，每个分量是节点列表
        """
        # 基础编码
        h = self.encoder(x)
        
        # 在每个连通分量内部进行注意力
        component_reprs = []
        for comp in components:
            if len(comp) > 0:
                comp_feat = h[comp].unsqueeze(0)  # [1, comp_size, hidden]
                attn_out, _ = self.connectivity_attn(comp_feat, comp_feat, comp_feat)
                component_reprs.append(attn_out.squeeze(0).mean(dim=0))
        
        # 聚合所有分量表示
        if len(component_reprs) > 0:
            global_repr = torch.stack(component_reprs).mean(dim=0)
        else:
            global_repr = torch.zeros(hidden_dim)
        
        # 将全局表示加到每个节点
        h = h + global_repr
        
        return self.classifier(h)


def find_connected_components_dfs(n, edges):
    """
    使用DFS找到所有连通分量
    返回分量列表
    """
    graph = [[] for _ in range(n)]
    for u, v in edges:
        graph[u].append(v)
        graph[v].append(u)
    
    visited = [False] * n
    components = []
    
    def dfs(u, component):
        visited[u] = True
        component.append(u)
        for v in graph[u]:
            if not visited[v]:
                dfs(v, component)
    
    for i in range(n):
        if not visited[i]:
            component = []
            dfs(i, component)
            components.append(component)
    
    return components
```

### 2. 图粗化（Graph Coarsening）

```python
def coarsen_by_connected_components(graph, features):
    """
    使用连通分量进行图粗化
    每个连通分量粗化为一个超级节点
    
    可用于大图的多尺度分析
    """
    # 找到所有连通分量
    components = find_connected_components_dfs(graph.num_nodes, graph.edges)
    
    # 构建粗化图
    node_to_component = {}
    for idx, comp in enumerate(components):
        for node in comp:
            node_to_component[node] = idx
    
    # 粗化特征：每个分量取平均
    coarsened_features = []
    for comp in components:
        comp_feat = features[comp].mean(dim=0)
        coarsened_features.append(comp_feat)
    
    # 粗化边：分量间有边则添加
    coarse_edges = set()
    for u, v in graph.edges:
        cu, cv = node_to_component[u], node_to_component[v]
        if cu != cv:
            coarse_edges.add((cu, cv))
    
    return {
        'num_nodes': len(components),
        'features': torch.stack(coarsened_features),
        'edges': list(coarse_edges),
        'components': components
    }
```

本题是**无向图连通分量**的基础题目，核心掌握点：

1. **连通分量 vs 强连通分量**：
   - 无向图：双向可达自动满足

2. **并查集**：解决连通性问题的利器，时间复杂度接近线性
3. **DFS/BFS**：图的遍历方法，同样可以解决问题
4. **路径压缩与按秩合并**：并查集的优化技巧
