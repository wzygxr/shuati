## 题目描述

给定一个有向图，判断该图是否存在环。

### 输入格式

第一行两个整数 $n$ 和 $m$，表示图的顶点数和边数。

接下来 $m$ 行，每行两个整数 $u$ 和 $v$，表示从 $u$ 到 $v$ 有一条有向边。

### 输出格式

如果图中有环，输出 "Yes"，否则输出 "No"。

### 输入输出样例

**输入**
```
4 4
1 2
2 3
3 4
4 2
```

**输出**
```
Yes
```

**解释**：2→3→4→2 构成环

### 数据范围
- $1 \le n \le 10^5$
- $0 \le m \le 2 \times 10^5$

## 笔试/面试考察点分析

### 核心考察点
1. **环检测算法**：拓扑排序或Tarjan算法
2. **SCC的应用**：SCC大小>1表示存在环
3. **算法选择**：拓扑排序更简单，Tarjan可以同时求出所有环

### 解题方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 能否定位环 | 适用场景 |
|------|-----------|-----------|-----------|----------|
| **拓扑排序** | $O(V+E)$ | $O(V)$ | 否 | 只需要判断是否有环 |
| **Tarjan** | $O(V+E)$ | $O(V)$ | 能 | 需要找出所有SCC |
| **DFS染色** | $O(V+E)$ | $O(V)$ | 能 | 只需要找到一个环 |

### 面试口述要点
```
"判断有向图是否有环有三种常用方法：
1. 拓扑排序：如果能完成拓扑排序则无环，否则有环
2. Tarjan算法：如果存在大小大于1的SCC，则有环
3. DFS染色：访问到灰色节点（当前路径上的节点）说明有环

三种方法时间复杂度都是O(V+E)，根据具体需求选择。"
```

## 解题思路

### 方法一：拓扑排序（推荐）

```
1. 计算所有节点的入度
2. 将入度为0的节点加入队列
3. 依次取出节点，删除其出边（邻接点入度-1）
4. 若邻接点入度变为0，加入队列
5. 统计能处理的节点数，若小于n则存在环
```

### 方法二：Tarjan算法

```
1. 运行Tarjan算法求所有SCC
2. 若存在大小>1的SCC，说明存在环
3. 或者：若SCC数量为n（每个节点单独一个SCC），则无环
```

### 方法三：DFS染色法

```
0 = 未访问（白色）
1 = 正在访问（灰色）
2 = 已访问完毕（黑色）

DFS过程中遇到灰色节点，说明存在环
```

## 完整代码实现

### 方法一：拓扑排序（C++）

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 100001;

int n, m;
vector<int> adj[MAXN];
int inDegree[MAXN];

bool hasCycle() {
    queue<int> q;
    int cnt = 0;  // 统计处理的节点数
    
    // 入度为0的节点入队
    for (int i = 1; i <= n; i++) {
        if (inDegree[i] == 0) {
            q.push(i);
        }
    }
    
    while (!q.empty()) {
        int u = q.front();
        q.pop();
        cnt++;
        
        for (int v : adj[u]) {
            if (--inDegree[v] == 0) {
                q.push(v);
            }
        }
    }
    
    // 如果处理的节点数小于n，说明存在环
    return cnt < n;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    cin >> n >> m;
    for (int i = 0; i < m; i++) {
        int u, v;
        cin >> u >> v;
        adj[u].push_back(v);
        inDegree[v]++;
    }
    
    cout << (hasCycle() ? "Yes" : "No") << endl;
    return 0;
}
```

### 方法二：Tarjan算法（C++）

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 100001;

int n, m;
vector<int> adj[MAXN];

int dfn[MAXN], low[MAXN], timestamp;
int stk[MAXN], top;
bool in_stk[MAXN];
int scc_cnt;

void tarjan(int u) {
    dfn[u] = low[u] = ++timestamp;
    stk[++top] = u;
    in_stk[u] = true;
    
    for (int v : adj[u]) {
        if (!dfn[v]) {
            tarjan(v);
            low[u] = min(low[u], low[v]);
        } else if (in_stk[v]) {
            low[u] = min(low[u], dfn[v]);
        }
    }
    
    if (dfn[u] == low[u]) {
        scc_cnt++;
        int v;
        int scc_size = 0;
        do {
            v = stk[top--];
            in_stk[v] = false;
            scc_size++;
        } while (v != u);
        
        // 如果SCC大小>1，说明有环
        if (scc_size > 1) {
            // 可以设置全局标志
        }
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    cin >> n >> m;
    for (int i = 0; i < m; i++) {
        int u, v;
        cin >> u >> v;
        adj[u].push_back(v);
    }
    
    for (int i = 1; i <= n; i++) {
        if (!dfn[i]) tarjan(i);
    }
    
    // SCC数量小于n说明存在环
    cout << (scc_cnt < n ? "Yes" : "No") << endl;
    return 0;
}
```

### 方法三：DFS染色法（Python）

```python
from collections import defaultdict

def has_cycle_dfs(graph, n):
    """
    使用DFS染色法判断有向图是否有环
    color: 0=未访问(白), 1=访问中(灰), 2=已访问完(黑)
    """
    color = [0] * (n + 1)
    
    def dfs(u):
        color[u] = 1  # 标记为访问中（灰色）
        
        for v in graph[u]:
            if color[v] == 1:  # 遇到灰色节点，存在环
                return True
            if color[v] == 0 and dfs(v):  # 未访问，递归检查
                return True
        
        color[u] = 2  # 标记为已访问完（黑色）
        return False
    
    for i in range(1, n + 1):
        if color[i] == 0:  # 对每个未访问节点进行DFS
            if dfs(i):
                return True
    
    return False

# 主函数
def main():
    n, m = map(int, input().split())
    
    graph = defaultdict(list)
    for _ in range(m):
        u, v = map(int, input().split())
        graph[u].append(v)
    
    print("Yes" if has_cycle_dfs(graph, n) else "No")

if __name__ == "__main__":
    main()
```
