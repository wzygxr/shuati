# 强连通分量算法详解与面试指南

## 一、什么是强连通分量

### 1.1 定义

**强连通（Strongly Connected）**：在有向图中，如果顶点 $u$ 到顶点 $v$ 有路径，且 $v$ 到 $u$ 也有路径，则称 $u$ 和 $v$ 强连通。

**强连通分量（Strongly Connected Component, SCC）**：极大的强连通子图。即：
1. 分量内任意两个顶点强连通
2. 无法再加入其他顶点保持强连通性

### 1.2 直观理解

```
原图：          SCC缩点后：
1 → 2 → 3       SCC1 = {1,2,3} ──┐
↑ ↓   ↓         SCC2 = {4} ──────┼──→ SCC3 = {5}
└── 4 → 5                        │
                                 └──→ SCC4 = {6}
```

SCC缩点后形成**有向无环图（DAG）**，这是解决很多图问题的关键。

## 二、三大核心算法

### 2.1 Tarjan算法（最常用）

#### 核心思想
- 一次DFS遍历完成SCC识别
- 使用`dfn`数组记录DFS序
- 使用`low`数组记录能回溯到的最早祖先
- 使用栈维护当前DFS路径上的节点

#### 算法流程
```
1. 初始化：dfn[u] = low[u] = ++timestamp，u入栈
2. 遍历u的所有邻接点v：
   a. 若v未访问（树边）：递归访问v，回溯时low[u] = min(low[u], low[v])
   b. 若v已访问且在栈中（回边）：low[u] = min(low[u], dfn[v])
3. 若dfn[u] == low[u]：u是SCC根，弹出栈中节点直到u，构成一个SCC
```

#### 代码模板（C++）

```cpp
const int MAXN = 100001;

int dfn[MAXN], low[MAXN], timestamp;
int stk[MAXN], top;
bool in_stk[MAXN];
int id[MAXN], scc_cnt, sz[MAXN];
vector<int> adj[MAXN];

void tarjan(int u) {
    // 1. 初始化时间戳
    dfn[u] = low[u] = ++timestamp;
    stk[++top] = u;
    in_stk[u] = true;
    
    // 2. 遍历邻接点
    for (int v : adj[u]) {
        if (!dfn[v]) {
            // 树边
            tarjan(v);
            low[u] = min(low[u], low[v]);
        } else if (in_stk[v]) {
            // 回边
            low[u] = min(low[u], dfn[v]);
        }
    }
    
    // 3. 找到SCC根
    if (dfn[u] == low[u]) {
        ++scc_cnt;
        int v;
        do {
            v = stk[top--];
            in_stk[v] = false;
            id[v] = scc_cnt;      // 标记所属SCC
            sz[scc_cnt]++;        // SCC大小+1
        } while (v != u);
    }
}
```

#### 时间/空间复杂度
- **时间**：$O(V + E)$
- **空间**：$O(V)$

### 2.2 Kosaraju算法

#### 核心思想
- 两次DFS遍历
- 第一次：在反向图上DFS，记录完成顺序
- 第二次：按完成顺序的逆序在原图上DFS，每次DFS访问的节点构成一个SCC

#### 算法流程
```
1. 构建反向图
2. 第一次DFS（反向图）：记录节点的完成顺序
3. 按完成顺序的逆序，第二次DFS（原图）：
   - 每次DFS访问的所有节点构成一个SCC
```

#### 代码模板（C++）

```cpp
vector<int> adj[MAXN], adj_rev[MAXN];  // 原图和反向图
bool visited[MAXN];
vector<int> order;
int component[MAXN];

// 第一次DFS：反向图，记录顺序
void dfs1(int u) {
    visited[u] = true;
    for (int v : adj_rev[u]) {
        if (!visited[v]) dfs1(v);
    }
    order.push_back(u);
}

// 第二次DFS：原图，收集SCC
void dfs2(int u, int comp_id) {
    visited[u] = true;
    component[u] = comp_id;
    for (int v : adj[u]) {
        if (!visited[v]) dfs2(v, comp_id);
    }
}

void kosaraju(int n) {
    // 第一次DFS
    memset(visited, false, sizeof(visited));
    for (int i = 1; i <= n; i++) {
        if (!visited[i]) dfs1(i);
    }
    
    // 第二次DFS
    memset(visited, false, sizeof(visited));
    reverse(order.begin(), order.end());
    int comp_id = 0;
    for (int u : order) {
        if (!visited[u]) {
            dfs2(u, ++comp_id);
        }
    }
}
```

#### 时间/空间复杂度
- **时间**：$O(V + E)$
- **空间**：$O(V + E)$（需要存储反向图）

---

### 2.3 Gabow算法

#### 核心思想
- 使用两个栈：一个存储当前路径，一个存储候选SCC根
- 结合Tarjan和Kosaraju的思想

#### 特点
- 时间复杂度同样为$O(V + E)$
- 实现相对复杂，竞赛中较少使用

## 三、算法对比与选型

| 特性 | Tarjan | Kosaraju | Gabow |
|------|--------|----------|-------|
| **时间复杂度** | $O(V+E)$ | $O(V+E)$ | $O(V+E)$ |
| **空间复杂度** | $O(V)$ | $O(V+E)$ | $O(V)$ |
| **遍历次数** | 1次 | 2次 | 1次 |
| **实现难度** | 中等 | 简单 | 较难 |
| **常数因子** | 小 | 较大 | 小 |
| **笔试推荐** | ★★★★★ | ★★★☆☆ | ★★☆☆☆ |
| **面试理解** | ★★★★☆ | ★★★★★ | ★★☆☆☆ |

### 选型建议
- **笔试/竞赛**：首选**Tarjan**，效率高，常数小
- **教学/理解**：可选**Kosaraju**，逻辑清晰易懂
- **空间受限**：避免Kosaraju（需要存反向图）

## 四、缩点技巧

### 4.1 什么是缩点

将每个强连通分量缩成一个点，构造**有向无环图（DAG）**。

### 4.2 缩点步骤

```cpp
// 1. 求SCC（使用Tarjan或Kosaraju）
tarjan_all();

// 2. 构建缩点后的图
for (每条边(u, v) in 原图) {
    if (id[u] != id[v]) {  // 不同SCC
        add_condensed_edge(id[u], id[v]);
        in_degree[id[v]]++;
        out_degree[id[u]]++;
    }
}
```

### 4.3 缩点的应用

#### 1. 求最少加多少边使图强连通
```
缩点后，设入度为0的点有a个，出度为0的点有b个
答案 = max(a, b)
```

#### 2. 求被所有点到达的点
```
缩点后，出度为0的SCC中的点
```

#### 3. 求能到达所有点的点
```
缩点后，入度为0的SCC中的点
```

#### 4. DAG上的DP
```
缩点后形成DAG，可以按拓扑序进行动态规划
例如：最长路、最大权值链等
```

## 五、面试高频问题

### Q1: 请解释Tarjan算法中dfn和low数组的作用

**A:**
- `dfn[u]`：记录节点u在DFS中的发现时间戳（访问顺序）
- `low[u]`：记录从u出发，通过树边、回边、横叉边能到达的最小dfn值
- **核心作用**：`dfn[u] == low[u]` 时，u是某个SCC的根节点

### Q2: 如何判断一个边(u,v)是桥边（无向图）？

**A:**
在无向图的DFS中，边(u,v)是桥边当且仅当：`dfn[u] < low[v]`
含义：v的子树无法通过回边到达u或u的祖先

### Q3: Tarjan和Kosaraju算法的核心区别？

**A:**
- **Tarjan**：一次DFS+栈，实时识别SCC，空间更省
- **Kosaraju**：两次DFS（正向+反向），逻辑更简单，但需要存反向图

### Q4: 为什么缩点后得到的一定是DAG？

**A:**
假设缩点后存在环，则环上所有SCC可以合并成一个更大的SCC，与SCC的"极大性"矛盾。

### Q5: 强连通分量和双连通分量的区别？

**A:**
| 特性 | 强连通分量 | 点双连通分量 | 边双连通分量 |
|------|-----------|-------------|-------------|
| **适用图** | 有向图 | 无向图 | 无向图 |
| **定义** | 双向可达 | 删除任意点仍连通 | 删除任意边仍连通 |
| **算法** | Tarjan/Kosaraju | Tarjan | Tarjan |

## 六、机器学习/深度学习关联

### 6.1 图数据预处理

#### SCC用于图简化
```python
def preprocess_graph_for_gnn(graph, features):
    """
    使用SCC简化图，降低GNN计算复杂度
    """
    # 求SCC
    sccs = tarjan_scc(graph)
    
    # 缩点
    condensed_graph = condense(graph, sccs)
    
    # 特征聚合：SCC内特征平均
    condensed_features = []
    for scc in sccs:
        scc_feat = features[scc].mean(axis=0)
        condensed_features.append(scc_feat)
    
    return condensed_graph, condensed_features
```

**价值：**
- 降低图规模，加速GNN训练
- 合并语义相似节点，降噪
