# 洛谷 P2341 - 受欢迎的牛

## 题目链接
https://www.luogu.com.cn/problem/P2341

## 题目描述

每头牛都有自己的梦想：成为一个明星牛，被所有牛喜欢。现在有 $N$ 头牛，给出 $M$ 个喜欢关系（$A \rightarrow B$ 表示 $A$ 喜欢 $B$），喜欢关系具有传递性。如果 $A$ 喜欢 $B$，$B$ 喜欢 $C$，那么 $A$ 也喜欢 $C$。

求被所有牛都喜欢的牛的数量（明星牛数量）。

### 输入格式

第一行两个整数 $N$ 和 $M$。

接下来 $M$ 行，每行两个整数 $A$ 和 $B$，表示 $A$ 喜欢 $B$（$A \rightarrow B$）。

### 输出格式

一行一个整数，表示明星牛的数量。

### 输入输出样例

**输入 #1**
```
3 3
1 2
2 1
2 3
```

**输出 #1**
```
1
```

### 说明/提示

- $1 \le N \le 10^4$
- $1 \le M \le 5 \times 10^4$

---

## 笔试/面试考察点分析

### 核心考察点
1. **缩点（Condensation）思想**：将强连通分量缩为一个节点，简化问题
2. **DAG性质分析**：缩点后得到有向无环图，便于分析可达性
3. **出度分析**：明星牛所在的SCC出度必须为0（否则有些牛无法到达它）

### 解题关键 insight
```
【核心观察】
1. 同一个SCC内的牛互相可达，所以要么全部是明星，要么全部不是
2. 缩点后，若一个SCC出度>0，则它指向的其他SCC中的牛无法喜欢它
3. 因此，只有出度为0的SCC才可能包含明星牛
4. 若有多个出度为0的SCC，则这些SCC之间不可达，不可能都是明星
5. 结论：出度为0的SCC只能有1个，该SCC的大小即为答案
```

### 面试口述要点
```
"这道题的关键是缩点。首先用Tarjan算法求出所有强连通分量，
 然后将每个SCC缩成一个点，得到一个有向无环图。
 在DAG中，只有出度为0的SCC才可能被所有节点到达。
 如果存在多个出度为0的SCC，它们互相不可达，就没有明星牛。
 所以答案就是唯一的出度为0的SCC的大小。"
```

---

## 解题思路

### 步骤1：求强连通分量
使用Tarjan算法求出所有SCC，记录每个节点所属的SCC编号。

### 步骤2：缩点
遍历原图的所有边，若边的两端属于不同SCC，则在缩点后的图中添加边，并统计每个SCC的出度。

### 步骤3：分析出度为0的SCC
- 若出度为0的SCC数量为0：不可能（DAG至少有一个汇点）
- 若出度为0的SCC数量为1：该SCC的大小即为答案
- 若出度为0的SCC数量>1：没有明星牛，答案为0

## 完整代码实现

### Java实现

```java
import java.io.IOException; // 导入IO异常处理类
import java.io.InputStream; // 导入输入流基类
import java.io.OutputStreamWriter; // 导入输出流写入器
import java.io.PrintWriter; // 导入打印写入器

public class Main { // 主类，洛谷提交时类名为Main

    // 最大节点数，根据题目N<=10^4设置
    public static int MAXN = 10001;
    
    // 最大边数，根据题目M<=5*10^4设置
    public static int MAXM = 50001;
    
    // 图的节点数N和边数M
    public static int n, m;
    
    // 存储输入的边，用于后续缩点
    // a[i]表示第i条边的起点，b[i]表示第i条边的终点
    public static int[] a = new int[MAXM];
    public static int[] b = new int[MAXM];

    // 链式前向星存图
    public static int[] head = new int[MAXN]; // 邻接表头指针
    public static int[] nxt = new int[MAXM];  // 下一条边索引
    public static int[] to = new int[MAXM];   // 目标节点
    public static int cntg;                   // 边计数器

    // Tarjan算法相关
    public static int[] dfn = new int[MAXN];  // DFS序
    public static int[] low = new int[MAXN];  // 能回溯到的最早祖先
    public static int cntd;                   // 时间戳计数器
    
    public static int[] sta = new int[MAXN];  // 手动栈
    public static int top;                    // 栈顶指针
    
    public static int[] belong = new int[MAXN]; // 节点所属SCC编号
    public static int[] sccSiz = new int[MAXN]; // 每个SCC的大小
    public static int sccCnt;                   // SCC总数

    // 缩点相关：统计每个SCC的出度
    public static int[] outdegree = new int[MAXN];

    // 添加边：从u到v添加一条有向边
    public static void addEdge(int u, int v) {
        // 使用头插法添加边
        nxt[++cntg] = head[u]; // 新边的下一条指向原来的头
        to[cntg] = v;          // 设置目标节点
        head[u] = cntg;        // 更新头指针
    }

    // Tarjan算法：求强连通分量
    public static void tarjan(int u) {
        // 初始化dfn和low为当前时间戳
        dfn[u] = low[u] = ++cntd;
        // 节点入栈
        sta[++top] = u;
        
        // 遍历u的所有邻接边
        for (int e = head[u]; e > 0; e = nxt[e]) {
            int v = to[e]; // 邻接点
            
            if (dfn[v] == 0) { // 树边：v未访问
                // 递归访问v
                tarjan(v);
                // 回溯时更新low[u]
                low[u] = Math.min(low[u], low[v]);
            } else if (belong[v] == 0) { // 回边：v在栈中
                // 用v的dfn更新low[u]
                low[u] = Math.min(low[u], dfn[v]);
            }
        }
        
        // 找到SCC根节点
        if (dfn[u] == low[u]) {
            sccCnt++; // SCC计数+1
            int pop;  // 弹出的节点
            // 弹出栈中节点直到u
            do {
                pop = sta[top--];      // 弹出栈顶
                belong[pop] = sccCnt;  // 标记所属SCC
                sccSiz[sccCnt]++;      // SCC大小+1
            } while (pop != u);
        }
    }

    // 主函数
    public static void main(String[] args) throws Exception {
        FastReader in = new FastReader(System.in); // 快速输入
        PrintWriter out = new PrintWriter(new OutputStreamWriter(System.out)); // 输出
        
        // 读入节点数和边数
        n = in.nextInt();
        m = in.nextInt();
        
        // 读入所有边并建图
        for (int i = 1; i <= m; i++) {
            a[i] = in.nextInt(); // 边i的起点
            b[i] = in.nextInt(); // 边i的终点
            addEdge(a[i], b[i]); // 添加边
        }
        
        // 对所有未访问节点运行Tarjan算法
        for (int i = 1; i <= n; i++) {
            if (dfn[i] == 0) {
                tarjan(i);
            }
        }
        
        // 缩点：统计每个SCC的出度
        for (int i = 1; i <= m; i++) {
            int scc1 = belong[a[i]]; // 起点所属SCC
            int scc2 = belong[b[i]]; // 终点所属SCC
            
            // 如果两端属于不同SCC，则scc1到scc2有一条边
            if (scc1 != scc2) {
                outdegree[scc1]++; // scc1的出度+1
            }
        }
        
        // 统计出度为0的SCC
        int zeroOutDegreeCount = 0; // 出度为0的SCC数量
        int answer = 0;              // 答案（明星牛数量）
        
        for (int i = 1; i <= sccCnt; i++) {
            if (outdegree[i] == 0) { // 找到出度为0的SCC
                zeroOutDegreeCount++;
                answer = sccSiz[i];  // 记录该SCC的大小
            }
        }
        
        // 如果出度为0的SCC超过1个，说明没有明星牛
        if (zeroOutDegreeCount > 1) {
            answer = 0;
        }
        
        // 输出答案
        out.println(answer);
        out.flush();
        out.close();
    }

    // 快速输入类
    static class FastReader {
        private final byte[] buffer = new byte[1 << 16]; // 64KB缓冲区
        private int ptr = 0, len = 0;
        private final InputStream in;

        FastReader(InputStream in) {
            this.in = in;
        }

        private int readByte() throws IOException {
            if (ptr >= len) {
                len = in.read(buffer);
                ptr = 0;
                if (len <= 0) return -1;
            }
            return buffer[ptr++];
        }

        int nextInt() throws IOException {
            int c;
            do {
                c = readByte();
            } while (c <= ' ' && c != -1);
            
            boolean neg = false;
            if (c == '-') {
                neg = true;
                c = readByte();
            }
            
            int val = 0;
            while (c > ' ' && c != -1) {
                val = val * 10 + (c - '0');
                c = readByte();
            }
            return neg ? -val : val;
        }
    }
}
```

### C++实现

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 10001;
const int MAXM = 50001;

int n, m;
int a[MAXM], b[MAXM]; // 存储边

// 链式前向星
int head[MAXN], nxt[MAXM], to[MAXM], cntg;

// Tarjan
int dfn[MAXN], low[MAXN], cntd;
int sta[MAXN], top;
int belong[MAXN], sccSiz[MAXN], sccCnt;

// 缩点
int outdegree[MAXN];

void addEdge(int u, int v) {
    nxt[++cntg] = head[u];
    to[cntg] = v;
    head[u] = cntg;
}

void tarjan(int u) {
    dfn[u] = low[u] = ++cntd;
    sta[++top] = u;
    
    for (int e = head[u]; e; e = nxt[e]) {
        int v = to[e];
        if (!dfn[v]) {
            tarjan(v);
            low[u] = min(low[u], low[v]);
        } else if (!belong[v]) {
            low[u] = min(low[u], dfn[v]);
        }
    }
    
    if (dfn[u] == low[u]) {
        sccCnt++;
        int pop;
        do {
            pop = sta[top--];
            belong[pop] = sccCnt;
            sccSiz[sccCnt]++;
        } while (pop != u);
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    cin >> n >> m;
    for (int i = 1; i <= m; i++) {
        cin >> a[i] >> b[i];
        addEdge(a[i], b[i]);
    }
    
    for (int i = 1; i <= n; i++) {
        if (!dfn[i]) tarjan(i);
    }
    
    // 缩点统计出度
    for (int i = 1; i <= m; i++) {
        int scc1 = belong[a[i]];
        int scc2 = belong[b[i]];
        if (scc1 != scc2) {
            outdegree[scc1]++;
        }
    }
    
    // 统计出度为0的SCC
    int cnt = 0, ans = 0;
    for (int i = 1; i <= sccCnt; i++) {
        if (outdegree[i] == 0) {
            cnt++;
            ans = sccSiz[i];
        }
    }
    
    if (cnt > 1) ans = 0;
    
    cout << ans << "\n";
    return 0;
}
```

## 时间/空间复杂度分析

### 时间复杂度
- **Tarjan算法**：$O(N + M)$
- **缩点统计出度**：$O(M)$，遍历所有边
- **总时间复杂度**：$O(N + M)$

### 空间复杂度
- **图存储**：$O(N + M)$
- **Tarjan数组**：$O(N)$
- **总空间复杂度**：$O(N + M)$

### 1. 社交网络分析中的"意见领袖"发现
本题的场景与**社交网络中的意见领袖（KOL）发现**高度相关：

```python
def find_influencers_by_scc(social_graph):
    """
    使用SCC发现社交网络中的意见领袖群体
    
    Args:
        social_graph: 有向图，边表示关注关系 A->B 表示A关注B
    
    Returns:
        influencers: 意见领袖节点列表
    """
    # 1. 求SCC
    sccs = tarjan_scc(social_graph)
    
    # 2. 缩点构建关注关系DAG
    scc_graph, node_to_scc = condense_graph(social_graph, sccs)
    
    # 3. 找出度为0的SCC（被所有人关注的群体）
    influencers = []
    for scc_id, scc_nodes in enumerate(sccs):
        if scc_graph.out_degree(scc_id) == 0:
            # 这个SCC中的所有节点都是意见领袖
            influencers.extend(scc_nodes)
    
    return influencers
```

**实际应用：**
- **微博大V发现**：找出被最多用户关注的账号群体
- **GitHub关键项目**：找出被最多项目依赖的库
- **论文引用网络**：找出被引用最多的论文群落

### 2. 推荐系统中的核心物品发现
在推荐系统中，可以用SCC找出**核心物品群**：

```python
def find_core_items(user_item_graph):
    """
    在用户-物品交互图中发现核心物品
    
    假设：物品之间的共现关系构成有向图
    如果物品A经常与物品B一起被购买，添加边A->B
    """
    # 构建物品共现图
    item_graph = build_cooccurrence_graph(user_item_graph)
    
    # 求SCC并缩点
    sccs = tarjan_scc(item_graph)
    condensed_graph, item_to_scc = condense_graph(item_graph, sccs)
    
    # 找出度为0的SCC（最"流行"的物品群）
    core_items = []
    for scc_id, items in enumerate(sccs):
        if condensed_graph.out_degree(scc_id) == 0:
            # 这些物品是核心物品，应该优先推荐
            core_items.extend(items)
    
    return core_items
```

**推荐价值：**
- **冷启动**：新用户优先推荐核心物品群中的物品
- **多样性**：不同SCC代表不同兴趣圈子，用于增加推荐多样性
- **解释性**：SCC结构可以解释为什么推荐这些物品（同属一个圈子）

## 总结

本题是**SCC缩点思想的经典应用**，核心掌握点：

1. **缩点目的**：将复杂有向图简化为DAG，便于分析可达性
2. **关键观察**：出度为0的SCC才能被所有节点到达
3. **唯一性判断**：多个出度为0的SCC意味着没有"明星"
4. **ML应用**：社交网络意见领袖发现、推荐系统核心物品识别

**笔试技巧**：先求SCC，再统计出度，代码量少，易得分。
**面试重点**：解释为什么出度为0的SCC才是候选明星。
