# 洛谷 B3609 - 【模板】强连通分量

## 题目链接
https://www.luogu.com.cn/problem/B3609

## 题目描述

给定一张 $n$ 个点 $m$ 条边的**有向图**，求出所有的强连通分量。

注意：本题**无重边**。

### 输入格式

第一行两个整数 $n$ 和 $m$。

接下来的 $m$ 行，每行两个整数 $u, v$ 表示一条从 $u$ 到 $v$ 的有向边。

### 输出格式

第一行一个整数 $s$ 表示强连通分量的个数。

接下来的 $s$ 行，每行第一个整数 $s_i$ 表示第 $i$ 个强连通分量的节点数，接下来 $s_i$ 个整数表示这个强连通分量内的节点编号。请按照每个强连通分量的最小节点编号升序输出。

### 输入输出样例

**输入 #1**
```
5 5
2 1
1 3
3 2
2 4
4 5
```

**输出 #1**
```
3
1 5
2 1 3
2 4 2
```

### 说明/提示

【数据范围】
- $1 \le n \le 10^4$
- $1 \le m \le 10^5$

## 笔试/面试考察点分析

### 核心考察点
1. **Tarjan算法模板掌握程度**：笔试中最常考的SCC算法，要求能熟练手写
2. **dfn与low数组的理解**：面试高频考点，需清晰解释两者区别和更新逻辑
3. **栈的运用**：理解为什么需要栈、什么时候出栈、如何判断SCC根节点

### 常见坑点
1. **数组大小**：边数$10^5$，数组要开足够大（$MAXM = 100001$）
2. **递归深度**：$n=10^4$时递归可能栈溢出，建议掌握迭代版本
3. **输出顺序**：题目要求按SCC最小节点编号排序输出

### 面试口述要点
```
"Tarjan算法的核心是一次DFS遍历，用dfn数组记录节点发现时间戳，
 low数组记录该节点能回溯到的最早祖先的dfn值。
 当dfn[u]==low[u]时，说明u是某个强连通分量的根节点，
 此时将栈中节点弹出直到u，这些节点构成一个强连通分量。"
```

---

## 解题思路

### 步骤1：建图
使用链式前向星（邻接表）存储有向图，空间复杂度$O(V+E)$。

### 步骤2：Tarjan算法求SCC
核心逻辑：
1. 初始化`dfn[u] = low[u] = ++timestamp`，节点入栈
2. 遍历所有邻接点v：
   - 若v未访问（树边）：递归访问v，回溯时`low[u] = min(low[u], low[v])`
   - 若v已访问且在栈中（回边）：`low[u] = min(low[u], dfn[v])`
3. 若`dfn[u] == low[u]`，说明找到SCC根，弹出栈中节点直到u

### 步骤3：排序输出
对每个SCC内的节点排序，再按SCC的最小节点编号排序输出。

```java
import java.io.IOException; // 导入IO异常处理类，处理输入输出可能产生的异常
import java.io.InputStream; // 导入输入流基类
import java.io.OutputStreamWriter; // 导入输出流写入器，用于包装输出流
import java.io.PrintWriter; // 导入打印写入器，提供便捷的输出方法
import java.util.Arrays; // 导入数组工具类，用于数组排序

public class Main { // 主类定义，洛谷提交时类名必须是Main

    // 定义最大节点数常量，根据题目数据范围n<=10^4，开10001足够
    // 笔试时需根据题目数据范围调整，一般多开10%防止边界问题
    public static int MAXN = 10001;
    
    // 定义最大边数常量，根据题目数据范围m<=10^5，开100001足够
    // 注意有向图每条边只存一次，无向图需要开两倍空间
    public static int MAXM = 100001;
    
    // 图的节点数n和边数m，从输入读取
    public static int n, m;

    // 邻接表头指针数组，head[i]表示节点i的邻接表头指针
    // 初始值为0表示空，链式前向星使用1-based索引
    public static int[] head = new int[MAXN];
    
    // 邻接表边的下一条边索引数组，nxt[i]表示第i条边的下一条边
    public static int[] nxt = new int[MAXM];
    
    // 邻接表边的目标节点数组，to[i]表示第i条边指向的节点
    public static int[] to = new int[MAXM];
    
    // 邻接表计数器，记录当前已添加的边数，用于给新边分配索引
    public static int cntg;

    // dfn数组：DFS序（发现时间戳），dfn[i]表示节点i被访问的顺序
    // 初始值为0表示未访问，从1开始计数
    public static int[] dfn = new int[MAXN];
    
    // low数组：能回溯到的最早祖先的dfn值
    // low[i]表示从节点i出发能到达的所有节点中最小的dfn值
    public static int[] low = new int[MAXN];
    
    // 时间戳计数器，每访问一个新节点就自增
    public static int cntd;

    // Tarjan算法使用的栈，用数组模拟，存储当前DFS路径上的节点
    // 只有还在栈中的节点才可能属于当前正在寻找的SCC
    public static int[] sta = new int[MAXN];
    
    // 栈顶指针，指向栈中最后一个元素的位置，0表示栈空
    public static int top;

    // belong数组：记录每个节点属于哪个强连通分量
    // belong[i]=j表示节点i属于第j个SCC，0表示尚未分配
    public static int[] belong = new int[MAXN];
    
    // sccArr数组：存储所有SCC中的节点，按SCC编号顺序排列
    // 用于最终输出时按SCC分组
    public static int[] sccArr = new int[MAXN];
    
    // sccl数组：记录每个SCC在sccArr中的起始位置（左边界）
    public static int[] sccl = new int[MAXN];
    
    // sccr数组：记录每个SCC在sccArr中的结束位置（右边界）
    public static int[] sccr = new int[MAXN];
    
    // sccArr数组的当前索引，指向下一个可写入位置
    public static int idx;
    
    // 强连通分量的总数计数器
    public static int sccCnt;

    // sccPrint数组：标记每个SCC是否已经输出过
    // 防止重复输出同一个SCC
    public static boolean[] sccPrint = new boolean[MAXN];

    // 添加边的方法：从u到v添加一条有向边
    // 使用链式前向星存储，头插法，时间复杂度O(1)
    public static void addEdge(int u, int v) {
        // cntg先自增，得到新边的索引（1-based）
        // 将新边的下一条边指向u原来的头节点
        nxt[++cntg] = head[u];
        // 设置新边的目标节点为v
        to[cntg] = v;
        // 更新u的邻接表头指针指向新边
        head[u] = cntg;
    }

    // Tarjan算法核心方法：求强连通分量
    // u表示当前访问的节点
    public static void tarjan(int u) {
        // 初始化当前节点的dfn和low值为当前时间戳
        // dfn[u]记录发现时间，low[u]初始化为dfn[u]
        dfn[u] = low[u] = ++cntd;
        
        // 将当前节点压入栈中
        // 栈中保存的是当前DFS路径上的节点，只有这些节点可能形成SCC
        sta[++top] = u;
        
        // 遍历u的所有邻接边
        // e是边的索引，通过nxt[e]遍历下一条边，直到e=0表示遍历完成
        for (int e = head[u]; e > 0; e = nxt[e]) {
            // 获取当前边指向的节点v
            int v = to[e];
            
            // 情况1：v未被访问过（树边）
            // 这是DFS树中的正常边，继续递归深入
            if (dfn[v] == 0) {
                // 递归访问v，继续深度优先搜索
                tarjan(v);
                
                // 从v回溯后，用v的low值更新u的low值
                // 因为u可以通过v到达v能到达的所有节点
                // 所以u能回溯到的最早祖先至少是v能回溯到的最早祖先
                low[u] = Math.min(low[u], low[v]);
            } 
            // 情况2：v已被访问过且在栈中（回边或横叉边）
            // belong[v]==0表示v还在栈中（未分配到某个SCC）
            else if (belong[v] == 0) {
                // 用v的dfn值更新u的low值
                // 因为u可以通过这条边直接到达v
                // 所以u能回溯到的最早祖先可能是v的发现时间
                // 注意：这里用dfn[v]而不是low[v]，因为v可能属于另一个SCC
                low[u] = Math.min(low[u], dfn[v]);
            }
            // 情况3：v已被访问过且不在栈中（弃边）
            // 这种情况v已经属于某个已找到的SCC，无需处理
        }
        
        // 判断u是否为某个强连通分量的根节点
        // 当dfn[u]==low[u]时，说明u无法回溯到更早的祖先
        // 此时栈中从u到栈顶的所有节点构成一个强连通分量
        if (dfn[u] == low[u]) {
            // 找到一个新SCC，计数器加1
            sccCnt++;
            
            // 记录当前SCC在sccArr中的起始位置
            // idx+1是因为idx是当前最后一个元素的位置
            sccl[sccCnt] = idx + 1;
            
            // 临时变量，存储弹出的节点
            int pop;
            
            // 从栈中弹出节点，直到弹出u
            // 这些弹出的节点都属于同一个SCC
            do {
                // 弹出栈顶节点
                pop = sta[top--];
                
                // 标记pop属于第sccCnt个SCC
                belong[pop] = sccCnt;
                
                // 将pop加入sccArr数组
                sccArr[++idx] = pop;
            } while (pop != u); // 直到弹出u为止
            
            // 记录当前SCC在sccArr中的结束位置
            sccr[sccCnt] = idx;
        }
    }

    // 主函数：程序入口
    public static void main(String[] args) throws Exception {
        // 创建快速输入读取器
        FastReader in = new FastReader(System.in);
        
        // 创建输出写入器，使用PrintWriter提高输出效率
        PrintWriter out = new PrintWriter(new OutputStreamWriter(System.out));
        
        // 读取节点数n
        n = in.nextInt();
        
        // 读取边数m
        m = in.nextInt();
        
        // 读取m条边并建图
        for (int i = 1, u, v; i <= m; i++) {
            // 读取边的起点u
            u = in.nextInt();
            // 读取边的终点v
            v = in.nextInt();
            // 添加从u到v的有向边
            addEdge(u, v);
        }
        
        // 对所有未访问过的节点运行Tarjan算法
        // 图可能不连通，需要遍历所有节点作为起点
        for (int i = 1; i <= n; i++) {
            // 如果节点i未被访问过（dfn[i]==0）
            if (dfn[i] == 0) {
                // 从i开始运行Tarjan算法
                tarjan(i);
            }
        }
        
        // 输出强连通分量的数量
        out.println(sccCnt);
        
        // 对每个SCC内部的节点进行排序
        // 题目要求每个SCC内部按节点编号升序输出
        for (int i = 1; i <= sccCnt; i++) {
            // 对sccArr中第i个SCC的范围[sccl[i], sccr[i]]进行排序
            Arrays.sort(sccArr, sccl[i], sccr[i] + 1);
        }
        
        // 创建数组存储每个SCC的最小节点编号，用于排序输出
        int[] minNode = new int[sccCnt + 1];
        for (int i = 1; i <= sccCnt; i++) {
            // 第i个SCC的最小节点就是排序后的第一个元素
            minNode[i] = sccArr[sccl[i]];
        }
        
        // 按节点1到n的顺序，输出包含该节点的SCC
        // 这样自然按SCC的最小节点编号升序输出
        for (int i = 1; i <= n; i++) {
            // 获取节点i所属的SCC编号
            int scc = belong[i];
            
            // 如果这个SCC还没有输出过
            if (!sccPrint[scc]) {
                // 标记为已输出
                sccPrint[scc] = true;
                
                // 计算这个SCC的大小
                int size = sccr[scc] - sccl[scc] + 1;
                
                // 输出SCC大小
                out.print(size);
                
                // 输出SCC中的所有节点
                for (int j = sccl[scc]; j <= sccr[scc]; j++) {
                    out.print(" " + sccArr[j]);
                }
                
                // 换行
                out.println();
            }
        }
        
        // 刷新输出缓冲区，确保所有数据输出
        out.flush();
        
        // 关闭输出流
        out.close();
    }

    // 快速输入类：使用缓冲区读取，提高输入速度
    // 笔试/竞赛中常用，避免Scanner的TLE风险
    static class FastReader {
        // 输入缓冲区，大小为64KB（1<<16）
        private final byte[] buffer = new byte[1 << 16];
        
        // 缓冲区当前读取位置和有效长度
        private int ptr = 0, len = 0;
        
        // 输入流对象
        private final InputStream in;

        // 构造函数，初始化输入流
        FastReader(InputStream in) {
            this.in = in;
        }

        // 读取下一个字节的方法
        private int readByte() throws IOException {
            // 如果当前指针超出缓冲区有效范围
            if (ptr >= len) {
                // 从输入流读取一批数据到缓冲区
                len = in.read(buffer);
                // 重置读取指针到缓冲区开头
                ptr = 0;
                // 如果没有读到数据，返回-1表示结束
                if (len <= 0)
                    return -1;
            }
            // 返回当前指针处的字节并移动指针
            return buffer[ptr++];
        }

        // 读取下一个整数的方法
        int nextInt() throws IOException {
            int c; // 当前读取的字符
            
            // 跳过空白字符（空格、换行、制表符等）
            do {
                c = readByte();
            } while (c <= ' ' && c != -1);
            
            // 判断是否为负数
            boolean neg = false;
            if (c == '-') {
                neg = true; // 标记为负数
                c = readByte(); // 读取下一个字符
            }
            
            int val = 0; // 存储结果
            
            // 读取连续的数字字符
            while (c > ' ' && c != -1) {
                // 将字符转换为数字并累加
                // c - '0'将字符'0'-'9'转换为数字0-9
                val = val * 10 + (c - '0');
                c = readByte();
            }
            
            // 根据正负返回结果
            return neg ? -val : val;
        }
    }
}
```

### Python实现

```python
import sys
from collections import defaultdict

# 设置递归深度限制，Python默认1000，本题n<=10^4需要设置更大
sys.setrecursionlimit(20000)

def main():
    data = sys.stdin.read().strip().split()  # 快速读取所有输入
    it = iter(data)
    
    n = int(next(it))  # 节点数
    m = int(next(it))  # 边数
    
    # 建图：使用邻接表
    graph = defaultdict(list)
    for _ in range(m):
        u = int(next(it))
        v = int(next(it))
        graph[u].append(v)  # 添加有向边u->v
    
    # Tarjan算法相关变量
    dfn = [0] * (n + 1)      # DFS序
    low = [0] * (n + 1)      # 能回溯到的最早祖先
    timestamp = [0]          # 使用列表包装，实现引用传递
    
    stack = []               # 手动栈
    in_stack = [False] * (n + 1)  # 标记节点是否在栈中
    
    belong = [0] * (n + 1)   # 节点所属SCC
    scc_nodes = []           # 存储每个SCC的节点列表
    
    def tarjan(u):
        """Tarjan算法求强连通分量"""
        timestamp[0] += 1
        dfn[u] = low[u] = timestamp[0]  # 初始化时间戳
        
        stack.append(u)       # 节点入栈
        in_stack[u] = True
        
        # 遍历所有邻接点
        for v in graph[u]:
            if dfn[v] == 0:   # 树边：v未访问
                tarjan(v)
                low[u] = min(low[u], low[v])  # 回溯更新
            elif in_stack[v]: # 回边：v在栈中
                low[u] = min(low[u], dfn[v])  # 用dfn更新
        
        # 找到SCC根节点
        if dfn[u] == low[u]:
            scc = []          # 当前SCC的节点列表
            while True:
                v = stack.pop()
                in_stack[v] = False
                belong[v] = len(scc_nodes) + 1  # SCC编号
                scc.append(v)
                if v == u:
                    break
            scc.sort()        # SCC内部排序
            scc_nodes.append(scc)
    
    # 对所有未访问节点运行Tarjan
    for i in range(1, n + 1):
        if dfn[i] == 0:
            tarjan(i)
    
    # 按SCC的最小节点编号排序
    scc_nodes.sort(key=lambda x: x[0])
    
    # 输出结果
    output = []
    output.append(str(len(scc_nodes)))
    for scc in scc_nodes:
        output.append(str(len(scc)) + " " + " ".join(map(str, scc)))
    
    print("\n".join(output))

if __name__ == "__main__":
    main()
```

## 时间/空间复杂度分析

### 时间复杂度
- **建图**：$O(m)$，遍历所有边
- **Tarjan算法**：$O(n + m)$，每个节点访问一次，每条边遍历一次
- **排序**：$O(n \log n)$，对所有SCC内部排序
- **总时间复杂度**：$O(n + m + n \log n) = O(n \log n + m)$

### 空间复杂度
- **图存储**：$O(n + m)$，链式前向星
- **Tarjan数组**：$O(n)$，dfn、low、belong、sta等
- **SCC存储**：$O(n)$，sccArr等
- **总空间复杂度**：$O(n + m)$

### 面试常考复杂度问题
**Q: 为什么Tarjan算法时间复杂度是O(V+E)？**

**A:** 
- DFS过程中每个节点只被访问一次，时间$O(V)$
- 每条边只被遍历一次（从起点出发时），时间$O(E)$
- 栈操作（入栈出栈）每个节点各一次，时间$O(V)$
- 因此总时间复杂度为$O(V + E)$

## ML/DL关联思考

### 1. 图结构数据预处理
在实际机器学习场景中，**SCC可用于图数据的降噪和简化**：

```python
# 示例：使用SCC简化大规模图数据
def simplify_graph_by_scc(graph, features):
    """
    使用SCC合并图中紧密连接的节点
    
    Args:
        graph: 邻接表表示的有向图
        features: 节点特征矩阵 [n_nodes, n_features]
    
    Returns:
        condensed_graph: 缩点后的DAG
        condensed_features: SCC聚合后的特征 [n_scc, n_features]
    """
    # 1. 求强连通分量
    scc_list = tarjan_scc(graph)  # 返回SCC列表
    
    # 2. 构建SCC到节点的映射
    node_to_scc = {}
    for scc_id, nodes in enumerate(scc_list):
        for node in nodes:
            node_to_scc[node] = scc_id
    
    # 3. 缩点：构建DAG
    condensed_graph = defaultdict(list)
    for u in graph:
        for v in graph[u]:
            scc_u, scc_v = node_to_scc[u], node_to_scc[v]
            if scc_u != scc_v:
                condensed_graph[scc_u].append(scc_v)
    
    # 4. 特征聚合：SCC内节点特征取平均
    condensed_features = []
    for nodes in scc_list:
        scc_feature = features[nodes].mean(axis=0)  # 平均池化
        condensed_features.append(scc_feature)
    
    return condensed_graph, np.array(condensed_features)
```

**ML应用价值：**
- **降维**：将$N$个节点降至$SCC$数量，降低后续模型计算复杂度
- **降噪**：SCC内节点语义相似，合并可减少噪声影响
- **特征聚合**：SCC内部特征平均/最大池化，获得更鲁棒的表示

```python
class SCCGNN(nn.Module):
    """基于SCC的层次化图神经网络"""
    
    def __init__(self, in_dim, hidden_dim, out_dim):
        super().__init__()
        # SCC内部聚合层
        self.intra_scc_conv = GCNConv(in_dim, hidden_dim)
        # SCC之间聚合层（在DAG上进行）
        self.inter_scc_conv = GATConv(hidden_dim, out_dim)
    
    def forward(self, x, edge_index):
        # 1. 求SCC
        scc_list = self.compute_scc(edge_index)
        
        # 2. SCC内部消息传递（并行计算）
        intra_features = []
        for scc in scc_list:
            scc_edge_index = self.get_subgraph_edge_index(scc, edge_index)
            scc_x = self.intra_scc_conv(x[scc], scc_edge_index)
            intra_features.append(scc_x.mean(dim=0))  # 聚合SCC内部表示
        
        # 3. SCC之间消息传递（在DAG上拓扑排序后计算）
        dag_edge_index = self.build_condensed_graph(scc_list, edge_index)
        out = self.inter_scc_conv(
            torch.stack(intra_features), 
            dag_edge_index
        )
        
        return out
```

**GNN优化价值：**
- **计算效率**：SCC内部并行计算，SCC之间按拓扑序计算，避免重复消息传递
- **层次化表示**：学习SCC内部微观特征和SCC之间宏观拓扑特征
- **长距离依赖**：缩点后DAG的直径更小，有利于捕获长距离依赖
