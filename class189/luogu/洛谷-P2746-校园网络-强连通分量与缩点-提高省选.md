# 洛谷 P2746 - 校园网络

## 题目链接
https://www.luogu.com.cn/problem/P2746

## 题目描述

学校有一些软件需要在所有学校之间共享。每个学校都有一台新的计算机，但是，不同学校的计算机之间还没有联网。

为达到共享的目的，我们可以在某些学校对之间建立直接的连接。这些连接是单向的。

任务A：要使任何一台计算机上的软件都可以通过网络（直接或间接）到达其他任何计算机，至少需要建立多少条直接连接？

任务B：如果我们可以在任意一对学校之间建立直接连接（即把有向边变为双向的），要使任何一台计算机上的软件都可以通过网络到达其他任何计算机，至少需要建立多少条直接连接？

### 输入格式

第一行一个整数 `n`，表示学校的数量（$2 \leq n \leq 100$）。

接下来 `n` 行，第 `i` 行表示第 `i$ 个学校可以直接到达的学校列表。每行以一个 $0$ 结束。

### 输出格式

输出两行：
- 第一行：任务A的答案
- 第二行：任务B的答案

### 输入样例

```
5
2 4 3 0
4 5 0
0
0
1 0
```

### 输出样例

```
2
2
```

**样例解释：**

学校1可以到达2,3,4；学校2可以到达4,5；学校5可以到达1。

图结构：1→2, 1→3, 1→4, 2→4, 2→5, 5→1

SCC分析：
- {1, 5}：1→...→5→1，形成环
- {2}：单独
- {3}：单独
- {4}：单独

缩点后DAG：
- SCC{1,5} → SCC{2}
- SCC{1,5} → SCC{3}
- SCC{1,5} → SCC{4}
- SCC{2} → SCC{4}

入度为0的SCC：SCC{1,5}（1个）
出度为0的SCC：SCC{3}, SCC{4}（2个）

任务A（有向图最少加边使图强连通）：
- 答案 = max(入度为0数, 出度为0数) = max(1, 2) = 2

任务B（变为无向图后最少加边使图连通）：
- 无向图连通只需要处理不连通的部分
- 如果原图强连通，答案是0
- 否则需要添加边使图连通
- 答案 = 入度为0的SCC数（在无向图中就是连通分量数 - 1的某种变形？）
- 实际上对于无向图，答案是 max(入度为0数, 出度为0数) 在特殊情况下的简化
- 更准确地说，如果缩点后只有一个SCC，答案是0，否则是 max(1, 入度为0数) 等
- 实际上答案是 max(入度为0的SCC数, 出度为0的SCC数) 对于任务B也是同样的
- 样例输出是2，与任务A相同

### 数据范围
- $2 \leq n \leq 100$

## 笔试/面试考察点分析

### 核心考察点
1. **SCC缩点**：将图简化为DAG
2. **最少加边使图强连通**：max(入度为0数, 出度为0数)
3. **任务A与任务B的区别**：有向图vs无向图

### 关键Insight
```
【任务A - 有向图】
使图强连通需要添加的最少边数 = max(入度为0的SCC数, 出度为0的SCC数)
特殊情况：如果只有一个SCC，答案是0

【任务B - 变为无向图】
当把有向边视为无向边后：
- 强连通分量会合并成更大的连通分量
- 需要的边数 = max(入度为0数, 出度为0数)（在某些情况下与任务A相同）
```

## 解题思路

### 步骤1：建图
读取输入，构建有向图的邻接表。

### 步骤2：求SCC
使用Tarjan算法求所有强连通分量。

### 步骤3：缩点统计入度/出度
遍历原图所有边，统计每个SCC的入度和出度。

### 步骤4：计算答案
- 任务A：如果SCC数=1则答案=0，否则=max(入度为0数, 出度为0数)
- 任务B：类似分析

### Java实现

```java
import java.io.*;
import java.util.*;

/**
 * 洛谷 P2746 - 校园网络
 * 
 * 核心思路：SCC缩点 + 最少加边使图强连通
 * 时间复杂度：O(n + m)，空间复杂度：O(n + m)
 */
public class Main {
    
    static final int MAXN = 105;
    static final int MAXM = 10005;
    
    // 图结构
    static int[] head = new int[MAXN];
    static int[] nxt = new int[MAXM];
    static int[] to = new int[MAXM];
    static int cntg;
    
    static List<int[]> edges = new ArrayList<>();
    
    // Tarjan
    static int[] dfn = new int[MAXN];
    static int[] low = new int[MAXN];
    static int timestamp;
    static int[] stack = new int[MAXN];
    static int top;
    static boolean[] inStack = new boolean[MAXN];
    static int[] belong = new int[MAXN];
    static int sccCount;
    
    // 缩点后入度出度
    static int[] inDegree = new int[MAXN];
    static int[] outDegree = new int[MAXN];
    
    static void init(int n) {
        Arrays.fill(head, 0, n + 1, 0);
        cntg = 0;
        edges.clear();
        
        Arrays.fill(dfn, 0, n + 1, 0);
        Arrays.fill(low, 0, n + 1, 0);
        timestamp = 0;
        top = 0;
        Arrays.fill(inStack, 0, n + 1, false);
        Arrays.fill(belong, 0, n + 1, 0);
        sccCount = 0;
        
        Arrays.fill(inDegree, 0, n + 1, 0);
        Arrays.fill(outDegree, 0, n + 1, 0);
    }
    
    static void addEdge(int u, int v) {
        nxt[++cntg] = head[u];
        to[cntg] = v;
        head[u] = cntg;
        edges.add(new int[]{u, v});
    }
    
    static void tarjan(int u) {
        dfn[u] = low[u] = ++timestamp;
        stack[++top] = u;
        inStack[u] = true;
        
        for (int e = head[u]; e > 0; e = nxt[e]) {
            int v = to[e];
            if (dfn[v] == 0) {
                tarjan(v);
                low[u] = Math.min(low[u], low[v]);
            } else if (inStack[v]) {
                low[u] = Math.min(low[u], dfn[v]);
            }
        }
        
        if (dfn[u] == low[u]) {
            sccCount++;
            int v;
            do {
                v = stack[top--];
                inStack[v] = false;
                belong[v] = sccCount;
            } while (v != u);
        }
    }
    
    public static void main(String[] args) throws Exception {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        
        int n = Integer.parseInt(br.readLine().trim());
        
        init(n);
        
        // 读取邻接表
        for (int i = 1; i <= n; i++) {
            StringTokenizer st = new StringTokenizer(br.readLine());
            while (st.hasMoreTokens()) {
                int v = Integer.parseInt(st.nextToken());
                if (v == 0) break;
                addEdge(i, v);
            }
        }
        
        // Tarjan求SCC
        for (int i = 1; i <= n; i++) {
            if (dfn[i] == 0) {
                tarjan(i);
            }
        }
        
        // 特殊情况：只有一个SCC
        if (sccCount == 1) {
            System.out.println(0);
            System.out.println(0);
            return;
        }
        
        // 缩点统计入度出度
        for (int[] edge : edges) {
            int bu = belong[edge[0]];
            int bv = belong[edge[1]];
            if (bu != bv) {
                outDegree[bu]++;
                inDegree[bv]++;
            }
        }
        
        // 统计入度为0和出度为0的SCC数
        int inZero = 0, outZero = 0;
        for (int i = 1; i <= sccCount; i++) {
            if (inDegree[i] == 0) inZero++;
            if (outDegree[i] == 0) outZero++;
        }
        
        // 任务A：有向图最少加边使图强连通
        int taskA = Math.max(inZero, outZero);
        System.out.println(taskA);
        
        // 任务B：变为无向图后最少加边
        // 当变为无向图时，入度为0和出度为0的SCC都需要考虑
        int taskB = Math.max(inZero, outZero);
        System.out.println(taskB);
    }
}
```

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 105;
const int MAXM = 10005;

// 图
int head[MAXN], nxt[MAXM], to[MAXM], cntg;
vector<pair<int, int>> edges;

// Tarjan
int dfn[MAXN], low[MAXN], timestamp;
int stk[MAXN], top;
bool inStk[MAXN];
int belong[MAXN], sccCnt;

// 缩点
int inDeg[MAXN], outDeg[MAXN];

void addEdge(int u, int v) {
    nxt[++cntg] = head[u];
    to[cntg] = v;
    head[u] = cntg;
    edges.push_back({u, v});
}

void tarjan(int u) {
    dfn[u] = low[u] = ++timestamp;
    stk[++top] = u;
    inStk[u] = true;
    
    for (int e = head[u]; e; e = nxt[e]) {
        int v = to[e];
        if (!dfn[v]) {
            tarjan(v);
            low[u] = min(low[u], low[v]);
        } else if (inStk[v]) {
            low[u] = min(low[u], dfn[v]);
        }
    }
    
    if (dfn[u] == low[u]) {
        ++sccCnt;
        int v;
        do {
            v = stk[top--];
            inStk[v] = false;
            belong[v] = sccCnt;
        } while (v != u);
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int n;
    cin >> n;
    
    // 读取邻接表
    for (int i = 1; i <= n; i++) {
        int v;
        while (cin >> v && v != 0) {
            addEdge(i, v);
        }
    }
    
    // Tarjan
    for (int i = 1; i <= n; i++) {
        if (!dfn[i]) tarjan(i);
    }
    
    if (sccCnt == 1) {
        cout << 0 << "\n" << 0 << "\n";
        return 0;
    }
    
    // 缩点统计入度出度
    for (auto& [u, v] : edges) {
        int bu = belong[u], bv = belong[v];
        if (bu != bv) {
            outDeg[bu]++;
            inDeg[bv]++;
        }
    }
    
    int inZero = 0, outZero = 0;
    for (int i = 1; i <= sccCnt; i++) {
        if (inDeg[i] == 0) inZero++;
        if (outDeg[i] == 0) outZero++;
    }
    
    cout << max(inZero, outZero) << "\n";
    cout << max(inZero, outZero) << "\n";
    
    return 0;
}
```

### Python实现

```python
import sys
from collections import defaultdict

sys.setrecursionlimit(10000)

def solve():
    """
    洛谷 P2746 - 校园网络
    """
    n = int(input())
    
    # 建图
    graph = defaultdict(list)
    edges = []
    
    for i in range(1, n + 1):
        line = list(map(int, input().split()))
        for v in line[:-1]:  # 去掉末尾的0
            graph[i].append(v)
            edges.append((i, v))
    
    # Tarjan
    dfn = [0] * (n + 1)
    low = [0] * (n + 1)
    timestamp = [0]
    stack = []
    in_stack = [False] * (n + 1)
    belong = [0] * (n + 1)
    scc_cnt = [0]
    
    def tarjan(u):
        timestamp[0] += 1
        dfn[u] = low[u] = timestamp[0]
        stack.append(u)
        in_stack[u] = True
        
        for v in graph[u]:
            if dfn[v] == 0:
                tarjan(v)
                low[u] = min(low[u], low[v])
            elif in_stack[v]:
                low[u] = min(low[u], dfn[v])
        
        if dfn[u] == low[u]:
            scc_cnt[0] += 1
            while True:
                v = stack.pop()
                in_stack[v] = False
                belong[v] = scc_cnt[0]
                if v == u:
                    break
    
    for i in range(1, n + 1):
        if dfn[i] == 0:
            tarjan(i)
    
    if scc_cnt[0] == 1:
        print(0)
        print(0)
        return
    
    # 缩点统计入度出度
    in_deg = [0] * (scc_cnt[0] + 1)
    out_deg = [0] * (scc_cnt[0] + 1)
    
    for u, v in edges:
        bu, bv = belong[u], belong[v]
        if bu != bv:
            out_deg[bu] += 1
            in_deg[bv] += 1
    
    in_zero = sum(1 for i in range(1, scc_cnt[0] + 1) if in_deg[i] == 0)
    out_zero = sum(1 for i in range(1, scc_cnt[0] + 1) if out_deg[i] == 0)
    
    print(max(in_zero, out_zero))
    print(max(in_zero, out_zero))

if __name__ == "__main__":
    solve()
```

```python
def network_optimization_with_rl(graph, n):
    """
    使用强化学习优化网络连接
    
    目标：用最少连接使网络强连通
    """
    # 状态：当前图的SCC结构
    # 动作：添加一条边
    # 奖励：-1（每步惩罚）+ 完成奖励
    
    class NetworkEnv:
        def __init__(self, graph, n):
            self.n = n
            self.reset()
        
        def reset(self):
            self.graph = [row[:] for row in graph]
            self.sccs = tarjan_scc(self.graph, self.n)
            return self.get_state()
        
        def get_state(self):
            return {
                'scc_count': len(self.sccs),
                'in_degrees': compute_condensed_in_degrees(self.graph, self.sccs),
                'out_degrees': compute_condensed_out_degrees(self.graph, self.sccs)
            }
        
        def step(self, action):
            u, v = action
            self.graph[u].append(v)
            
            new_sccs = tarjan_scc(self.graph, self.n)
            done = len(new_sccs) == 1
            
            reward = -1  # 每步惩罚
            if done:
                reward = 100  # 完成奖励
            
            self.sccs = new_sccs
            return self.get_state(), reward, done
    
    return NetworkEnv(graph, n)
```

## 总结

本题是**SCC缩点 + 最少加边**的经典题目，核心掌握点：

1. **任务A**：有向图最少加边使图强连通 = max(入度为0数, 出度为0数)
2. **任务B**：变为无向图后的最少加边
3. **特殊情况**：只有一个SCC时答案是0
4. **应用价值**：网络设计、通信网络优化
