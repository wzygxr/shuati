```text

```

恢复命令：

```bash
base64 -d 力学习题全解_累计接续主文档_v071.md.gz.b64 \
  | gzip -d > 力学习题全解_累计接续主文档_v071.md
```

恢复后应以 `SHA256SUMS_v071.txt` 中的散列值核对。
