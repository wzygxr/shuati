## 关键纠错

1. 抛物线 $y=Ax^2$ 若不预设 $A>0$，曲率半径分母应为 $2|A|$；
2. 摆线尖点处的“曲率半径为零”是光滑分支趋近尖点的极限；
3. 实际长度坐标下余弦轨道应写为 $y=A\cos(kx)$，顶点曲率半径为 $1/(Ak^2)$；
4. L 形板原题没有尺寸，不能虚构唯一数值坐标；
5. 薄半球壳与实心半球质心分别为 $R/2$ 和 $3R/8$。
